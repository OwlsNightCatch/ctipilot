    CVE-2026-84295, Progress WS_FTP Server: an unauthenticated remote authentication flaw can expose administrative credentials (CVSS 10.0), with two more unauthenticated flaws, fixed in 2025.0.4 and 2024.0.7; no exploitation found

    Progress, as CVE numbering authority, published on 2026-10-29 CVE-2026-84295, an improper-authentication flaw in WS_FTP Server on Windows that could let an unauthenticated remote attacker reach administrative credentials (CVSS 3.1 10.0), together with an unauthenticated command injection under certain configurations (CVE-2026-90865, 9.0) and an access-control flaw in the Web Admin console (CVE-2026-90867, 8.1).     NOTABLENATOB2

    Teams help-desk impersonation to domain-controller identity: Microsoft traces two intrusions from a Quick Assist session to AD CS ESC1 certificates with DCSync, and to PetitPotam relayed to ESC8 Web Enrollment

    Microsoft Threat Intelligence describes two human-operated intrusions, not attributed to any actor, in which an external Teams contact impersonating help-desk staff got a user to open Quick Assist, after which the operator staged a portable runtime and used Active Directory Certificate Services to reach privileged identities: a template open to ESC1 issued certificates for privileged accounts and DCSync followed within seconds, and in the second case PetitPotam was relayed to AD CS Web Enrollment (ESC8) for a certificate for a domain controller account. An issued certificate stays valid after a password reset or a reimage of the first workstation, and in the first case one privileged account excluded from automated containment stayed usable and was used to copy data to an external SFTP destination.

    NOTABLENATOB1

    Cursor marketplace: a tampered Claude Code extension (versions 2.1.312 and 2.1.313) planted an SSH key, a reverse tunnel and persistence for about eleven hours on 2026-10-29; uninstalling it does not remove the persistence

    Between about 09:27 and 20:35 UTC on 2026-10-29 the Cursor VS Code Extension Marketplace served a modified copy of Anthropic's Claude Code extension, versions 2.1.312 and 2.1.313 for macOS and Windows, that appends an attacker's SSH key to authorized_keys, tries to enable SSH and open a reverse tunnel, and installs persistence that outlives the extension. Coding errors made the SSH step fail on most standard-user hosts, so Cursor and Sophos say the attacker could not log in there, but the key, the persistence and a host report were still written. Anthropic told Microsoft its systems were not compromised, and no source says how the attacker published under Anthropic's name.

    NOTABLECVE-2026-98432NATOB2

    CVE-2026-98432, Linux kernel IPv4 TCP: a use-after-free in connection setup, present since 4.4, has an Anthropic-built remote root exploit against MPTCP listeners; Debian is fixed, Ubuntu and Red Hat kernels are not yet (CVSS 9.8)

    The Linux kernel CVE team published CVE-2026-98432 on 2026-10-15, a use-after-free in the IPv4 TCP connection setup path that dates to Linux 4.4 and is reached by a SYN packet carrying IP options; the CNA scores it CVSS 9.8. Anthropic reports that Claude wrote an exploit giving a remote, unauthenticated attacker root command execution on servers with a multipath TCP (MPTCP) listener, and the Go team says the bug is not specific to MPTCP and that Go programs enable MPTCP on Linux listeners by default. Debian's security kernels are fixed while Ubuntu 22.04 to 26.10 and RHEL 8 to 10 had no fixed kernel on 2026-10-30; no source reports public exploit code or attacks.
