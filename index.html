    Technical University of Munich: attackers captured the central-login passwords of everyone who signed in to the legacy myTUM portal, took a TUMonline system administrator's credentials and attacked the campus-management system; accounts with MFA were protected

    The Technical University of Munich said on 2026-11-06 that unknown attackers attacked its myTUM portal and captured the central-login passwords of all persons who had signed in there, among them the credentials of a TUMonline system administrator, with which they attacked the campus-management system TUMonline, which TUM took off the network.     Oneconsult on the File System Access API: after two clicks a website holds read and write access to folders such as .vscode, .Azure, the public desktop and SMB shares in Chrome and Edge, enough for token theft and persistence without a process on the host

    Oneconsult's analysis of Chromium's Windows blocklist shows that a website granted a folder through the File System Access API after two clicks keeps a handle for as long as the tab is open, and that the blocklist leaves .vscode, .Azure, C:\Users\Public, SMB shares and, after a OneDrive Known Folder Move, the Desktop reachable. The paths it demonstrates are token and .env theft, a fake VS Code extension and PowerShell profile or module backdoors that need the Bypass or Unrestricted execution policy, and a file proxy through the open tab that EDR sees only as browser file activity.

    NOTABLENATOB2

    Kaspersky GERT: two ESXi and Proxmox ransomware cases in which a monitoring server's reused root password and plaintext administrator notes, not a VM escape, gave the attackers the hypervisor

    Kaspersky's Global Emergency Response Team describes two ransomware cases in virtualised estates. In the BlackNevas case a PRTG Network Monitor held ESXi root access and the same root password was reused across hosts, so the attacker connected over SSH, disabled the execInstalledOnly policy with esxcli, ran the encryptor and deleted logs; in the case attributed to The Gentlemen the actor found Proxmox root credentials in plaintext notes on an administrator workstation and used the VNC web socket to encrypt the cluster. Kaspersky stresses that no VM escape was needed.
