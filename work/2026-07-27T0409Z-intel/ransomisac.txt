Introduction</h2><p>The Unified Threat Advisory is a coordinated Cyber Intelligence effort led by Ransom-ISAC, with collaboration from eCrime.ch and DEFUSED. This update covers active Cl0p ransomware affiliate exploitation targeting internet-exposed PTC Windchill and FlexPLM deployments.</p><h2 id="overview">2. Overview</h2><p>Attackers chain a pre-authentication information disclosure in the FlexPLM WSDL endpoint with a server-side flaw in the Windchill login servlet, enabling unauthenticated remote code execution and deployment of hex-named JSP webshells under<!-- --> <code>/Windchill/login/</code>. Post-exploitation includes filesystem enumeration via <code>flst.txt</code>, staging of engineering/design data, and double-extortion data theft. Confirmed victim sectors include Manufacturing, Automotive, Aerospace, and Retail/Apparel.</p><p>This advisory issues four new C2 indicators alongside previously distributed IOCs from 7/8/2026, 7/1/2026, 6/25/2026, and 6/18/2026.</p><ul><li><strong>Windchill RCE Chain</strong> — CVSS 9.8</li><li><strong>FlexPLM WSDL Disclosure</strong> — CVSS 7.5</li></ul><p>PTC has released fixed builds for both defects; unpatched, internet-exposed Windchill/FlexPLM instances remain the primary attack surface.</p><h2 id="key-highlights">3. Key Highlights</h2><ul><li><strong>Threat actor:</strong> Cl0p ransomware affiliate activity</li><li><strong>Initial access:</strong> FlexPLM WSDL disclosure + Windchill login servlet flaw</li><li><strong>Post-exploitation:</strong> JSP webshells,<!-- --> <code>flst.txt</code> file listing, data staging</li><li><strong>Malicious header:</strong> <code>X-windchill-req: ?x8Fmgow</code></li><li><strong>Hunt path:</strong> <code>/Windchill/login/[0-9a-f]<!-- -->{16}<!-- -->.jsp</code></li><li><strong>Hash IOC (SHA-256):</strong> <code class="break-all">55a1eb4c2d3da04376df39d7ba832569c6af1a37a0cf2b95f754ac898023a30c</code></li><li><strong>Pre-attack recon:</strong> <code>GET /Windchill/rfa/jsp/login/*.jsp?wsdl</code> with<!-- --> <code>response_bytes = 4045</code></li></ul><h2 id="extortion-campaign">4. Extortion campaign</h2><p>On 20 July, Ransom-ISAC began observing an alleged Cl0p ransomware (aka Graceful Spider, Chubby Scorpius, FIN11, Lace Tempest) data extortion campaign sending emails with a subject line, “Windchill PDMLink module serious data leak” to an unknown number of affected organizations (Figure 1 &amp; Figure 2). The extortion emails appear to originate from randomly compromised accounts, are sent to hundreds of users within an impacted organization and include Cl0p’s latest contact information (Figure 3). This extortion approach is consistent with what we observed with the Oracle EBS campaign last year, except for the use of new email addresses.</p><div class="my-8"><div aria-owns="rmiz-modal-" The vulnerability</h2><p>We suspect that threat actors affiliated with Cl0p ransomware most likely exploited<!-- --> <a href="https://nvd.nist.gov/vuln/detail/CVE-2026-12569" target="_blank" rel="noopener noreferrer">CVE-2026-12569</a> <!-- -->as a zero-day vulnerability in early June 2026.<!-- --> <a href="https://nvd.nist.gov/vuln/detail/CVE-2026-12569" target="_blank" rel="noopener noreferrer">CVE-2026-12569</a> <!-- -->(CVSS v3.1 9.8 / 10; vector<!-- --> <code>CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H</code>) was disclosed on 17 June, 2026 and is described as a critical-severity remote code execution (RCE) vulnerability in PTC Windchill PDMlink and PTC FlexPLM that may be exploited through the deserialization of untrusted data.<!-- --> <a href="https://nvd.nist.gov/vuln/detail/CVE-2026-12569" target="_blank" rel="noopener noreferrer">CVE-2026-12569</a> <!-- -->also impacts Windchill and FlexPLM releases prior to 11.0 M030. CISA added<!-- --> <a href="https://nvd.nist.gov/vuln/detail/CVE-2026-12569" target="_blank" rel="noopener noreferrer">CVE-2026-12569</a> <!-- -->to their<!-- --> <a href="https://www.cisa.gov/known-exploited-vulnerabilities-catalog?field_cve=CVE-2026-12569" target="_blank" rel="noopener noreferrer">known exploited vulnerabilities (KEV) catalog</a> <!-- -->on 25 June, 2026. In the observed intrusions, this RCE is chained with a separate pre-authentication information-disclosure defect in the FlexPLM WSDL endpoint (CVSS v3.1 7.5) to enable unauthenticated exploitation.</p><h2 id="new-iocs">6. Recommended actions</h2><p>Organizations receiving emails matching this pattern should conduct threat hunting dating back to early June 2026, using the indicators of compromise (IOCs) in<!-- --> <a href="https://www.ptc.com/en/about/trust-center/advisory-center/active-advisories/windchill-flexplm-rce-vulnerability" target="_blank" rel="noopener noreferrer">PTC’s advisory</a> <!-- -->as soon as possible and follow PTC’s remediation steps outlined in<!-- --> <a href="https://www.ptc.com/en/support/article/CS473270" target="_blank" rel="noopener noreferrer">PTC’s Support Article</a>. This situation is still developing.</p><h2 id="outlook">8. Outlook</h2><p>We will continue to monitor for any updates with this latest campaign.
