# New features in Airlock Gateway 8.6

This section describes new features in Airlock Gateway 8.6.

Airlock Gateway 8.6 is available in the [Techzone download area](https://techzone.ergon.ch/download).

## Main new features

- Airlock Anomaly Shield: Improved Client Behavior Analysis Model for more stable, reliable, and consistent detection results.
- Airlock Anomaly Shield: New URL Model for Path Navigation Analytics to detect anomalous behavior.
- Run Airlock Gateway in [Red Hat OpenShift Virtualization](https://docs.airlock.com/1776358270564.html) and move forward with your Kubernetes strategy.
- Improved [DoS protection](https://docs.airlock.com/1571978527018.html) with higher performance through early Layer 3 filtering and better resource efficiency.
- [ACME services with DNS-01](https://docs.airlock.com/1583435026461.html) support are now available for the Configuration Center.
- REST API extensions with stricter mapping imports, allow rules, reusable ICAP services per mapping, and dedicated read-only and full-access roles.

See the [Changelog](https://docs.airlock.com/1781491741687.html) for details and make sure to check  [Actions required when upgrading](https://docs.airlock.com/1741011877825.html) for important changes when upgrading.
