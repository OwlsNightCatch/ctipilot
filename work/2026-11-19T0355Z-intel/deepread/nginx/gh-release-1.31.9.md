## Repository navigation

[nginx-1.31.9](https://nginx.org/en/download.html) mainline version has been released, with vulnerability fixes for [use-after-free](https://nginx.org/en/security_advisories.html) in resolver ([CVE-2026-123634](https://github.com/advisories/GHSA-qxf8-26hv-4jh5)), [memory corruption](https://nginx.org/en/security_advisories.html) in HTTP/2 flow control ([CVE-2026-123007](https://github.com/advisories/GHSA-m4q8-cf44-f42r)), [use-after-free](https://nginx.org/en/security_advisories.html) in HTTP/3 ([CVE-2026-121810](https://github.com/advisories/GHSA-fxx2-rrmx-x4v2)), [use-after-free](https://nginx.org/en/security_advisories.html) in HTTP/2 ([CVE-2026-123633](https://github.com/advisories/GHSA-7xxj-p8w5-434q)), [infinite loop](https://nginx.org/en/security_advisories.html) while reading client request body over TLS 1.3 ([CVE-2026-118899](https://github.com/advisories/GHSA-mjqw-rmmf-hgxf)), [use-after-free](https://nginx.org/en/security_advisories.html) in mail proxy module ([CVE-2026-113425](https://github.com/advisories/GHSA-rmpv-v5m5-rr27)), [NULL pointer dereference](https://nginx.org/en/security_advisories.html) when using PROXY protocol version 2 ([CVE-2026-120993](https://github.com/advisories/GHSA-39qv-989q-vg33)), [buffer overflow](https://nginx.org/en/security_advisories.html) when using alias with try\_files ([CVE-2026-125283](https://github.com/advisories/GHSA-cgqq-hx2v-pf8c)), [SNI bypass](https://nginx.org/en/security_advisories.html) in client certificate validation in stream module ([CVE-2026-120967](https://github.com/advisories/GHSA-q9wg-m5cc-h828)), and [insufficient validation](https://nginx.org/en/security_advisories.html) in stream ssl\_preread module ([CVE-2026-123640](https://github.com/advisories/GHSA-c32q-x8cv-vhfr)).

See official [CHANGES](https://nginx.org/en/CHANGES) on nginx.org.
