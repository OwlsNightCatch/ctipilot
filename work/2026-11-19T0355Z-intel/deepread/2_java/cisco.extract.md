# Cisco Security Advisory

# Vulnerability in Oracle OpenJDK (Java4Shell) Affecting Cisco Products: November 2026

- On November 17, 2026, Oracle announced the availability of fixes for a vulnerability in OpenJDK that could lead to remote code execution identified by CVE-2026-114938. The vulnerability affects OpenJDK Java 17.0.6 and later on x86-64 platforms when processing Base64 encoded content. For more information, see the [Oracle Critical Security Patch Update Advisory - November 2026](https://www.oracle.com/security-alerts/cspunov2026.html) and the [OpenJDK Vulnerability Advisory: 2026/11/17](https://openjdk.org/groups/vulnerability/advisories/2026-11-17).
For additional information, see the Talos blog post: [Talos Threat Advisory CVE-2026-114938: Critical vulnerability in OpenJDK JAVA](https://blog.talosintelligence.com/java4shell/)
This advisory will be updated as additional information becomes available. This advisory is available at the following link:
[https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-nov2026-java-rce-eCa6ss9z](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-nov2026-java-rce-eCa6ss9z)

## Products Confirmed Not Vulnerable Only products listed in the [Affected Products](https://sec.cloudapps.cisco.com#affectfield) section of this advisory are known to be affected by this vulnerability.


- Available details indicate that systems that use x86-64 CPU architectures with AVX-512 VBMI support are affected. Hardware families that use x86-64 without AVX-512 or that use different CPU architectures like ARM or Cisco Silicon One are not affected.

- There are no workarounds that address this vulnerability.
