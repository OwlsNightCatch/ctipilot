# Sicherheits-Updates für Java angekündigt: Betreiber sollen ihre Systeme prüfen

**Oracle hat für den 17. November 2026 Sicherheits-Updates angekündigt, darunter elf Sicherheits-Patches für Java SE. Laut Hersteller können die zugehörigen Schwachstellen über das Netzwerk ohne Zugangsdaten ausgenutzt werden. Das Bundesamt für Cybersicherheit (BACS) empfiehlt Betreibern, ihre Systeme zu prüfen und die Aktualisierung vorzubereiten.**

Java ist eine technische Grundlage vieler Anwendungen. Es kann auch in Software und Geräten enthalten sein, ohne dass dies den Nutzerinnen und Nutzern bekannt ist. Die Ankündigung umfasst neben Java SE auch GraalVM und JavaFX. Details zu den einzelnen Schwachstellen und ihrer Behebung sollen mit der vollständigen Sicherheitsmeldung folgen.

## Was Betreiber jetzt tun sollten

- **Bestand prüfen:** 
Erfassen Sie Anwendungen und Geräte, die Java verwenden, die eingesetzten Versionen und die zuständigen Betreiber. Berücksichtigen Sie integrierte Komponenten und extern betriebene Dienste.
- **Aktualisierung vorbereiten:** 
Klären Sie mit Ihren Software-Lieferanten und IT-Dienstleistern, welche Produkte betroffen sind und wie Updates bereitgestellt werden. Bereiten Sie die zeitnahe Installation einschliesslich notwendiger Tests und Neustarts vor.
- **Zugriffe überprüfen:** 
Priorisieren Sie aus dem Internet erreichbare und geschäftskritische Systeme. Beschränken Sie nicht benötigte externe Zugriffe.

## Was Privatpersonen tun sollten

Für Privatpersonen steht das Installieren verfügbarer Sicherheits-Updates für Programme und Geräte im Vordergrund. Nutzen Sie dafür die offiziellen Update-Funktionen und Hinweise der Anbieter. Enthaltene Java-Komponenten werden je nach Produkt über dessen Software- oder Geräte-Update aktualisiert.

Wer eigene Server oder Online-Dienste betreibt, sollte zusätzlich die Empfehlungen für Betreiber beachten.

## Weitere Informationen

Das BACS ergänzt seine technischen Informationen auf dem [Cyber Security Hub](https://security-hub.ncsc.admin.ch/#/posts/13198). Für betroffene Produkte sind die [Sicherheitsinformationen von Oracle](https://www.oracle.com/security-alerts/cspunov2026.html) und den jeweiligen Anbietern massgebend.
