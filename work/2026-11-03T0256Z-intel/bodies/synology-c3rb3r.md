# Synology urges users to update DSM following ransomware attacks on outdated DSM versions

TAIPEI, Taiwan – October 29, 2026 — Synology has identified threat actors exploiting a vulnerability patched in December 2024 to target devices running outdated versions of DSM. These attacks aim to encrypt data and extort ransom.

Synology strongly urges all users running vulnerable versions to update DSM immediately to protect their systems. Synology also recommends enabling automatic updates to keep DSM up to date at all times.

For more information, refer to [<u>Synology-SA-24:20</u>](https://www.synology.com/zh-tw/security/advisory/Synology_SA_24_20).
