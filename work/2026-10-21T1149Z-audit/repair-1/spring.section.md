HeroDevs states that the Config Server's resource endpoints are read-only, so the direct impact of the traversal is information disclosure: secrets, credentials or any other file the server process can read, which in typical deployments includes the secrets the Config Server centralizes for a fleet of microservices ([HeroDevs, 2026-05-08](https://www.herodevs.com/blog-posts/cve-2026-40982-critical-spring-cloud-config-server-directory-traversal-cvss-9-8)). The same post also says an attacker can read or write arbitrary files, and the CVSS vector it gives scores integrity High; Spring's advisory describes only a directory traversal ([Spring, 2026-05-06](https://spring.io/security/cve-2026-40982)).
