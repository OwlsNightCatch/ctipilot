### Description

Palo Alto Networks is aware of the vulnerability in Brotli: CVE-2026-111497.

A buffer overflow vulnerability in the Brotli decoder (c/dec/decode.c) in Google Brotli versions 1.0.3 through 1.2.0 on all platforms allows a remote unauthenticated attacker to corrupt adjacent decoder state memory, disclose sensitive memory contents, cause a denial of service, or potentially execute arbitrary code using a crafted Brotli-compressed stream. Users need to update any Brotli libraries or binaries between 1.0.3 through 1.2.0 to the latest available version: 1.0.10 or 1.1.1 or 1.2.1. Brotli is commonly used by many HTTP-based applications including Node.js.

*Palo Alto Networks is actively investigating its product portfolio and cloud services to determine potential impact from this vulnerability. The sections below will be updated as our analysis progresses and additional information or remediation status becomes available.*

### Required Configuration for Exposure

PAN-OS

This issue is applicable to PAN-OS software on PA-Series and VM-Series firewalls that have inspection of Brotli compressed traffic and TLS/SSL decryption enabled on the dataplane. There is no impact on the Management interface (web or API) of the PAN-OS devices.

Brotli inspection is not supported for PAN-OS versions before 11.2.4.

To check if you have this configuration is enabled follow below steps:

**On the CLI **(PAN-OS 11.2.4 or higher)****:

1. Log in to the firewall [command-line interface](https://docs.paloaltonetworks.com/content/techdocs/en_US/ngfw/pan-os-cli-quick-start/cli-cheat-sheet-content-id).
2. Run the command **show system setting brotli**.
3. Check the output. The firewall is only exposed if the output displays Enabled: yes (or if **show system setting brotli-encoding** returns **Enabled: Yes**).

**On the Web Interface (PAN-OS 12.1.2 and later):**

1. Navigate to Device > Setup > [Content-ID](https://docs.paloaltonetworks.com/network-security/security-policy/administration/security-profiles).
2. Locate the Content-ID Settings pane.
3. Check if the Allow Brotli Encoding option is checked.

Other Products

No special configuration is required to be affected by this issue.

### Workarounds and Mitigations

**PAN-OS**

Customers can mitigate the risk of this issue by taking any of the following actions:

**:**


1. You can disable the Brotli inspection engine globally on the firewall by running the following command in the [command-line interface](https://docs.paloaltonetworks.com/content/techdocs/en_US/ngfw/pan-os-cli-quick-start/cli-cheat-sheet-content-id): **set system setting brotli-encoding disable**.
2. To verify that decompression has been disabled, execute **show system setting brotli** and confirm the output displays **Enabled: no**.

Disable Brotli Decompression via the Web Interface (PAN-OS 12.1.2 and later)

****:****

1. Navigate to Device > Setup > [Content-ID](https://docs.paloaltonetworks.com/network-security/security-policy/administration/security-profiles).
2.  Locate the Content-ID settings pane and click the edit icon.
3. Uncheck the Allow Brotli Encoding option.
4. Commit the configuration changes.
