SAP's Security Patch Day page of 2026-11-10 lists 35 new notes and four GitHub security advisories and carries the four CVSS 10.0 notes this entry covers ([SAP, 2026-11-10](https://support.sap.com/en/my-support/knowledge-base/security-notes-news/november-2026.html)). Onapsis published threat advisories for the Web Dispatcher and ICM pair, which it names ICM2SHELL, and for the Gateway flaw, which it names ProxyGate, with the fixed kernel patch levels, the Gateway parameter gw/acl_mode_proxy = 1 and the statement that it gave SAP a working unauthenticated exploit for ICM2SHELL and has seen no attacks ([Onapsis, 2026-11-10](https://onapsis.com/blog/icm2shell-cve-2026-76964-cve-2026-89126-sap-netweaver-web-dispatcher-threat-advisory/); [Onapsis, 2026-11-10](https://onapsis.com/blog/proxygate-cve-2026-89103-sap-netweaver-gateway-threat-advisory/)). Five further notes on the page are rated Critical at CVSS 9.1 to 9.9, among them an ABAP application server OS command injection for low-privileged users (CVE-2026-76965, note 3792735) and a code injection in NetWeaver Knowledge Management XML Forms (CVE-2026-109803, note 3809153); they are authenticated and are not covered here ([SAP, 2026-11-10](https://support.sap.com/en/my-support/knowledge-base/security-notes-news/november-2026.html)).
