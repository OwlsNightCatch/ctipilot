Veeam's impact statement KB4966, last modified on 2026-11-10, says that every Veeam component that includes a Linux kernel is affected until the kernel is updated: Veeam Software Appliance 13.1, Veeam Infrastructure Appliance 13.1 in any role (backup proxies, repositories including hardened repositories, gateways, mount servers, WAN accelerators and others), workers deployed by the hypervisor plug-ins, the Linux-based helper appliances of Veeam Backup & Replication 13.1 and 12.3, Veeam Recovery Media for the Agent for Linux created before the update, and the public-cloud plug-in appliances; Kasten for Kubernetes is not affected ([Veeam, 2026-11-10](https://www.veeam.com/kb4966)). The fixed kernel, a CIQ build 5.14.0-570.60.1+27.2.el9_6_ciq, has been in the Veeam repository since 2026-11-02; Veeam Updater checks every 12 hours and, with the default configuration, installs mandatory updates on the nearest Sunday at 14:00 in the backup server's time zone, a restart may be required, Windows-based Backup & Replication servers need a private fix for their helper appliances, and virtual labs and helper appliances that stay deployed must be redeployed ([Veeam, 2026-11-10](https://www.veeam.com/kb4966)).
