    ### Description

**Impact:** A remote attacker may be able to execute arbitrary code with root privileges.

**Description:** Multiple issues were addressed with improved input validation.

### Affected Versions

All Kiteworks Email Protection Gateway versions prior to 9.4.1.

### Remediation

Upgrade to Kiteworks Email Protection Gateway 9.4.1 or later.
