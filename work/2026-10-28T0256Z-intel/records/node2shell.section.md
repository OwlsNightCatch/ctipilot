CISA added CVE-2026-111497 to its Known Exploited Vulnerabilities catalog on 2026-10-27 "based on evidence of active exploitation", naming no actor or victim ([CISA, 2026-10-27](https://www.cisa.gov/news-events/alerts/2026/10/27/cisa-adds-two-known-exploited-vulnerabilities-catalog)). ELLIO's sensors recorded a public checker that maps hosts decompressing Brotli and then, on 2026-10-26, one Brotli-coded request body of about 23 MB built against Node.js 24.22.0 on x86-64, which ELLIO reads as adoption by an operator focused on mass exploitation; its own test of the attacker's chain against that build got no shell in 50 attempts, so a failed attempt shows as a worker crash ([ELLIO, 2026-10-26](https://ellio.tech/en/blog/node2shell-cve-2026-111497-rce-on-stock-nodejs-builds/)). Tenable relays the report and has not confirmed it ([Tenable, 2026-10-26](https://www.tenable.com/blog/brotli2shell-frequently-asked-questions-for-google-brotli-decoder-cve-2026-111497)); Cisco and Palo Alto report no malicious use against their own products ([Cisco PSIRT, 2026-10-27](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-oct2026-node-js-Jj3SQ19u); [Palo Alto Networks, 2026-10-26](https://security.paloaltonetworks.com/CVE-2026-111497)).

JFrog reproduced a remote crash of a ClickHouse server with one request carrying a crafted 23 MB body, with the fix merged but not released when it wrote ([JFrog, 2026-10-25](https://research.jfrog.com/post/brotli2shell-beyond-node2shell-and-http2shell/)). Akamai gives a lever for Express 5 and body-parser 2 services that accept no compressed request bodies: set the inflate option to false ([Akamai, 2026-10-26](https://www.akamai.com/blog/security-research/inside-node2shell-closer-look-cve-2026-111497)). A Node.js build is judged by its release version, because the bundled version string reads 1.2.0 on patched builds as well ([ELLIO, 2026-10-26](https://ellio.tech/en/blog/node2shell-cve-2026-111497-rce-on-stock-nodejs-builds/)).
