# ITEM 1 — PUPPET: CVE-2026-115731 (Perforce Puppet Enterprise / Puppet Server; CISA KEV 2026-11-17)

## 1.1 Headline versus the first pass
- Vendor-channel confirmation now in hand: Puppet's own release notes for PE 2026.0.1, 2025.12.1 and 2023.8.13 and its "What's New" page name CVE-2026-115731 and CVE-2026-115732 as fixed, and Puppet Core 8.22.2 / 9.1.3 release notes carry the agent-side fix. The Perforce portal CVE page itself stays unreadable.
- The CNA record lists **only Puppet Enterprise** as affected product (Puppet Server appears only in the description text). No vendor fix line for a standalone open-source Puppet Server exists in any source read: Vox Pupuli says "Puppet will not be receiving any more updates" and tells users to migrate to OpenVox; Debian nevertheless shipped puppet-agent updates (DSA-6608-1, DLA-4884-1). The CNA solution text says to upgrade to a release that bundles puppet-agent 8.22.2 or 9.1.3 (Puppet Enterprise 2023.8.13, 2025.12.1 or 2026.0.1) and restart the server.
- Exploitation basis is still only CISA's assertion plus ENISA's `exploitedSince`; nobody names an actor, victim or telemetry. The public payload predates KEV by 14 days (OpenVox advisory 2026-11-03T20:04Z).
- The sibling CVE-2026-115732 is fixed in the same releases, is NOT in KEV, and carries conflicting second-hand exploitation claims (securityonline update citing a Reddit thread; unreadable Feedly entry) against CISA ADP SSVC "none" (2026-11-06) and securityonline's own tracker "No exploitation is confirmed yet". Treat as unconfirmed.

## 1.5 Contradictions with, or corrections to, the first pass
1. First-pass title says "Perforce Puppet Enterprise and Puppet Server before 2023.8.13, 2025.12.1 and 2026.0.1". The CNA lists Puppet Enterprise only; "Puppet Server" is in the description. Do not state a Puppet Server version range as vendor fact.
2. No correction needed to the first pass's "unauthenticated code execution where the CA autosigns": it is the CNA's own wording (1.1). Add Neodyme's precision that the flaw is strictly rated "authenticated" (needs a valid agent certificate) while autosign makes obtaining one trivial (1.22), and that the GHSA title itself reads "Authenticated RCE".
3. First pass cites the Perforce portal page as the vendor advisory; that page was not readable by any transport. All vendor statements here come from Puppet's What's New page and release notes plus the CNA record.
4. First pass: "EPSS 0.00366 (FIRST)" confirmed; EUVD displays 0.37 for the same CVE without a stated scale (do not quote it as a probability).
5. KEV due date: the catalogue says 2026-12-01; the alert page (WebFetch reading) states no due date. The catalogue row also now carries a `forensicTriage` field and cites BOD 26-04.
