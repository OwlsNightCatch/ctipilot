**N-central Critical Security Update – 2026.4 HF3 Available**

Valued Customer, As part of our continued response to the non-responsible communication of critical vulnerabilities affecting N-central, **N-able has released N-central 2026.4 HF3**, which provides additional security updates and hardening measures.

HF3 builds on the protections delivered in HF2 and includes further improvements across authentication and access controls, Agent and Probe communications, file handling, server components, legacy APIs, and user management.

**The vulnerabilities announced on November 9 and November 12 are specific to N-central. No other N-able products are at risk from these vulnerabilities.**

**N-central On-Premises Environments:**

*   **Action Required:** Please upgrade your N-central server to 2026.4 HF3 as soon as possible.

**Security Improvements in HF3:**

HF3 includes additional security improvements across the following areas:

*   **Authentication and access control:**Added authentication and permission checks to additional server operations.
*   **Agent, Probe, and appliance security:**Strengthened appliance authentication and validation of requests between Agents, Probes, and appliances, including appliance session handling.
*   **File and import handling:** Added additional validation for file publishing, file paths, and XML imports.
*   **Server hardening:**Further hardened server components, including how the server handles incoming requests and makes outbound connections.
*   **Legacy APIs:** Removed the configuration option for legacy APIs. Legacy APIs are now permanently blocked.
*   **User management:** Improved how user accounts are managed and secured.

**Open Issues:**

*   **Remote control is not available.** Remote control functionality other than Take Control is disabled. Take Control continues to work as expected.
*   **Intune integration is blocked.** The Intune integration is currently blocked.

We appreciate your continued partnership and patience as we have worked through these updates. N-able remains committed to taking the actions necessary to help protect N-central environments.
