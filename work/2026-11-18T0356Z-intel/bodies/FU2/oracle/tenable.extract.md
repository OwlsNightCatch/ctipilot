**Oracle addresses 640 CVEs in its November 2026 Critical Security Patch Update with 655 patches, including 62 critical updates.**

## Key Takeaways

1. The November 2026 Critical Security Patch Update (CSPU) contains fixes for 640 unique CVEs in 655 security updates
2. 62 issues (9.5% of all patches) were assigned a critical severity rating
3. Oracle Hyperion received the highest number of patches at 267, accounting for 40.8% of all patches

## Background

On November 17, Oracle released its [<u>Critical Security Patch Update (CSPU) for November 2026</u>](https://www.oracle.com/security-alerts/cspunov2026.html). Beginning in May 2026, Oracle introduced CSPUs as a monthly release cycle that sits between the larger quarterly Critical Patch Updates (CPUs), addressing a focused set of high-severity issues on a faster cadence. This CSPU contains fixes for 640 unique CVEs in 655 security updates across 21 Oracle product families. Out of the 655 security updates published, 9.5% of patches were assigned a critical severity. Medium severity patches accounted for the bulk of security patches at 41.8%, followed by high severity patches at 38%.

This month's update includes 62 critical patches across 57 CVEs.

| **Severity** | **Issues Patched** | **CVEs** | 
|---|---|---|
| Critical | 62 | 57 | 
| High | 249 | 245 | 
| Medium | 274 | 268 | 
| Low | 70 | 70 | 
| **Total** | **655** | **640** | 

## Analysis

This month's update saw the Oracle Hyperion product family contain the highest number of patches at 267, accounting for 40.8% of the total patches, followed by Oracle Supply Chain at 74 patches, which accounted for 11.3% of the total patches.

**Oracle CSPU includes patches for Java4Shell (CVE-2026-114938)** 

As part of the November CSPU release, Oracle patched CVE-2026-114938, a vulnerability in the Compiler component of Oracle Java SE and GraalVM. It was assigned a CVSSv3 score of 8.1. Researchers have dubbed this flaw “Java4Shell” and technical details about this vulnerability are expected to be released soon. The Research Special Operations (RSO) team plans to publish a FAQ blog post on the [<u>Tenable blog</u>](https://tenable.com/blog) with more detail.
