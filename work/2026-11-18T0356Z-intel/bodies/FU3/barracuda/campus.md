# Barracuda XDR Integration Credentials

By SVC-ATLASS-ADMIN

Subscribe Subscribe

This guide provides step-by-step instructions for rotating API keys, tokens, and client secrets used by Barracuda XDR integrations. It covers creating replacement credentials, updating integrations, verifying data collection, and revoking old credentials. Integration-specific requirements and troubleshooting guidance are also included.

For detailed instructions, see the attached Barracuda XDR - API Key Rotation Guide.pdf.
