### 1(v) Workaround text, verbatim

* **CVE-2026-123903 (vCenter bypass): none.** "To remediate CVE-2026-123903 apply the patches listed in the 'Fixed Version' column of the 'Response Matrix' found below. ⏎ ⏎ **Workarounds:**None" (advisory). Same "None" for CVE-2026-123904 to -123909, -123913 to -123916 and -123918; Avi CVEs "None."
* **CVE-2026-123910 / -123911 (ESX): ESXi 8.0 row only, KB463535** (published 11-24-2026 00:22 per the KB page's JSON-LD, timezone not stated). Advisory text for both: "**Workarounds:**Please see the response matrix." The matrix points only the `ESX | N/A | 8.0` row to KB463535; the 9.1.x, 9.0.x, 7.0 and VCF 5.x rows say "None". KB463535 text verbatim:

  > ESXi 8.x versions run an `IOFilterVP` service on port 9080 and is vulnerable to CVE-2026-123910 and CVE-2026-123911.
  > **Note:** This is applicable to ESXi 8.x versions only.
  > To mitigate this risk, configure the ESXi firewall settings to restrict access to port 9080.
  > Only the vCenter Server IP address should be allowed to communicate to port 9080.
  > Follow the below stesp to configure the ESXi firewall:
  > 1. Log in to the ESXi host via SSH or the ESXi Shell using root credentials.
  > 2. Disable the `"allowed-all"` rule for the `IOFilterVP` service: `esxcli network firewall ruleset set -r iofiltervp --allowed-all false`
  > 3. Add the vCenter Server IP address to the allowed list (replace <vCenter-IP> with your actual IPv4/IPv6 address or subnet): `esxcli network firewall ruleset allowedip add -r iofiltervp -i <vCenter-IP>`
  > 4. Verify that the IP address was successfully added: `esxcli network firewall ruleset allowedip list -r iofiltervp`

  Q&A caveat (Q25): "Network access control can be a mitigation for many security issues, and is recommended as a general best practice for security. For the ESX I/O filter service, limiting the systems that can reach it only resolves a small portion of the issues in this VMSA, and may negatively impact the operation of the cluster and the availability of workloads and storage. Please apply the software updates instead."
