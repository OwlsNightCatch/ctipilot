VMware HCX

CVE-2026-119618 is a critical remote code execution vulnerability in Apache mod\_http2 that impacts VCF Operations HCX. This vulnerability and its impact on the mentioned VMware products are documented in the following VMware Security Advisory (VMSA), review this document before continuing: [VMSA-2026-0010](https://support.broadcom.com/web/ecx/support-content-notification/-/external/content/SecurityAdvisories/0/39625)

VCF Operations HCX Manager 9.1.x

Disable h2 protocol in Apache configuration. Following are the steps to disable h2 protocol in HCX manager. There is no functional impact due to this workaround. This will not impact the on-going migrations and network extensions.

1. Take a backup or snapshot of the VCF Operations HCX Manager.
2. SSH to the HCX manager appliance and switch to root user.
3. Download the script `block-http2.sh` attached to this KB.

1. Copy `block-http2.sh` script to `/tmp` directory
2. Run the script using `sh /tmp/block-http2.sh`
3. The script backs up the current apache config, removes h2 protocol and restarts the apache server.

Using a workstation that has **http2** functionality, run the below **towards** HCX Manager to verify http2 protocol is **disabled** on both 443 and 9443 ports. The below curl commands should show curl using HTTP/1.1. Look for using HTTP/1.x string in the output.

```
curl --http2 https://<HCX-Manager-IP>/hybridity/api/endpointInfo  -k -v
curl --http2 https://<HCX-Manager-IP>:9443  -k -v
```
