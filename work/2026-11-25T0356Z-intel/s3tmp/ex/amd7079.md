# Replay Protected Monotonic Counters (RPMC) Increment Suppression Vulnerability

## Summary

Researchers identified a vulnerability in how the AMD Secure Processor handles non-volatile data on systems equipped with RPMC-capable SPI flash. The vulnerability could allow a physically present attacker to suppress RPMC increment commands via an interposer, potentially bypassing rollback protection. While attacks requiring physical access to the system are outside of the AMD product security threat model, RPMC is intended to stop this type of interposer attack and AMD plans to release firmware updates to mitigate this issue.

## Affected Products and Mitigation

Until updated firmware is available, AMD recommends following security best practices, including maintaining physical control of systems and monitoring for signs of physical tampering.

AMD plans to release mitigations on the target dates listed below.
