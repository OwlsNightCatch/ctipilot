# Avis du CERT-FR

Objet : Multiples vulnérabilités dans les produits Cisco

## Gestion du document

Une gestion de version détaillée se trouve à la fin de ce document.

## Risques

- Contournement de la politique de sécurité
- Exécution de code arbitraire à distance
- Non spécifié par l'éditeur

## Systèmes affectés

- AI Canvas
- AppDynamics SaaS
- Business Process Automation (BPA) versions antérieures à 4.1.2, date de publication des correctifs à déterminer
- Business Process Automation (BPA) versions antérieures à 5.0, correctifs prévu pour novembre 2026
- Business Process Automation (BPA) versions antérieures à 5.1, date de publication des correctifs à déterminer
- Catalyst Center (anciennement DNA Center) versions antérieures à 3.4.1, correctifs prévu pour juillet 2027
- CLI Analyzer
- Duo Authentication Proxy Local Manager pour Windows versions antérieures à 6.8.1, correctifs prévu pour novembre 2026
- Duo Network Gateway versions antérieures à 3.4.2
- Intersight Virtual Appliance, correctifs prévu pour novembre 2026
- Intersight, correctifs prévu pour novembre 2026
- Nexus 9000 Series Switches en standalone NX-OS (Guest Shell)
- Packet Tracer versions antérieures à 9.2.0, correctifs prévu pour décembre 2026
- Private 5G versions antérieures à 22.23.4, date de publication des correctifs à déterminer
- Secure Endpoint - Private Cloud Appliance, correctifs prévu pour novembre 2026
- Secure Workload
- Security Cloud Control
- Smart PHY, correctifs prévu pour mars 2027
- Spaces versions antérieures à 24.22.1
- UCS Central Software versions antérieures à 2.1(2c)
- Virtualized Infrastructure Manager
- Webex Connect versions antérieures à 6.22.2, correctifs prévu pour novembre 2026

## Résumé

De multiples vulnérabilités ont été découvertes dans les produits Cisco. Elles permettent à un attaquant de provoquer une exécution de code arbitraire à distance, un contournement de la politique de sécurité et un problème de sécurité non spécifié par l'éditeur.

## Solutions

Se référer au bulletin de sécurité de l'éditeur pour l'obtention des correctifs (cf. section Documentation).
