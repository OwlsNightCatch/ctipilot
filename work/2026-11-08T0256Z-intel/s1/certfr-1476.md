# Avis du CERT-FR

Objet : Multiples vulnérabilités dans les produits Cisco

## Gestion du document

Une gestion de version détaillée se trouve à la fin de ce document.

## Risque

- Exécution de code arbitraire à distance

## Systèmes affectés

- Duo Access Gateway versions antérieures à 3.2.0
- Expressway Select Series versions antérieures à 15.5.21
- Expressway Series versions antérieures à 15.5.21
- Identity Services Engine (ISE) Portal Builder (aucune action utilisateur requise)
- Ultra-Reliable Wireless Backhaul (URWB) versions antérieures à 26.2.1.9, disponibilité prévue pour novembre 2026
- Unified Industrial Wireless versions antérieures à 26.2.1.9, disponibilité prévue pour novembre 2026

## Résumé

De multiples vulnérabilités ont été découvertes dans les produits Cisco. Elles permettent à un attaquant de provoquer une exécution de code arbitraire à distance.

## Solutions

Se référer au bulletin de sécurité de l'éditeur pour l'obtention des correctifs (cf. section Documentation).
