This adds an exploit module for CVE-2026-97229, an integer overflow in the Ruby regular expression compiler which can be triggered via GitLab's CI lint API. Ruby 3.3 is currently GitLab’s standard production runtime and so offsets targeting Ruby 3.3 have been extracted from

`libruby`from CE and EE Linux amd64 Docker builds of all affected GitLab versions.
## Description

An attacker with credentials for a user who can push to a public project plants a crafted CI configuration and repository path. An unauthenticated CI lint request then compiles the expression and executes a command as the GitLab git account. The module selects the native pcode and libruby layout for affected official GitLab CE and EE Docker images on Linux amd64. Each attempt allocates slightly more than 2 GiB and crashes a Puma worker after execution. GitLab 19.2 before 19.2.8, 19.3 before 19.3.5, and 19.4 before 19.4.2 are affected.
