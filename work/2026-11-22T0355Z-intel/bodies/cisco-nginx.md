# Cisco Security Advisory

# Vulnerabilities in nginx Affecting Cisco Products: November 2026

- On November 18, 2026, nginx announced the availability of a fix for multiple critical vulnerabilities in nginx that could lead to remote code execution. These vulnerabilities affect nginx releases 1.9.5 through 1.31.8 and is fixed in releases 1.31.9 (mainline) and 1.30.7 (stable). These vulnerabilities were identified by the following CVEs: 
  - CVE-2026-113425: NGINX ngx\_mail\_proxy\_module vulnerability
  - CVE-2026-121810: NGINX ngx\_http\_v3\_module vulnerability
  - CVE-2026-123007: NGINX ngx\_http\_v2\_module vulnerability
  - CVE-2026-123633: NGINX ngx\_http\_v2\_module vulnerability
  - CVE-2026-123634: NGINX resolver vulnerability
For more information, see the [nginx Security Advisories](https://nginx.org/en/security_advisories.html).
This advisory will be updated as additional information becomes available. This advisory is available at the following link:
[https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-nginx-nov-2026-e8jska2s](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-nginx-nov-2026-e8jska2s)
