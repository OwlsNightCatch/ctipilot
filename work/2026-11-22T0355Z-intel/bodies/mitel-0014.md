# Mitel Product Security Advisory MISA-2026-0014

## OpenJDK Heap-Based Buffer Overflow Vulnerability (java4shell, CVE-2026-114938)

Advisory ID: MISA-2026-0014

First Issue Date: 2026-11-19

Last Updated: 2026-11-19

Revision: 1.0


## **Summary**

In November 2026, a heap-based buffer overflow vulnerability in the OpenJDK and Oracle Java SE Runtime Environment was publicly disclosed.

A heap-based buffer overflow vulnerability, CVE-2026-114938 (java4shell), has been identified in OpenJDK and Oracle Java SE Runtime Environment, which if successfully exploited, could allow an unauthenticated attacker to conduct a remote code execution attack due to improper validation of specially crafted Base64 input. The vulnerability severity is rated as high, based on the assessment provided in the CVE record.

## **Affected Products and Solutions**

Mitel is actively investigating the impact of CVE-2026-114938 on Mitel software and hardware appliances. Mitel will provide updates as more information becomes available.

Mitel is investigating all Mitel operated cloud SaaS services and will apply updates as required.

Product statements are related only to supported product versions. Products which have reached End of Support status are not considered.
