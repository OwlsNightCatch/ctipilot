ServiceNow says it deployed a security update to hosted instances and provided updates to self-hosted customers and partners, and recommends that customers apply the updates or upgrade to a patched release if they have not already done so ([ServiceNow, 2026-07-13](https://support.servicenow.com/kb?id=kb_article_view&sysparm_article=KB3137947)). Its hosted estate is not described as fully remediated: its spokesperson encourages both self-hosted and ServiceNow-hosted customers to apply the relevant patches if they have not already done so ([BleepingComputer, 2026-07-20](https://www.bleepingcomputer.com/news/security/critical-servicenow-code-execution-flaw-now-exploited-in-attacks/)).
