Google's advisory, which OSV aliases to CVE-2026-12537 ([OSV, 2026-04-24](https://api.osv.dev/v1/vulns/GHSA-wpqr-6v78-jr5g)), covers two hardening changes: headless mode no longer trusts the workspace folder automatically, because untrusted contents "could lead to remote code execution via malicious environment variables in the local `.gemini/` directory", and "the Gemini CLI policy engine now evaluates tool allowlisting under --yolo mode" ([Google, 2026-04-24](https://github.com/google-github-actions/run-gemini-cli/security/advisories/GHSA-wpqr-6v78-jr5g)). It does not describe the read of the parent process's environment that the researchers used to reach the runner's secrets ([Novee Security, 2026-08-05](https://novee.security/blog/critical-flaws-in-anthropic-google-and-openais-coding-agents/)).
