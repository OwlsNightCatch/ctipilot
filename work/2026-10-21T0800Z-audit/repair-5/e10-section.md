Arista lists the affected releases by version alone; certificate-based authentication from the VeloCloud Edge to the orchestrator is its "Required Configuration for Exploitation", the condition under which an affected VCO is exposed, not a limit on which releases are affected ([Arista Networks, Security Advisory 0183, 2026-09-22](https://www.arista.com/en/support/advisories-notices/security-advisory/24765-security-advisory-0183)). The flaw Arista reported exploited in July is described only as a different VCO flaw ([The Hacker News, 2026-09-22](https://thehackernews.com/2026/09/new-cvss-100-velocloud-orchestrator.html)); no source says whether the two are related. As of 2026-10-21 the advisory still lists fixed releases only for the 5.2 and 6.4 trains ([Arista Networks, Security Advisory 0183, 2026-09-22](https://www.arista.com/en/support/advisories-notices/security-advisory/24765-security-advisory-0183)).
