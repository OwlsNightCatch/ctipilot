# Update: Sicherheitsupdate für PowerFolder Server — Release Candidate auf Anfrage verfügbar

- **PowerFolder Server (selbst betrieben):** Die Veröffentlichung des Sicherheitsupdates **verzögert sich**, weil die abschließenden Tests noch laufen. Wir veröffentlichen das Update erst, wenn alle Tests bestanden sind.
- **Release Candidate verfügbar:** Ein Release Candidate (RC) mit allen Sicherheitskorrekturen steht bereit. Betreiber, die ihn vorab einsetzen möchten, fordern ihn bitte über [support.powerfolder.com](https://support.powerfolder.com) an.
- **Bis zur Installation gilt weiter:** Sperren Sie alle Anfragen auf `/wopi/` an Ihrem Reverse-Proxy bzw. Ihrer Firewall — auch für Ihren Dokumentenserver. Das Abschalten der Online-Bearbeitung in den Einstellungen schützt nicht. Im Zweifel nehmen Sie den Server vom Netz.
- **PowerFolder Cloud:** Der Wiederanlauf ist weiterhin für **Dienstag, 10. November 2026**, geplant.

#### Was das Sicherheitsupdate enthält

Das Update schließt die beim Angriff ausgenutzten Schwachstellen. Bereits geplante Sicherheitskorrekturen haben wir vorgezogen; zusätzliche Schwachstellen, die wir bei der umfassenden Prüfung unseres Codes gefunden haben, sind ebenfalls geschlossen. Darüber hinaus bringt das Update neue Schutzfunktionen, unter anderem verpflichtende Zwei-Faktor-Anmeldung für Server-Administratoren, kürzere Gültigkeitsdauern für Anmeldetokens und eine Protokollierung von Administrator-Anmeldungen und Konfigurationsänderungen. Details zu den einzelnen Schwachstellen veröffentlichen wir erst, wenn Betreiber genug Zeit zum Aktualisieren hatten.

Den Termin für das finale Sicherheitsupdate geben wir hier und direkt an die Betreiber bekannt.

Fragen bitte über [support.powerfolder.com](https://support.powerfolder.com).
