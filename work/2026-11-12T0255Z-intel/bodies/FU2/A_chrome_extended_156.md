## 
[Extended Stable Update for Desktop](https://chromereleases.googleblog.com/2026/11/extended-stable-update-for-desktop_01570615041.html)

The Extended Stable channel has been updated to 156.0.8078.100 for Windows and Mac which will roll out over the coming days/weeks.

# Security Fixes

Note: Access to bug details and links may be kept restricted until a majority of users are updated with a fix. We will also retain restrictions if the bug exists in a third party library that other projects similarly depend on, but haven’t yet fixed.

This update includes [72](https://issues.chromium.org/issues?q=customfield1223088:5-M156-EXT) security fixes. Please see the [Chrome Security Page](https://www.chromium.org/Home/chromium-security) for more information.
