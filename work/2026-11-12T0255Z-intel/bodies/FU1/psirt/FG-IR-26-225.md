# Improper neutralization of special elements used in a template engine i

## Summary

An Improper Neutralization of Special Elements Used in a Template Engine vulnerability \[CWE-1336\] in FortiManager and FortiManager Cloud may allow a low privileged Device Manager admin to obtain super admin privilege on managed FortiGates via injecting malicious commands.

| Version | Affected | Solution | 
|---|---|---|
| FortiManager 8.0 | 8.0.0 through 8.0.1 | Upgrade to 8.0.2 or above | 
| FortiManager 7.6 | 7.6.0 through 7.6.7 | Upgrade to 7.6.8 or above | 
| FortiManager 7.4 | 7.4.0 through 7.4.11 | Upgrade to 7.4.12 or above | 
| FortiManager 7.2 | 7.2 all versions | Migrate to a fixed release | 
| FortiManager Cloud 8.0 | 8.0.0 through 8.0.1 | Upgrade to 8.0.2 or above | 
| FortiManager Cloud 7.6 | 7.6.0 through 7.6.7 | Upgrade to 7.6.8 or above | 
| FortiManager Cloud 7.4 | 7.4.1 through 7.4.11 | Upgrade to 7.4.12 or above | 
| FortiManager Cloud 7.2 | 7.2 all versions | Migrate to a fixed release |
