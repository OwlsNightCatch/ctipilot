# Unauthenticated adjacent command execution via HA

## Summary

A missing authentication for critical function vulnerability \[CWE-306\] in FortiOS may allow an unauthenticated attacker with HA FGSP + standalone-config-sync, or autoscale to execute command as super admin via crafted HA packets.

| Version | Affected | Solution | 
|---|---|---|
| FortiOS 8.0 | 8.0.0 | Upgrade to 8.0.1 or above | 
| FortiOS 7.6 | 7.6.0 through 7.6.7 | Upgrade to 7.6.8 or above | 
| FortiOS 7.4 | 7.4.0 through 7.4.12 | Upgrade to 7.4.13 or above | 
| FortiOS 7.2 | 7.2.0 through 7.2.13 | Upgrade to 7.2.14 or above | 
| FortiOS 7.0 | 7.0 all versions | Migrate to a fixed release | 

Follow the recommended upgrade path using our tool at:

[https://docs.fortinet.com/upgrade-tool](https://docs.fortinet.com/upgrade-tool)

Virtual Patch named "FG-VD-61445.0day." is available in FMWP db update 26.082
