# Authorization bypass through user-controlled key

## Summary

An Authorization Bypass Through User-Controlled Key vulnerability \[CWE-639\] in FortiMail may allow an authenticated remote attacker to delete arbitrary directories as root, or to access or delete other users' calendar and mailbox data across tenant domains, via crafted HTTP requests to the webmail and administrative interfaces.

| Version | Affected | Solution | 
|---|---|---|
| FortiMail 8.0 | 8.0.0 through 8.0.1 | Upgrade to 8.0.2 or above | 
| FortiMail 7.6 | 7.6.0 through 7.6.6 | Upgrade to 7.6.7 or above | 
| FortiMail 7.4 | 7.4.0 through 7.4.8 | Upgrade to 7.4.9 or above | 
| FortiMail 7.2 | 7.2 all versions | Migrate to a fixed release | 
| FortiMail 7.0 | 7.0 all versions | Migrate to a fixed release |
