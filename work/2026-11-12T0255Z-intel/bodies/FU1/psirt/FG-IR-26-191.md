# Open Redirect on /login

## Summary

A URL redirection to untrusted site ('open redirect') vulnerability \[CWE-601\] in FortiAuthenticator may allow an unauthenticated attacker to perform an open redirect attack via crafted HTTP requests.

| Version | Affected | Solution | 
|---|---|---|
| FortiAuthenticator 8.0 | 8.0.0 through 8.0.3 | Upgrade to 8.0.4 or above | 
| FortiAuthenticator 6.6 | 6.6.0 through 6.6.10 | Upgrade to 6.6.11 or above | 
| FortiAuthenticator 6.5 | 6.5 all versions | Migrate to a fixed release |
