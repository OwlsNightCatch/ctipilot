# Improper certificate validation in RADIUS protocol

## Summary

An Improper Certificate Validation vulnerability \[CWE-295\] in FortiSASE Sovereign, FortiManager, Fortianalyzer, FortiManager Cloud and FortiAnalyzer Cloud RADIUS protocol may allow a MITM attacker to impersonate the radius server via a rogue RADIUS server.
