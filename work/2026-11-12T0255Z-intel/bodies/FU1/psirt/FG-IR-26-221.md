# Improper neutralization of special elements used in an SQL command

## Summary

An improper neutralization of special elements used in an SQL Command ('SQL Injection') vulnerability \[CWE-89\] in FortiAnalyzer, FortiAnalyzer Cloud, FortiManager and FortiManager Cloud may allow an authenticated attacker to execute unauthorized code or commands via crafted JSON-RPC requests.
