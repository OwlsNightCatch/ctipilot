# Use of externally-controlled format string

## Summary

A use of externally-controlled format string vulnerability \[CWE-134\] in FortiAuthenticator may allow an authenticated privileged attacker to execute unauthorized code or commands via http requests.

| Version | Affected | Solution | 
|---|---|---|
| FortiAuthenticator 8.0 | 8.0.0 through 8.0.3 | Upgrade to 8.0.4 or above | 
| FortiAuthenticator 6.6 | 6.6.0 through 6.6.10 | Upgrade to 6.6.11 or above |
