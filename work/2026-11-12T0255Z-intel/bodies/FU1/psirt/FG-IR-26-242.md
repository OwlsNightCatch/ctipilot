# Unintended proxy or intermediary in GUI

## Summary

An unintended Proxy or Intermediary ('Confused Deputy') vulnerability \[CWE-441\] in FortiAnalyzer, FortiManager, FortiAnalyzer Cloud, FortiManager Cloud GUI may allow an authenticated attacker to execute commands outside of the intended scope via specially crafted HTTP request

| Version | Affected | Solution | 
|---|---|---|

| FortiAnalyzer 7.6 | 7.6.0 through 7.6.7 | Upgrade to 7.6.8 or above | 
| FortiAnalyzer 7.4 | 7.4.0 through 7.4.11 | Upgrade to 7.4.12 or above | 
| FortiAnalyzer 7.2 | 7.2.0 through 7.2.12 | Upgrade to 7.2.13 or above | 
| FortiAnalyzer Cloud 8.0 | 8.0.1 | Upgrade to 8.0.2 or above | 
| FortiAnalyzer Cloud 7.6 | 7.6.0 through 7.6.7 | Upgrade to 7.6.8 or above |

| FortiAnalyzer Cloud 7.2 | 7.2.1 through 7.2.12 | Upgrade to 7.2.13 or above |

| FortiManager 7.6 | 7.6.0 through 7.6.7 | Upgrade to 7.6.8 or above |

The vulnerability can be exploited via the JSON API if enabled (Disabled by default)

If enabled on a profile, it can be disabled it via the following configuration to reduce the attack surface:

```
config system admin profile
  edit <profile name>
    set rpc-permit none
end
```
