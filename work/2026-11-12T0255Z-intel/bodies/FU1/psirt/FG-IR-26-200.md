# Improper neutralization of special elements used in an os command

## Summary

An Improper neutralization of special elements used in a command ('command injection') \[CWE-77\] in FortiMail may allow an unauthenticated attacker to execute unauthorized code or commands via crafted HA join-request packets.

| Version | Affected | Solution | 
|---|---|---|
| FortiMail 8.0 | 8.0.0 through 8.0.1 | Upgrade to 8.0.2 or above | 
| FortiMail 7.6 | 7.6.0 through 7.6.6 | Upgrade to 7.6.7 or above | 
| FortiMail 7.4 | Not affected | Not Applicable | 
| FortiMail 7.2 | Not affected | Not Applicable | 

Please note that Fortinet has remediated this issue on Oct 05, 2026 in FortiMail Cloud by updating all the firmwares to v7.6.7 GA or v8.0.2 GA, hence the FortiMail Cloud customers need not perform any action.
