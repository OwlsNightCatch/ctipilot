# Improper neutralization of special elements used in an OS command in webmail

## Summary

An improper neutralization of special elements used in an OS Command ('OS Command Injection') vulnerability \[CWE-78\] in FortiMail, FortiRecorder and FortiVoice may allow an authenticated attacker to execute unauthorized code or commands via specifically crafted HTTP requests.

| Version | Affected | Solution | 
|---|---|---|
| FortiMail 8.0 | 8.0.0 through 8.0.1 | Upgrade to 8.0.2 or above | 
| FortiMail 7.6 | 7.6.0 through 7.6.4 | Upgrade to 7.6.5 or above | 
| FortiMail 7.4 | 7.4.0 through 7.4.6 | Upgrade to 7.4.7 or above | 
| FortiMail 7.2 | 7.2 all versions | Migrate to a fixed release | 
| FortiRecorder 7.6 | 7.6.0 through 7.6.2 | Upgrade to upcoming 7.6.3 or above | 
| FortiRecorder 7.2 | 7.2.0 through 7.2.12 | Upgrade to upcoming 7.2.13 or above | 
| FortiRecorder 7.0 | 7.0.0 through 7.0.6 | Upgrade to upcoming 7.0.7 or above | 
| FortiVoice 8.0 | 8.0.0 through 8.0.1 | Upgrade to upcoming 8.0.2 or above | 
| FortiVoice 7.4 | 7.4.0 through 7.4.2 | Upgrade to upcoming 7.4.3 or above | 
| FortiVoice 7.2 | 7.2.0 through 7.2.5 | Upgrade to upcoming 7.2.6 or above | 
| FortiVoice 7.0 | 7.0.0 through 7.0.8 | Upgrade to upcoming 7.0.9 or above |
