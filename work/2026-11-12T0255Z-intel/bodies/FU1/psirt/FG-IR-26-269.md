# Improper neutralization of special elements in output used by a downstream component in sshd

## Summary

A Path Traversal vulnerability \[cwe-24\] in FortiOS, FortiSASE, FortiProxy and FortiPam ssh daemon may allow an unauthenticated attacker to bypass authentication via specially crafted credentials.
