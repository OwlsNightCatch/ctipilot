# Improper neutralization of special elements used in an os command in GUI

## Summary

An Improper Neutralization of Special Elements used in an OS Command ('OS Command Injection') vulnerability \[cwe-78\] in FortiManager, FortiAnalyzer, FortiManager Cloud, FortiAnalyzer Cloud, FortiSASE-Sovereign GUI may allow an authenticated attacker to execute unauthorized code or commands via specially crafted HTTP requests
