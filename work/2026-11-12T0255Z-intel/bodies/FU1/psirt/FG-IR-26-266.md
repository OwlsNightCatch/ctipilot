# Improper neutralization of special elements used in an SQL command in collectoragent

## Summary

An improper neutralization of special elements used in an sql command ('sql injection')\[CWE-89\] vulnerability may allow an authenticated attacker to execute unauthorized code or commands via http requests

| Version | Affected | Solution | 
|---|---|---|
| FortiAuthenticator 8.0 | 8.0.0 through 8.0.3 | Upgrade to 8.0.4 or above | 
| FortiAuthenticator 6.6 | 6.6.0 through 6.6.10 | Upgrade to 6.6.11 or above |
