# Pre-auth SSRF

## Summary

A server-side request forgery (SSRF) vulnerability \[CWE-918\] in FortiAnalyzer, FortiManager with FortiAnalyzer features, may allow an attacker that can reach the oftp port to execute requests server side via crafted OFTP packets.

| Version | Affected | Solution | 
|---|---|---|
| FortiAnalyzer 8.0 | 8.0.0 | Upgrade to 8.0.1 or above | 
| FortiAnalyzer 7.6 | 7.6.0 through 7.6.7 | Upgrade to 7.6.8 or above | 
| FortiAnalyzer 7.4 | 7.4.0 through 7.4.11 | Upgrade to 7.4.12 or above | 
| FortiAnalyzer 7.2 | Not affected | Not Applicable | 
| FortiManager 8.0 | 8.0.0 | Upgrade to 8.0.1 or above | 
| FortiManager 7.6 | 7.6.0 through 7.6.7 | Upgrade to 7.6.8 or above | 
| FortiManager 7.4 | 7.4.0 through 7.4.11 | Upgrade to 7.4.12 or above | 
| FortiManager 7.2 | Not affected | Not Applicable |
