# FGFM elevation before registration password is verified

## Summary

An improper authorization vulnerability in FortiManager FGFM may allow an unauthenticated attacker that can reach the FGFM port to execute code or commands via crafted FGFM packets.

| Version | Affected | Solution | 
|---|---|---|
| FortiManager 8.0 | 8.0.0 | Upgrade to 8.0.1 or above | 
| FortiManager 7.6 | 7.6.0 through 7.6.7 | Upgrade to 7.6.8 or above | 
| FortiManager 7.4 | 7.4.0 through 7.4.5 | Upgrade to 7.4.6 or above | 
| FortiManager 7.2 | 7.2.0 through 7.2.8 | Upgrade to 7.2.9 or above |
