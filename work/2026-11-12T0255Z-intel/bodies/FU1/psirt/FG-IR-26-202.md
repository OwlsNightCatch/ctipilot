# Weak password recovery mechanism for forgotten password

## Summary

A Missing Authentication for Critical Function vulnerability \[CWE-306\] in FortiMail may allow an unauthenticated attacker to reset the password of an arbitrary IBE webmail user and take over their account via specially crafted HTTP requests.

| Version | Affected | Solution | 
|---|---|---|
| FortiMail 8.0 | 8.0.0 | Upgrade to 8.0.1 or above | 
| FortiMail 7.6 | 7.6.0 through 7.6.5 | Upgrade to 7.6.6 or above | 
| FortiMail 7.4 | 7.4.0 through 7.4.7 | Upgrade to 7.4.8 or above | 
| FortiMail 7.2 | 7.2.0 through 7.2.9 | Upgrade to upcoming 7.2.10 or above | 

Please note that Fortinet has remediated this issue on oct 05, 2026 in FortiMail Cloud , hence the FortiMail Cloud customers need not perform any action.
