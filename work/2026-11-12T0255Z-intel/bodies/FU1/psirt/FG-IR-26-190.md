# Arbitrary file write and delete in JSON API

## Summary

An improper limitation of a pathname to a restricted directory ('Path Traversal') vulnerability \[CWE-22\] in FortiManager and FortiAnalyzer API may allow an authenticated attacker whose profile only has read permission to write and delete files from the underlying filesystem via crafted HTTP or HTTPs requests.

| Version | Affected | Solution | 
|---|---|---|
| FortiAnalyzer 8.0 | Not affected | Not Applicable | 
| FortiAnalyzer 7.6 | 7.6.0 through 7.6.4 | Upgrade to 7.6.5 or above | 
| FortiAnalyzer 7.4 | 7.4.0 through 7.4.7 | Upgrade to 7.4.8 or above | 
| FortiAnalyzer 7.2 | 7.2.0 through 7.2.11 | Upgrade to 7.2.12 or above | 
| FortiManager 8.0 | Not affected | Not Applicable |
