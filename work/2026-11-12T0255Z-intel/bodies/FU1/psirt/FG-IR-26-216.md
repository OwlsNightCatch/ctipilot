# Improper neutralization of special elements used in an SQL command

## Summary

An Improper neutralization of special elements used in an SQL command ('SQL injection') \[CWE-89\] in FortiMail may allow an unauthenticated attacker to execute unauthorized code or commands via crafted requests.

| Version | Affected | Solution | 
|---|---|---|
| FortiMail 8.0 | 8.0.0 through 8.0.1 | Upgrade to 8.0.2 or above | 
| FortiMail 7.6 | 7.6.0 through 7.6.6 | Upgrade to 7.6.7 or above | 
| FortiMail 7.4 | 7.4.0 through 7.4.8 | Upgrade to 7.4.9 or above | 
| FortiMail 7.2 | 7.2 all versions | Migrate to a fixed release | 

Please note that Fortinet has remediated this issue on Oct 05, 2026 in FortiMail Cloud, hence the FortiMail Cloud customers need not perform any action.
