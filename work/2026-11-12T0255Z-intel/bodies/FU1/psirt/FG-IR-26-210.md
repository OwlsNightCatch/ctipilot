# Improper neutralization of special elements used in an os command

## Summary

An Improper Neutralization of Special Elements used in an OS Command ('OS Command Injection') vulnerability \[CWE-78\] in FortiMail may allow an authenticated administrator to execute unauthorized code or commands as root via specially crafted HTTP requests.

| Version | Affected | Solution | 
|---|---|---|
| FortiMail 8.0 | 8.0.0 through 8.0.1 | Upgrade to 8.0.2 or above | 
| FortiMail 7.6 | Not affected | Not Applicable | 
| FortiMail 7.4 | Not affected | Not Applicable |
