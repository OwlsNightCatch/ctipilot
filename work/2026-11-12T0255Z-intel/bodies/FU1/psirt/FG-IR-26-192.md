# Multiple privilege escalations via CLI

## Summary

Multiple Execution with Unnecessary Privileges vulnerabilities \[CWE-250\] in FortiClient EMS may allow an authenticated local attacker with admin privileges to gain root shell access via CLI commands.

| Version | Affected | Solution | 
|---|---|---|
| FortiClientEMS 8.0 | Not affected | Not Applicable | 
| FortiClientEMS 7.4 | 7.4.3 through 7.4.7 | Upgrade to 7.4.8 or above | 
| FortiClientEMS 7.4 | 7.4.0 through 7.4.1 | Upgrade to 7.4.8 or above | 
| FortiClientEMS 7.2 | 7.2 all versions | Migrate to a fixed release | 

Fortinet remediated this issue in FortiClient Cloud and hence customers do not need to perform any action.
