# XML injection

## Summary

An XML Injection (aka Blind XPath Injection) vulnerability \[CWE-91\] in FortiAnalyzer, FortiAnalyzer Cloud, FortiManager, FortiManager Cloud may allow an unauthenticated remote attacker to inject arbitary content into a signed SAML response via crafted SAML requests.
