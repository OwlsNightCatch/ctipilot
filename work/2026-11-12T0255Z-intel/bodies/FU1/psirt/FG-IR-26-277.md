# SQL Injection

## Summary

An Improper Neutralization of Special Elements used in an SQL Command ('SQL Injection') vulnerability \[CWE-89\] in FortiMail may allow an authenticated attacker to execute unauthorized code or commands via specifically crafted requests.

| Version | Affected | Solution | 
|---|---|---|
| FortiMail 8.0 | 8.0.0 through 8.0.1 | Upgrade to 8.0.2 or above | 
| FortiMail 7.6 | 7.6.0 through 7.6.4 | Upgrade to 7.6.7 or above | 
| FortiMail 7.4 | 7.4.0 through 7.4.6 | Upgrade to 7.4.7 or above | 

Please note that Fortinet has remediated this issue in FortiMail Cloud by updating all the firmwares to 7.6.7 GA or 8.0.2 GA, hence the FortiMail Cloud customers need not perform any action.
