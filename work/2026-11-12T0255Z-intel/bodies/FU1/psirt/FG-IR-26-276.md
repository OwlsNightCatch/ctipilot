# SQL injection

## Summary

An Improper Neutralization of Special Elements used in an SQL Command ('SQL Injection') vunerability \[CWE-89\] in FortiAnalyzer or FortiManager with FortiAnalyzer features may allow an unauthenticated attacker who has access to the oftp port to execute code or command on the system via crafted OFTP packets.

| Version | Affected | Solution | 
|---|---|---|
| FortiAnalyzer 8.0 | 8.0.0 through 8.0.1 | Upgrade to 8.0.2 or above | 
| FortiAnalyzer 7.6 | 7.6.0 through 7.6.7 | Upgrade to 7.6.8 or above | 
| FortiAnalyzer 7.4 | 7.4.0 through 7.4.11 | Upgrade to 7.4.12 or above | 
| FortiAnalyzer 7.2 | 7.2.0 through 7.2.12 | Upgrade to 7.2.13 or above |
