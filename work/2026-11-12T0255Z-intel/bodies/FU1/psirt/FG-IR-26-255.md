# Improper neutralization of special elements used in an ldap query

## Summary

An Improper Neutralization of Special Elements used in an LDAP Query ('LDAP Injection')\[CWE-90\] in FortiAuthenticator may allow an authenticated attacker to bypass authentication. Successful exploitation requires either a malicious/compromised upstream IdP, or an IdP configuration that allows the user to control the NameID (or the SAML attribute used as the username).

| Version | Affected | Solution | 
|---|---|---|
| FortiAuthenticator 8.0 | 8.0.0 through 8.0.3 | Upgrade to 8.0.4 or above | 
| FortiAuthenticator 6.6 | 6.6.0 through 6.6.10 | Upgrade to 6.6.11 or above |
