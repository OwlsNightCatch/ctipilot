# Authorization bypass through user-controlled key in GUI

## Summary

An Authorization Bypass Through User-Controlled Key vulnerability \[cwe-639\] in FortiManager, FortiManager Cloud and FortiSase-Sovereign GUI may allow an authenticated attacker to execute commands outside of the expected scope via specially crafted HTTP request.

| Version | Affected | Solution | 
|---|---|---|
| FortiManager 8.0 | 8.0.0 through 8.0.1 | Upgrade to 8.0.2 or above | 
| FortiManager 7.6 | 7.6.0 through 7.6.7 | Upgrade to 7.6.8 or above | 
| FortiManager 7.4 | 7.4.0 through 7.4.11 | Upgrade to 7.4.12 or above | 
| FortiManager 7.2 | 7.2.0 through 7.2.12 | Upgrade to 7.2.13 or above | 
| FortiManager Cloud 8.0 | 8.0.1 | Upgrade to 8.0.2 or above | 
| FortiManager Cloud 7.6 | 7.6.0 through 7.6.7 | Upgrade to 7.6.8 or above | 
| FortiManager Cloud 7.4 | 7.4.1 through 7.4.11 | Upgrade to upcoming 7.4.13 or above | 
| FortiManager Cloud 7.2 | 7.2.1 through 7.2.12 | Migrate to a fixed release | 
| FortiSASE-Sovereign 26.2 | 26.2 all versions | Fortinet remediated this issue in 26.2 (not released) and hence customers do not need to perform any action. | 
| FortiSASE-Sovereign 25.4 | 25.4 all versions | Migrate to a fixed release | 
| FortiSASE-Sovereign 25.3 | 25.3 all versions | Migrate to a fixed release | 
| FortiSASE-Sovereign 25 | 25 all versions | Migrate to a fixed release | 

The vulnerability impacts the JSON API if enabled (Disabled by default)

If enabled on a profile, it can be disabled it via the following configuration:

```
config system admin profile
  edit <profile name>
    set rpc-permit none
end
```
