# Use of externally-controlled format string

## Summary

A Use of Externally-Controlled Format String \[CWE-134\] in FortiMail may allow a remote unauthenticated attacker to execute unauthorized code or commands via a specially crafted SMTP command.

| Version | Affected | Solution | 
|---|---|---|
| FortiMail 8.0 | 8.0.0 through 8.0.1 | Upgrade to 8.0.2 or above | 
| FortiMail 7.6 | Not affected | Not Applicable | 
| FortiMail 7.4 | Not affected | Not Applicable | 

Please note that Fortinet has remediated this issue on Oct 05, 2026 in FortiMail Cloud by updating all the firmwares to v7.6.7 GA or v8.0.2 GA, hence the FortiMail Cloud customers need not perform any action.
