# Origin validation error in local API endpoint

## Summary

An origin validation error vulnerability \[CWE-346\] in FortiClient Mac, FortiClient Windows, and FortiClient Windows PAM may allow an unauthorized remote attacker to execute unauthorized code or commands. Successful exploitation requires interaction with the victim.

| Version | Affected | Solution | 
|---|---|---|
| FortiClientMac 8.0 | Not affected | Not Applicable | 
| FortiClientMac 7.4 | 7.4.0 through 7.4.7 | Upgrade to 7.4.8 or above | 
| FortiClientMac 7.2 | Not affected | Not Applicable | 
| FortiClientWindows 8.0 | Not affected | Not Applicable | 
| FortiClientWindows 7.4 | 7.4.0 through 7.4.7 | Upgrade to 7.4.8 or above | 
| FortiClientWindows 7.2 | 7.2.0 through 7.2.14 | Upgrade to 7.2.15 or above | 
| FortiClientWindowsPAM 8.0 | Not affected | Not Applicable | 
| FortiClientWindowsPAM 7.4 | 7.4.0 through 7.4.7 | Upgrade to 7.4.8 or above | 
| FortiClientWindowsPAM 7.2 | 7.2.0 through 7.2.14 | Upgrade to 7.2.15 or above | 

FortiClient Windows Free VPN is not impacted.
