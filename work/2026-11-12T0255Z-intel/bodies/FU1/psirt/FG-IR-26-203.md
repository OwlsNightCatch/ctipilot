# Incorrect implementation of authentication algorithm in fortiweb2

## Summary

An Incorrect Implementation of Authentication Algorithm vulnerability (CWE-303) in FortiWeb may allow an unauthenticated remote attacker to gain elevation of privilege (account takeover) via a crafted request.

| Version | Affected | Solution | 
|---|---|---|
| FortiMail 8.0 | 8.0.0 through 8.0.1 | Upgrade to 8.0.2 or above | 
| FortiMail 7.6 | 7.6.0 through 7.6.6 | Upgrade to 7.6.7 or above | 
| FortiMail 7.4 | 7.4.0 through 7.4.8 | Upgrade to 7.4.9 or above | 
| FortiMail 7.2 | 7.2 all versions | Migrate to a fixed release | 

Please note that Fortinet has remediated this issue on Oct 05, 2026 in FortiMail Cloud by updating all the firmwares to v7.6.7 GA or v8.0.2 GA, hence the FortiMail Cloud customers need not perform any action.
