# Use of hard-coded credentials

## Summary

A Use of Hard-coded Credentials vulnerability \[CWE-798\] in FortiManager cloud orchestration may allow an adjacent-network authenticated attacker with user permission to join the FGFM configuration-sync mesh of the affected FortiGate deployment via the default pre-shared key.

| Version | Affected | Solution | 
|---|---|---|
| FortiManager 8.0 | 8.0.0 through 8.0.1 | Upgrade to 8.0.2 or above | 
| FortiManager 7.6 | 7.6.0 through 7.6.7 | Upgrade to 7.6.8 or above | 
| FortiManager 7.4 | 7.4.0 through 7.4.11 | Upgrade to 7.4.12 or above | 
| FortiManager 7.2 | 7.2 all versions | Migrate to a fixed release |
