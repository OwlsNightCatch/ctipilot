# Broken Access Control in Two-Factor-Authentication

## Summary

An Improper Authentication vulnerability \[CWE-287\] in the FortiOS Remote Radius Type Admin Two-Factor (TFA) Authentication may allow a remote authenticated attacker with at least read-only permission to log in to the FortiOS GUI with an invalid token after entering a valid username and password, in scenarios where the RADIUS server returns an additional "Access-Challenge" response following an invalid TFA token.

| Version | Affected | Solution | 
|---|---|---|
| FortiOS 8.0 | Not affected | Not Applicable | 
| FortiOS 7.6 | 7.6.0 through 7.6.6 | Upgrade to 7.6.7 or above | 
| FortiOS 7.4 | Not affected | Not Applicable | 
| FortiOS 7.2 | Not affected | Not Applicable | 

Follow the recommended upgrade path using our tool at:

[https://docs.fortinet.com/upgrade-tool](https://docs.fortinet.com/upgrade-tool)

### Workaround

Remove the Remote Radius Type Admin account linked to the RADIUS server that responds with an additional "Access-Challenge" message when the user fails to enter a valid two-factor authentication token.

In the GUI: 

Navigate to System > Administrators and delete the Remote Radius Type administrator accounts.

In the CLI:  

config system admin

delete \< Remote type administrator account >
