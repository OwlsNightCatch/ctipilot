# Improper neutralization of special elements used in an OS command

## Summary

An improper Neutralization of Special Elements used in an OS Command ('OS Command Injection') vulnerability (CWE-78) in FortiAnalyzer, FortiAnalyzer Cloud, FortiManager, FortiManager Cloud system-ha plugin may allow an authenticated attacker to execute unauthorized commands via a crafted HTTP request.

| FortiAnalyzer 7.4 | 7.4.0 through 7.4.11 | Upgrade to 7.4.12 or above |
