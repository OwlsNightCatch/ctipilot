# Improper neutralization of special elements used in a command

## Summary

An Improper Neutralization of Argument Delimiters in a Command ('Argument Injection') \[CWE-88\] in FortiMail may allow an authenticated remote attacker with domain admin or admin privileges to delete users of other tenant domains on a paired FortiAuthenticator, execute arbitrary code as root or arbitrary CLI commands, and read or write arbitrary files as root via crafted HTTP requests to the administrative interface.

| Version | Affected | Solution | 
|---|---|---|
| FortiMail 8.0 | 8.0.0 through 8.0.2 | Upgrade to upcoming 8.0.3 or above | 
| FortiMail 7.6 | 7.6.0 through 7.6.6 | Upgrade to 7.6.7 or above | 
| FortiMail 7.4 | 7.4.0 through 7.4.8 | Upgrade to 7.4.9 or above | 
| FortiMail 7.2 | 7.2 all versions | Migrate to a fixed release | 

Please note that Fortinet has remediated this issue on oct 05, 2026 in FortiMail Cloud by updating all the firmwares to v7.6.7 GA or v8.0.2 GA, hence the FortiMail Cloud customers need not perform any action.
