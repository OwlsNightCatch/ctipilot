# SSLVPN Improper Certificate Validation

## Summary

An improper certificate validation vulnerability \[CWE-295\] in FortiOS SSLVPN may allow a remote and unauthenticated attacker to perform a Man-in-the-Middle attack on the communication channel between the SSLVPN web portal and the backend destination website.

| Version | Affected | Solution | 
|---|---|---|
| FortiOS 8.0 | Not affected | Not Applicable | 
| FortiOS 7.6 | 7.6.0 through 7.6.4 | Upgrade to 7.6.5 or above | 
| FortiOS 7.4 | 7.4.0 through 7.4.9 | Upgrade to 7.4.10 or above | 
| FortiOS 7.2 | 7.2.0 through 7.2.13 | Upgrade to 7.2.14 or above | 
| FortiOS 7.0 | 7.0 all versions | Migrate to a fixed release | 
| FortiOS 6.4 | 6.4 all versions | Migrate to a fixed release | 

Follow the recommended upgrade path using our tool at:

[https://docs.fortinet.com/upgrade-tool](https://docs.fortinet.com/upgrade-tool)

In the fixed FortiOS versions, the following configuration option is available:

config vpn ssl setting

set remote-https-cert-check 

end

The default behavior is warn-on-error. With reject-on-error, where there is certificate check error, a rejecting page would be presented, and the user's only option is to close the connection.
