# Improper neutralization of special elements used in an SQL command

## Summary

An Improper Neutralization of Special Elements used in an SQL Command ('SQL Injection')\[CWE-89\] in FortiAuthenticator may allow an authenticated attacker to execute unauthorized SQL commands on the underlying database.

| Version | Affected | Solution | 
|---|---|---|
| FortiAuthenticator 8.0 | 8.0.0 through 8.0.3 | Upgrade to 8.0.4 or above | 
| FortiAuthenticator 6.6 | 6.6.0 through 6.6.10 | Upgrade to 6.6.11 or above | 
| FortiAuthenticator 6.5 | 6.5.2 through 6.5.7 | Migrate to a fixed release |
