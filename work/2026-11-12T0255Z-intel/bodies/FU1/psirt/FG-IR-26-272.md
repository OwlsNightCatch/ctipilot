# Stack buffer overflow in wad

## Summary

A stack-based buffer overflow vulnerability \[CWE-121\] in Fortinet FortiOS WAD proxy may allow an unauthenticated attacker with wad port access to crash proxy or ZTNA sessions via crafted HTTP or HTTPS requests.

| Version | Affected | Solution | 
|---|---|---|
| FortiOS 8.0 | 8.0.0 | Upgrade to 8.0.1 or above | 
| FortiOS 7.6 | 7.6.7 | Upgrade to 7.6.8 or above | 
| FortiOS 7.4 | Not affected | Not Applicable | 
| FortiOS 7.2 | Not affected | Not Applicable | 

Follow the recommended upgrade path using our tool at:

[https://docs.fortinet.com/upgrade-tool](https://docs.fortinet.com/upgrade-tool)
