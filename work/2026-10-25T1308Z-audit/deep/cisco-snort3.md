# Multiple Cisco Products Snort 3 Security Hardening Release: October 2026

[Base 9.0](https://sec.cloudapps.cisco.com/security/center/cvssCalculator.x?version=3.1&vector=CVSS:3.1/AV:N/AC:H/PR:N/UI:N/S:C/C:H/I:H/A:H)

- As part of Cisco's ongoing commitment to proactive security and product quality, the Cisco owned Open Source Snort 3 Software engineering team has conducted a comprehensive internal security review. This review resulted in software hardening releases that address multiple internally discovered vulnerabilities. The vulnerabilities tracked by CVE-2026-20043 are related to issues concerning out-of-bounds writes that are grouped under the Common Weakness Enumeration (CWE) Base CWE-787. As part of Cisco's ongoing commitment to proactive security and product quality, the Cisco-owned Open Source Snort 3 engineering team has conducted a comprehensive internal security review. This review resulted in software hardening releases that address multiple internally discovered vulnerabilities. These vulnerabilities were found during internal testing and are not known to be actively exploited. To assist customers in patching and to streamline the disclosure process, Cisco has grouped these issues by their underlying vulnerability class - Common Weakness Enumeration (CWE) - and assigned a single Common Vulnerabilities and Exposures Identifier (CVE ID) to each CWE grouping. **Note:** Cisco may publish separate security advisories that provide additional details about individual vulnerabilities that are addressed in this release.
Cisco has released software updates that address these vulnerabilities. There are no workarounds that address these vulnerabilities. This advisory is available at the following link:
[https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-hardening-snort3-ybgmhTQe](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-hardening-snort3-ybgmhTQe)
This advisory is part of a group of advisories. For a complete list of the advisories and links to them, see [Cisco Advance Notification for Publication of October 21, 2026, Security Advisories](https://sec.cloudapps.cisco.com/security/center/content/CiscoSecurityAdvisory/cisco-sa-notice-QGwHnJ6k).

- ## Vulnerable Products These vulnerabilities affect the following products, regardless of device configuration: 
  - Cisco Cloud-delivered Firewall (CDFW)
  - Cisco Cyber Vision
  - Cisco Meraki MX Security Appliances
  - Cisco Secure Access (CSA)
  - Cisco Secure Firewall Threat Defense (FTD) Software
  - Open Source Snort 3
  - Unified Threat Defense (UTD) on Cisco IOS XE Software
For information about which Cisco software releases are vulnerable, see the [Fixed Software](https://sec.cloudapps.cisco.com#fs) section of this advisory.
## Products Confirmed Not Vulnerable Only products listed in the [Vulnerable Products](https://sec.cloudapps.cisco.com#vp) section of this advisory are known to be affected by these vulnerabilities.
Cisco has confirmed that these vulnerabilities do not affect Open Source Snort 2. **Note:** Open Source Snort 2 has reached End of Life. For more information, see [End of Life Announcement for Open Source Snort 2](https://blog.snort.org/2026/10/end-of-life-announcement-for-open.html).

- There are no workarounds that address these vulnerabilities.
