## QNAP Statement on Critical PHP Vulnerabilities (PHP2Shell): Assessment and Mitigation Guidance

**Taipei, Taiwan, October 22, 2026 –** QNAP® Systems, Inc., a leading innovator in storage, networking, and data protection solutions, today issued an official statement on PHP2Shell, a set of critical PHP vulnerabilities with global impact. QNAP immediately activated its security incident response, is closely tracking the impact of the vulnerabilities, and has put protective measures in place to safeguard user data.

**Immediate Response by QNAP PSIRT**

The QNAP Product Security Incident Response Team (QNAP PSIRT) launched a cross-functional response to two critical vulnerabilities in PHP’s core engine, CVE-2026-109618 and CVE-2026-109619 (collectively known as “PHP2Shell,” CVSS v4.0 score: 9.2), which the PHP project patched on October 21, 2026. The team is conducting a comprehensive review of all QNAP products and cloud services. The vulnerabilities allow unauthenticated attackers to execute code remotely and affect a large number of PHP-based web servers worldwide.

QNAP PSIRT has observed scanning activity and exploitation attempts targeting these vulnerabilities in the wild. It is monitoring this activity around the clock and remains in close contact with the global security community and the PHP project, ensuring that QNAP’s defenses adapt in real time as the threat landscape evolves.

**Protections in Place to Keep User Data Secure**

QNAP has deployed multiple layers of protection for user data. QNAP PSIRT detected and successfully blocked attempted attacks against QNAP’s official website and online store, as well as its cloud services. The team promptly completed a comprehensive assessment and deployed targeted protections, ensuring that online transactions, users’ personal data, and website operations remain fully secured. QNAP has found no evidence that any user data held on QNAP’s online services has been accessed or exposed as a result of these vulnerabilities. Users can rest assured that their data remains safe.

Security is QNAP’s foremost commitment to its users, and the company meets every security challenge with proactive disclosure, rapid remediation, and transparent communication, ensuring that user data always receives the strongest possible protection.

Read the QNAP Security Advisory: [Vulnerabilities in PHP (PHP2Shell) Affecting Multiple QNAP Products](https://www.qnap.com/go/security-advisory/qsa-26-18)

**Ongoing Updates and Contact Information**

QNAP will continue to monitor the vulnerabilities and related threat activity, and will publish the latest information and remediation progress on its official Security Advisories page.

- **Technical Support:** If you have any questions or notice any unusual system behavior, please contact the [QNAP Technical Support team](https://service.qnap.com/) immediately.
- **Vulnerability Reporting:** Security researchers can report related issues through the [QNAP Security Bounty Program](https://www.qnap.com/go/security-bounty-program).

QNAP has always placed the security of user data first. As security threats evolve worldwide, QNAP will continue to uphold the highest standards in protecting its users and will stand with them through every challenge.
