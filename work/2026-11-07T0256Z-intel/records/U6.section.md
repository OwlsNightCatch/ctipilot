Microsoft Threat Intelligence reports that Storm-3358, a Cambodia-based intrusion cluster that primarily targets financial organisations in Southeast Asia and a smaller number of large financial organisations globally, began using ARTEX against the financial sector in October 2026 ([Microsoft, 2026-11-06](https://www.microsoft.com/en-us/security/blog/2026/11/06/artex-abuse-expands-as-cybercriminals-target-financial-sector/)). Microsoft says the cluster combines ARTEX with conventional automated tools to scan internet-facing systems, exploit flaws including anonymous file upload and server-side request forgery, and install the open-source remote access tools WISP, vshell and AdaptixC2, which ARTEX agents download with netcat and curl ([Microsoft, 2026-11-06](https://www.microsoft.com/en-us/security/blog/2026/11/06/artex-abuse-expands-as-cybercriminals-target-financial-sector/)). Microsoft's tell for an agent on a scanned system is "a wide variety of requests in a brief time", retries of variations on one technique and a move to next-stage actions at machine speed; ARTEX by default drives Nmap, curl, wget, Python HTTP clients and headless Chromium through Playwright, and blocking their default traits will not stop an agent, which "will quickly change them" ([Microsoft, 2026-11-06](https://www.microsoft.com/en-us/security/blog/2026/11/06/artex-abuse-expands-as-cybercriminals-target-financial-sector/)). In Microsoft's testing, tarpits and decoys that present convincing evidence of success reduced the attack traffic reaching real assets, with no figures given ([Microsoft, 2026-11-06](https://www.microsoft.com/en-us/security/blog/2026/11/06/artex-abuse-expands-as-cybercriminals-target-financial-sector/)).

Check Point Research counts 2,557 systems that host or hosted ARTEX panels, 1,608 of them live and public, and ten that exposed the full database; in those ten consoles the operators set a goal and then "barely interacted with their agent fleets" ([Check Point, 2026-11-05](https://research.checkpoint.com/2026/hacking-on-autopilot-inside-artex-cybercrime-campaigns/)). The campaigns it reads are opportunistic crime, not espionage: iOS signing certificates from grey-market shops, a cryptocurrency-service campaign and game-account credentials. The agents got in through hardcoded administrator passwords in JavaScript bundles, missing API authentication, command injection, insecure direct object references, weak administrative credentials and template injection ([Check Point, 2026-11-05](https://research.checkpoint.com/2026/hacking-on-autopilot-inside-artex-cybercrime-campaigns/)). Check Point does not name Storm-3358.
