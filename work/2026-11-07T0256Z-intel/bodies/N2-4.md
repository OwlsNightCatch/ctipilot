# Mitel Product Security Advisory MISA-2026-0010

## Brotli Decoder Out-of-bounds Write Vulnerability (node2shell, CVE-2026-111497)

Advisory ID: MISA-2026-0010

First Issue Date: 2026-10-28

Last Updated: 2026-11-04

Revision: 5.0


## **Summary**

In October 2026, an out-of-bounds write vulnerability in the Google Brotli decoder library was publicly disclosed. 


An Out-of-bounds Write Vulnerability, CVE-2026-111497, has been identified in the Google Brotli decoder library, which if successfully exploited, could allow an unauthenticated attacker to conduct a denial-of-service attack and potentially disclose sensitive information or execute arbitrary code due to improper handling of malformed compressed data. The vulnerability severity is rated as high (CVSS 3.1), based on the publicly available information regarding the vulnerability and its potential impact.

## **Affected Products and Solutions**

Mitel is actively investigating the impact of CVE-2026-111497 on Mitel software and hardware appliances. Mitel will provide updates as more information becomes available. 


Mitel is investigating all Mitel operated cloud SaaS services and will apply updates as required. Specifically, Unify Phone and CloudLink updates have been applied to address these issues. 


Product statements are related only to supported product versions. Products which have reached End of Support status are not considered.
