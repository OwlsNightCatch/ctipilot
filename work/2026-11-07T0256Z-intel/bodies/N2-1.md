# Vulnerabilities in Node.js and Brotli Affecting Cisco Products: October 2026

- On October 21, 2026, Node.js announced the availability of fixes for multiple vulnerabilities across the following supported release lines: 22.x, 24.x, and 26.x. These vulnerabilities impact critical operations such as the Brotli decoder, DNS resolution, and TLS certificate validation. The vulnerabilities pose risks for remote code execution and traffic interception. For more information, see [Node.js Security Release](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases).
The following vulnerabilities have a Security Impact Rating (SIR) of High and are addressed in this advisory: 
  - CVE-2026-111497 - Brotli decoder out-of-bounds write; potential remote code execution
  - CVE-2026-105482 - DNS resolution truncation involving embedded NUL characters
  - CVE-2026-105483 - TLS hostname validation bypass using fullwidth IP digits
  - CVE-2026-106069 - TLS hostname validation bypass with noncanonical IP addresses
For information about Splunk products and offerings, see [Vulnerabilities in Node.js (CVE-2026-111497, CVE-2026-105482, CVE-2026-105483, CVE-2026-106069) on Splunk Products - October 2026](https://advisory.splunk.com/advisories/SVD-2026-1015)
This investigation was expanded to cover Brotli outside of Node.js on October 30, 2026. The Brotli decoder flaw (CVE-2026-111497), which is in the Google Brotli C decoder, is often bundled with or linked to other software, so products beyond Node.js may be affected. For software that may be affected, see [Broccoli2Shell](https://broccoli2shell.com/).
**Important:** If a product is not listed within this advisory, Cisco's review indicates that the product is not affected by this vulnerability.
