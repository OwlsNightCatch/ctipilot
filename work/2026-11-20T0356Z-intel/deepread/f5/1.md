# Avis du CERT-FR

Objet : Multiples vulnérabilités dans les produits F5

## Gestion du document

Une gestion de version détaillée se trouve à la fin de ce document.

## Risques

- Contournement de la politique de sécurité
- Déni de service à distance
- Exécution de code arbitraire à distance

## Systèmes affectés

- BIG-IP Next pour Kubernetes versions 2.2.x antérieures à BNK-2.2.5-EHF1
- BIG-IP Next pour Kubernetes versions 2.3.x antérieures à BNK-2.3.4-EHF1
- BIG-IP Next pour Kubernetes versions 2.4.x antérieures à BNK-2.4.2-EHF1
- BIG-IP versions 17.5.x antérieures à 17.5.1.10.0.80.35-ENG
- BIG-IP versions 17.5.x antérieures à 17.5.1.11.0.61.12-ENG
- BIG-IP versions 17.x antérieures à 17.1.3.6.0.14.20-ENG
- BIG-IP versions 17.x antérieures à 17.1.3.7.0.21.4-ENG
- BIG-IP versions 21.1.x antérieures à 21.1.0.4.0.19.3-ENG
- BIG-IQ Centralized Management versions 8.4.x antérieures à 8.4.2.3
- NGINX Open Source versions 1.31.x antérieures à 1.31.9
- NGINX Open Source versions antérieures à 1.30.7
- NGINX Plus versions 3.1.x à 3.2.x antérieures à 3.7.3.0.1
- NGINX Plus versions 3.7.x antérieures à 37.0.8.1

## Résumé

De multiples vulnérabilités ont été découvertes dans les produits F5. Elles permettent à un attaquant de provoquer une exécution de code arbitraire à distance, un déni de service à distance et un contournement de la politique de sécurité.

## Solutions

Se référer au bulletin de sécurité de l'éditeur pour l'obtention des correctifs (cf. section Documentation).
