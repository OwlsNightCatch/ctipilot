### Description

Palo Alto Networks is aware of the Critical Severity vulnerability in Java: CVE-2026-114938.

A buffer-overflow vulnerability in HotSpot JVM's optimized (intrinsic) Base64 decoder, affecting Oracle Java SE, Oracle GraalVM, and OpenJDK on x86-64 CPUs with AVX-512 VBMI support (where Base64 hardware intrinsics are enabled by default). When decoding specially crafted Base64 input, it causes an out-of-bounds heap write that can lead to remote code execution by an unauthenticated remote attacker in affected applications

Successful exploitation relies on a combination of specific conditions: execution on an affected JDK release, underlying x86-64 hardware supporting AVX-512 VBMI with Base64 intrinsics enabled, and an exposed processing path where the application decodes untrusted Base64 input.

*Palo Alto Networks is actively investigating its product portfolio and cloud services to determine potential impact from this vulnerability. The sections below will be updated as our analysis progresses and additional information or remediation status becomes available.*
