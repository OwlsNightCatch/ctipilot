# Avis du CERT-FR

Objet : Vulnérabilité dans les produits Elastic

## Gestion du document

Une gestion de version détaillée se trouve à la fin de ce document.

## Risques

- Déni de service à distance
- Exécution de code arbitraire à distance

## Systèmes affectés

- Elastic Cloud Hosted versions 9.5.x antérieures à 9.5.7, date de disponibilité non disponible
- Elastic Cloud Hosted versions 9.x antérieures à 9.4.10, date de disponibilité non disponible
- Elastic Cloud Hosted versions antérieures à 8.19.26, date de disponibilité non disponible
- Elasticsearch versions 9.5.x antérieures à 9.5.7, date de disponibilité non disponible
- Elasticsearch versions 9.x antérieures à 9.4.10, date de disponibilité non disponible
- Elasticsearch versions antérieures à 8.19.26, date de disponibilité non disponible
- Logstash versions 9.5.x antérieures à 9.5.7, date de disponibilité non disponible
- Logstash versions 9.x antérieures à 9.4.10, date de disponibilité non disponible
- Logstash versions antérieures à 8.19.26, date de disponibilité non disponible

## Résumé

Une vulnérabilité a été découverte dans les produits Elastic. Elle permet à un attaquant de provoquer une exécution de code arbitraire à distance et un déni de service à distance.

## Solutions

Se référer au bulletin de sécurité de l'éditeur pour l'obtention des correctifs (cf. section Documentation).
