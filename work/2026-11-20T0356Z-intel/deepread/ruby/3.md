    ### Summary

Ruby has a double free in its regular expression engine. Compiling a crafted regular expression pattern may allow remote code execution in applications that compile attacker-controlled patterns. We are aware of PoCs that prove this flaw can be used to trigger RCE in some scenarios.

A CVE ID has been requested and is pending.

### Details

When parsing a character class intersection (`&&`) in a regular expression pattern, Ruby could free the same buffer twice.

### Impact

This is a double free that may allow remote code execution in applications that compile regular expressions from attacker-controlled strings. We are aware of PoCs that prove this flaw can be used to trigger RCE in some scenarios. Applications should upgrade.

### Patches

Upgrade to Ruby 3.3.14, 3.4.13 or 4.0.10.

### Credits

Thanks to Stephan Lipp (Ada Logics) and Anthropic for reporting this issue.
