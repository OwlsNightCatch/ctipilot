    ### Summary

Ruby has an out-of-bounds read in its regular expression engine. Matching a crafted string may disclose memory contents or crash the process.

A CVE ID has been requested and is pending.

### Details

When matching a case-insensitive backreference, Ruby could read past the end of the subject string.

### Impact

This is an out-of-bounds read that may disclose memory contents or crash the process. Applications should upgrade.

### Patches

Upgrade to Ruby 3.3.14, 3.4.13 or 4.0.10.

### Credits

Thanks to Hiroya Fujinami and Hiroshi SHIBATA for reporting this issue.
