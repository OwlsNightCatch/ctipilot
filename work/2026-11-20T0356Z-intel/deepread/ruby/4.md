    ### Summary

Ruby has an integer overflow in the case conversion of strings, which causes a heap-based buffer overflow. Changing the case of a crafted string may allow remote code execution. We are aware of PoCs that prove this flaw can be used to trigger RCE in some scenarios.

A CVE ID has been requested and is pending.

### Details

When changing the case of a string whose converted result exceeds 4 GiB, the length of the result could overflow, and Ruby could write past the end of a heap buffer.

### Impact

This is a heap-based buffer overflow that may allow remote code execution. We are aware of PoCs that prove this flaw can be used to trigger RCE in some scenarios. Applications should upgrade.

### Patches

Upgrade to Ruby 3.3.14, 3.4.13 or 4.0.10.
