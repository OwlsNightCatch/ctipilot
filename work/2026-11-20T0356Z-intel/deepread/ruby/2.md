    ### Summary

Ruby has a one-byte heap-based buffer overflow in the case conversion of strings. Changing the case of a crafted string may allow remote code execution. We are aware of PoCs that prove this flaw can be used to trigger RCE in some scenarios.

A CVE ID has been requested and is pending.

### Details

When changing the case of a string in some single-byte encodings, such as ISO-8859-1 and Windows-1252, Ruby could write one byte past the end of the output buffer.

### Impact

This is a heap-based buffer overflow that may allow remote code execution. We are aware of PoCs that prove this flaw can be used to trigger RCE in some scenarios. Applications should upgrade.

### Patches

Upgrade to Ruby 3.3.14, 3.4.13 or 4.0.10.

### Credits

Thanks to Stephan Lipp (Ada Logics) and Anthropic for reporting this issue.
