    ### Summary

Ruby has a heap-based buffer overflow in `Regexp#to_s`. Converting a crafted regular expression to a string may allow information disclosure or remote code execution in applications that compile attacker-controlled patterns. We are aware of PoCs that prove this flaw can be used to trigger RCE in some scenarios.

A CVE ID has been requested and is pending.

### Details

When converting a regular expression to a string, Ruby could write past the end of a heap buffer.

### Impact

This is a heap-based buffer overflow that may allow information disclosure or remote code execution in applications that compile regular expressions from attacker-controlled strings. We are aware of PoCs that prove this flaw can be used to trigger RCE in some scenarios. Applications should upgrade.

### Patches

Upgrade to Ruby 3.3.14, 3.4.13 or 4.0.10.

### Credits

Thanks to Stephan Lipp (Ada Logics) and Anthropic for reporting this issue.
