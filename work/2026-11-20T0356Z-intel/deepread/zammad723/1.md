# Zammad 7.2.3

· Zammad 7.2.3 is a security update that addresses several vulnerabilities and includes additional security improvements.

Below, you’ll find all relevant information about the update and the required steps.

## [🚨 Important note on the update](https://zammad.com#important-note-on-the-update)

### [nginx/Apache2 Configuration Update Required](https://zammad.com#nginx-apache2-configuration-update-required)

Please update your nginx or Apache2 configuration file to insert the following line next to the existing X-Forwarded-User line, like in the examples below. The Docker images apply this change automatically.

Add the following line to your configuration file:

**nginx:**

`# change this line in an SSO setup`

`proxy_set_header X-Forwarded-User "";`

`proxy_set_header Remote-User "";`

**Apache2:**

`# change this line in an SSO setup`

`RequestHeader unset X-Forwarded-User`

`RequestHeader unset Remote-User`

In an SSO setup, make sure your proxy sets exactly one of the two headers and clears the other.
