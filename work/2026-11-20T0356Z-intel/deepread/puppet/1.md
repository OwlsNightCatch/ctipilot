  "content": "##### SEVERITY AND IMPACT:\n- Successful exploitation allows network attackers with a CA-signed agent certificate to run code on the Puppet Server. Unauthenticated attackers can obtain such a certificate if auto-signing is misconfigured. This can compromise the CA signing key and every managed system.\n- **Current exploitation status**: Actively Exploited, Proof of Concept Available\n\n##### AFFECTED PRODUCTS:\n- Perforce Puppet Enterprise\n- Perforce Puppet Enterprise Advanced\n- Perforce Puppet Core (as used by Puppet Server)\n- OpenVox (Vox Pupuli open-source Puppet implementation): OpenVox Agent and OpenVox Server\n\nFor specific versions, please check the references.\n\n##### VULNERABILITY DETAILS:\n- **Attack Chain:** CVE-2026-115731 enables server RCE via crafted rich-data reports. CVE-2026-115732, an authorization bypass through colliding certificate names, enables node impersonation and, in Puppet Enterprise, CA administration and remote command execution on managed nodes.\n- **Prerequisites:**\n    - Network access to the Puppet Server.\n    - A CA-signed agent certificate, which can be obtained without authentication where the CA auto-signs requests without strong verification.\n- **Impact Details:**\n    - Code runs with the Puppet Server service user's permissions.\n    - Attackers can steal CA signing keys, issue trusted certificates, impersonate hosts and alter software or configuration pushed to managed systems on their next Puppet run.\n- **Available Mitigations:**\n    - Vendor patches are available for Puppet Enterprise, Puppet Enterprise Advanced, Puppet Core and OpenVox.\n    - CISA added CVE-2026-115731 to its KEV catalog, with a remediation deadline of December 1, 2026 for federal agencies.\n    - **Temporary:** Disable certificate auto-signing and enforce strong CSR validation. Audit issued certificates for suspicious or colliding names. Review CA configuration for signs of compromise.\n\n##### CVEs IN THIS ADVISORY:\n- CVE-2026-115731 CVSS4.0: 9.4 (CRITICAL) - Deserialization of untrusted data in report processing leading to RCE on the Puppet Server\n- CVE-2026-115732 CVSS4.0: 9.0 (CRITICAL) - Certificate-name matching authorization bypass enabling node impersonation\n\n##### REFERENCES:\nPrimary:\n- Source Advisory: https://portal.perforce.com/s/article/Puppet-security-vulnerabilities-CVE-2026-115731-and-CVE-2026-115732 (Perforce security advisory for both flaws)\n- Vendor Advisory: https://portal.perforce.com/s/cve/a91Qi000003IaHpIAK/report-deserialization-code-execution (Perforce CVE detail, report deserialization RCE)\n- Vendor Advisory: https://portal.perforce.com/s/cve/a91Qi000003IaJRIA0/certificate-name-authorization-bypass (Perforce CVE detail, certificate name authorization bypass)\n\nSupporting:\n- Technical Analysis: https://neodyme.io/en/blog/puppet_rce/ (Neodyme researcher write-up with detailed technical information)\n- Additional Sources: https://www.cisa.gov/known-exploited-vulnerabilities-catalog?field_cve=CVE-2026-115731 (CISA KEV entry and remediation deadline)\n- Additional Sources: https://www.reddit.com/r/Puppet/comments/1xnj0v1/cve2026115732_published_114_being_exploited_in/ (Community report of in-the-wild exploitation)\n- News Coverage: https://www.securityweek.com/critical-perforce-puppet-rce-exploited-in-attacks/ (SecurityWeek report on exploitation)\n- News Coverage: https://thehackernews.com/2026/11/hackers-exploiting-critical-puppet-rce.html (The Hacker News coverage with affected and fixed versions)\nNote: A public PoC exploit targeting OpenVox has been reported, but no direct link was provided in the sources.\n\n*Timestamp of the Information: 19.11.2026, 10:59*",
