# NGINX vulnerabilities

## Summary

CVE-2026-123007 (high)

This vulnerability affects NGINX OSS versions 1.31.0 - 1.31.8, 1.9.5 - 1.30.6.

CVE-2026-123633 (high)

This vulnerability affects NGINX OSS versions 1.31.0 - 1.31.8, 1.19.7 - 1.30.6.

CVE-2026-121810 (high)

This vulnerability affects NGINX OSS versions 1.31.0 - 1.31.8, 1.25.0 - 1.30.6.

CVE-2026-123634 (high)

This vulnerability affects NGINX OSS versions 1.31.0 - 1.31.8, 1.0.0 - 1.30.6.

CVE-2026-113425 (high)

CVE-2026-120993 (medium)

This vulnerability affects NGINX OSS versions 1.31.4.

CVE-2026-125283 (medium)

This vulnerability affects NGINX OSS versions 1.31.0 - 1.31.8, 0.9.6 - 1.30.6.

CVE-2026-123640 (medium)

This vulnerability affects NGINX OSS versions 1.31.0 - 1.31.8, 1.15.2 - 1.30.6.
