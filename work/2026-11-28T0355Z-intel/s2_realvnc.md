# Security Advisory: UDP-based connection vulnerability

[Follow](https://help.realvnc.com/hc/en-us/articles/40824627217949-Security-Advisory-UDP-based-connection-vulnerability/subscription.html "Opens a sign-in dialog")

**[RealVNC Customer Support Agent](https://help.realvnc.com/hc/en-us/profiles/367081576372-RealVNC-Customer-Support-Agent)**

 Updated Today, 6:50 AM

# Summary

We've fixed a memory-safety vulnerability affecting UDP-based connections. It could potentially be exploited to execute code remotely or cause the software to crash, pre-authentication.

At the time of publication, RealVNC is not aware of any active exploitation in the wild.

# Vulnerability Details

| Advisory ID | RVNC-2026-001 |
| --- |
| CVE ID | [CVE-2026-137738](https://www.cve.org/CVERecord?id=CVE-2026-137738) |
| Severity | Critical, CVSS 9.8 |
| **Description** | We've fixed a memory-safety vulnerability affecting UDP-based connections. It could potentially be exploited to execute code remotely or cause the software to crash, pre-authentication. This could allow an attacker to remotely execute code as root on certain platforms or perform a denial of service attack. This affects all customers using our cloud-hosted connectivity and manually configured direct connections (including offline licensed/on-premises deployments). TCP-only direct connections are not exposed. |
| Affected | **Desktop applications (Windows, macOS, Linux)** * RealVNC Viewer 8.4.0 to 8.6.1 * RealVNC Classic Viewer 6.4.0 to 7.18.2 * RealVNC Server 6.4.0 to 7.19.0 * RealVNC Connect App 8.6.1 and earlier * RealVNC On-Demand Assist 3.4.1 and earlier **Mobile applications (iOS/iPadOS and Android)** * RealVNC Viewer iOS 3.7.0 to 4.9.5 * RealVNC Viewer Android 3.5.0 to 4.9.5 * RealVNC Server iOS 2.8.1 and earlier * RealVNC Server Android 2.8.3 and earlier |
| Fixed in | **Desktop applications (Windows, macOS, Linux)** * RealVNC Viewer 8.6.2 * RealVNC Connect app 8.6.2 * RealVNC Classic Viewer 7.18.3 * RealVNC Server 7.19.1 * RealVNC On-Demand Assist 3.5.0 **Mobile applications (iOS/iPadOS and Android)** * RealVNC Viewer iOS/iPadOS 4.9.6 * RealVNC Viewer Android 4.9.6 * RealVNC Server iOS/iPadOS 2.8.2 * RealVNC Server Android 2.8.4 |

# Exploitation status

At the time of publication, we are not aware of this vulnerability being actively exploited.

# Solutions & Mitigations

Update to the latest versions available of each application.

## Desktop applications

### RealVNC Viewer, RealVNC Server, and RealVNC Connect App

1.   Download the latest version from [https://www.realvnc.com/en/connect/download/](https://www.realvnc.com/en/connect/download/)

2.   Install the updated versions on your devices.

### RealVNC Classic Viewer*

1.   Go to [https://manage.realvnc.com](https://manage.realvnc.com/), then _Downloads_ to find the latest version of RealVNC Classic Viewer.

2.   Download and install the latest version on your devices.

_*The RealVNC Classic Viewer (v7.x) is only available to eligible Premium and Enterprise subscription holders._

### RealVNC On-Demand Assist

1.   Download the latest version from [https://www.realvnc.help/en/](https://www.realvnc.help/en/)
2.   Advise end users to delete any copies of older versions that they previously downloaded.

## Mobile applications

Mobile applications should update automatically. To verify the version you are on:

### RealVNC Viewer for Android

1.   Go to [https://play.google.com/store/apps/details?id=com.realvnc.viewer.android](https://play.google.com/store/apps/details?id=com.realvnc.viewer.android)

2.   Click ‘Update’ to update your application

### RealVNC Server for Android

1.   Go to [https://play.google.com/store/apps/details?id=com.realvnc.server](https://play.google.com/store/apps/details?id=com.realvnc.server)
2.   Click ‘Update’ to update your application

### RealVNC Viewer for iOS/iPadOS

1.   Go to [https://apps.apple.com/gb/app/realvnc-viewer-remote-desktop/id352019548](https://apps.apple.com/gb/app/realvnc-viewer-remote-desktop/id352019548) or search ‘RealVNC Viewer’ in the App Store.

2.   Click ‘Update’ to update your application.

### RealVNC Server for iOS/iPadOS

1.   Go to [https://apps.apple.com/gb/app/realvnc-server/id1616886311](https://apps.apple.com/gb/app/realvnc-server/id1616886311) or search ‘RealVNC Server’ in the App Store.

2.   Click ‘Update’ to update your application.
