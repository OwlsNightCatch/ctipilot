#### I. 概要

EGセキュアソリューションズ株式会社は、2026年10月14日にSiteGuard Server EditionにおけるOSコマンドインジェクションの脆弱性（CVE-2026-106931）を公表しました。本脆弱性の悪用により、当該製品が動作するサーバー上で、rootまたはSYSTEM権限で任意のOSコマンドが実行される可能性があります。EGセキュアソリューションズ株式会社は、本脆弱性の悪用を確認しているとのことです。


EGセキュアソリューションズ株式会社

[https://www.eg-secure.co.jp/siteguard/news/alert-202610-1](https://www.eg-secure.co.jp/siteguard/news/alert-202610-1)


JPCERT/CCでは、当該製品が国内で広く利用されていることを確認しています。本脆弱性の影響を受ける製品を利用している場合は、後述「III. 対策」以降に記載の情報を確認の上、対策と侵害調査の実施を検討してください。



#### II. 対象

本脆弱性の対象となる製品およびバージョンは次のとおりです。詳細は、EGセキュアソリューションズ株式会社が提供する最新の情報をご確認ください。


SiteGuard Server Edition Ver2.20 以降の以下のバージョン

- Apache版、Nginx版、IIS版：Ver8.00 Update5 より前のバージョン

- FreeBSD Apache版、Nginx版：Ver7.00 Update6 より前のバージョン


当該製品においてデフォルトで有効となっている統計機能が有効な場合に本脆弱性の影響を受けます。ただし、IIS版についてはVer3.10からVer4.00 Update4のバージョンは本脆弱性の影響を受けません。



#### III. 対策

EGセキュアソリューションズ株式会社は本脆弱性を修正したバージョンへのアップデートを推奨しています。また、バージョンアップが困難な利用者向けに統計処理の対象ファイルを差し替えるパッチを提供しています。詳細は、開発者が提供する最新の情報を確認してください。



#### IV. 回避策

統計機能を無効化することで本脆弱性の影響を回避することが可能です。無効化手順など詳細は、EGセキュアソリューションズ株式会社が提供する最新の情報を確認してください。



#### V. アップデートにおける注意事項

EGセキュアソリューションズ株式会社は本脆弱性を修正したバージョンへのアップデートが完了した場合、侵害の痕跡が削除される可能性があると報告しています。そのため、攻撃を受けた際の痕跡の保全方法を案内しています。該当するバージョンを利用している場合、SiteGuard Server Edition上のウェブ管理画面で「診断情報」の取得を行い、攻撃痕跡を保全した上でのアップデートが推奨されています。詳細は、EGセキュアソリューションズ株式会社が提供する最新の情報を確認してください。
