**Serial number:** AV26-1048

**Date:** October 15, 2026

As of October 14, 2026, SonicWall is affected by vulnerabilities in the following product:

- Network Security Manager (NSM) On-Prem (VMWare, Hyper-V, Azure and KVM)
	
  - Version 4.3.1 and prior

The Cyber Centre encourages users and administrators to review the provided web links and apply any necessary updates as they become available.
