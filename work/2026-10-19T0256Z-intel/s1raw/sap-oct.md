## SAP Security Patch Day – October 2026

This post shares the information on security notes that remediate vulnerabilities discovered in SAP products. SAP strongly recommends that the customer visits the [support portal](https://support.sap.com/en/my-support/knowledge-base/security-notes-news.html) and applies patches on priority to protect their SAP landscape.


On 13<sup>th</sup> of October 2026, SAP security patch day saw the release of 16 new security notes and 4 GitHub security advisories. There are 2 updates to previously released security notes.
