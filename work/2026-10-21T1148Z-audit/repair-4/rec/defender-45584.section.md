Exploitation is not zero-click: Microsoft says a remote, unauthenticated attacker would have to entice a local user to take multiple actions that result in Defender scanning a malicious file that has been quarantined, and rates the attack complexity high ([MSRC, 2026-05-19](https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2026-45584)). The advisory does not say the attacker's code runs in the Defender process context. Malware Protection Engine version 1.1.26030.3008 and earlier are affected and Engine version 1.1.26040.8 fixes the flaw ([MSRC, 2026-05-19](https://msrc.microsoft.com/update-guide/en-US/vulnerability/CVE-2026-45584)).
