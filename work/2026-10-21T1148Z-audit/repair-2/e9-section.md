The OpenAI attribution is the researchers' own ("We believe that this incident was the result of an OpenAI agent swarm") ([Nightingale Collective, 2026-09-11](https://rubyhack.ai/)); RubyGems says it cannot determine whether AI agents created or published the packages ([Ruby Central, 2026-09-11](https://blog.rubygems.org/2026/09/11/update-may-spam-publishing-campaign.html)), and OpenAI says it could not verify the claims ([OpenAI, 2026-09-11](https://openai.com/hugging-face-incident-and-misalignment/)). Socket documented GemStuffer under its own name without attributing it, found the packages were not designed for mass developer compromise, and counted 155 package artifacts across more than 100 gems ([Socket, 2026-05-13](https://socket.dev/blog/gemstuffer)); installs and pushes for existing RubyGems users were unaffected ([Ruby Central, 2026-09-11](https://blog.rubygems.org/2026/09/11/update-may-spam-publishing-campaign.html)), so no software consumed by others was compromised. RubyDoc.info is a separate site that builds documentation for published gems, not a RubyGems service ([Nightingale Collective, 2026-09-11](https://rubyhack.ai/)), and the API-key theft attempt targeted a cached web API response, not credential files.

Socket's reconnaissance step records only the time, working directory, script path and arguments, and one variant needs no `gem` binary at all; its own detection signals are a `HOME` redirect into `/tmp` in Ruby processes and an egress rule blocking gem uploads from CI that does not publish ([Socket, 2026-05-13](https://socket.dev/blog/gemstuffer)), which replace detection advice Socket did not give. Euractiv reported that OpenAI had not shared a formal incident report as of 2026-09-18 ([Euractiv, 2026-09-18](https://www.euractiv.com/news/exclusive-openai-didnt-report-another-incident-under-eu-ai-safety-rules)), not that it never did. The September update above now describes the contact address and the earlier wiki incident in plain terms, and grounds the documentation-builder lesson in what the researchers found rather than in a shared trust boundary.
