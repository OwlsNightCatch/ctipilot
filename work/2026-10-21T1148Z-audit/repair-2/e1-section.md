No CVE covers the rogue plugin build: CVE-2026-33634 is the Trivy flaw in which a threat actor used compromised credentials on 2026-03-19 to publish a malicious Trivy release and move the trivy-action tags to credential-stealing code ([GitHub Advisory Database, 2026-03-21](https://github.com/advisories/GHSA-69fq-xp46-6x23)), the attack Checkmarx names as the source of the attacker's access ([Checkmarx, updated 2026-07-06](https://checkmarx.com/blog/ongoing-security-updates/)). No source names SANDCLOCK as the Jenkins payload; GTIG uses the name for the stealer of the late-March compromises and describes it extracting cloud secrets such as AWS keys and GitHub tokens, not LLM API keys ([GTIG, 2026-05-11](https://cloud.google.com/blog/topics/threat-intelligence/ai-vulnerability-exploitation-initial-access)). Checkmarx lists crypto wallets, VPNs, AWS and GitHub as the payload's targets rather than registry, Kubernetes or Checkmarx One API credentials, and Mandiant found no threat-actor access to the Checkmarx One SaaS environment ([Checkmarx, updated 2026-07-06](https://checkmarx.com/blog/ongoing-security-updates/)).

The earlier waves were GitHub Actions and Open VSX extensions in March and the KICS Docker image with updated extensions and a GitHub Action in April ([Checkmarx, updated 2026-07-06](https://checkmarx.com/blog/ongoing-security-updates/)). PCPJack is a separate cloud worm whose first act is to evict TeamPCP tooling ([SentinelLABS, 2026-05-07](https://www.sentinelone.com/labs/cloud-worm-evicts-teampcp-and-steals-credentials-at-scale/)), and no cited source links it to the plugin. The defacement renamed the plugin's GitHub repository, not the build ([The Hacker News, 2026-05-11](https://thehackernews.com/2026/05/teampcp-compromises-checkmarx-jenkins.html)), and exposure did not depend on auto-update: any instance that pulled build 2026.5.09 during the window installed the compromised plugin ([SOCRadar, 2026-05-11](https://socradar.io/blog/checkmarx-jenkins-plugin-teampcp-backdoor/)). The exact window, the clean versions and Checkmarx's credential-rotation advice are now stated above.
