Bitdefender presents Azerbaijan's expanded gas exports to 13 European countries as context that does not establish motive, and attributes the intrusion with moderate-to-high confidence to FamousSparrow as likely affiliated with the Chinese APT ecosystem ([Bitdefender, 2026-05-13](https://www.bitdefender.com/en-us/blog/businessinsights/famoussparrow-apt-targets-azerbaijani-oil-gas-industry)); no source states a motive of Chinese state actors. Prior reporting placed the cluster against telecoms, government and technology targets, and Bitdefender cites toolset and tradecraft overlap with Earth Estries rather than shared infrastructure ([Bitdefender, 2026-05-13](https://www.bitdefender.com/en-us/blog/businessinsights/famoussparrow-apt-targets-azerbaijani-oil-gas-industry)). The sideload is what Bitdefender calls an evolved technique: its loader closely matches a Deed RAT loader Trend Micro documented for Earth Estries, and no source calls the Hamachi host new for the cluster or the binary signed ([Bitdefender, 2026-05-13](https://www.bitdefender.com/en-us/blog/businessinsights/famoussparrow-apt-targets-azerbaijani-oil-gas-industry)).

The second wave's TernDoor installation was blocked by the security product before it completed, and TernDoor is Bitdefender's assessment from recovered memory pages ([Bitdefender, 2026-05-13](https://www.bitdefender.com/en-us/blog/businessinsights/famoussparrow-apt-targets-azerbaijani-oil-gas-industry)). The re-entries came through the same still-vulnerable Exchange server, and Bitdefender's lesson is patching plus rotation of compromised credentials; no surviving web shell or scheduled task is reported, no source describes cumulative updates rolling back fixes, and the persisted loader sat in a path mimicking the legitimate Hamachi install directory, so a hunt that trusts that path misses it ([Bitdefender, 2026-05-13](https://www.bitdefender.com/en-us/blog/businessinsights/famoussparrow-apt-targets-azerbaijani-oil-gas-industry)). Microsoft's advisory says ProxyNotShell requires an authenticated attacker ([MSRC, CVE-2022-41082](https://msrc.microsoft.com/update-guide/vulnerability/CVE-2022-41082)), while Bitdefender describes it as unauthenticated. The detection guidance now follows Bitdefender's observed signals instead of generic Exchange hunts.
