## 

Unit 42 is aware of two critical vulnerabilities in PHP: CVE-2026-109618 and CVE-2026-109619. Both are remote code execution (RCE) vulnerabilities rated as 9.2 (CVSS 4.0). The vulnerabilities are being referred to as PHP2Shell. We encourage reviewing the [PHP Group’s security advisory and patching guidance](https://www.php.net/index.php).

PHP is widely used across web servers and content management systems globally. We recommend assessing your exposure to these vulnerabilities and patching immediately.

Unit 42 has seen proof of concept of these vulnerabilities. At least one European government has taken its website offline as a precaution.

Palo Alto Networks has evaluated our product portfolio regarding this issue. Refer to our [security advisory](https://security.paloaltonetworks.com/CVE-2026-109618) for the most up to date details.

- [CVE-2026-109618](https://nvd.nist.gov/vuln/detail/cve-2026-109618) involves a remote code execution vulnerability where handling out-of-memory errors via longjmp() leaves request memory uninitialized due to improper control flow management, allowing attackers to reliably achieve RCE using out-of-memory (OOM) triggers.
- [CVE-2026-109619](https://nvd.nist.gov/vuln/detail/cve-2026-109619) describes a remote code execution vulnerability where longjmp() fatal error handling leaves global memory pointing to freed memory regions. These regions can later be read or branched on during subsequent requests, enabling attackers to execute arbitrary code.

Unit 42 researchers also observed attackers using agentic AI attack platforms for post-exploitation activity. In one case, the attackers targeted a government entity in Europe and within two hours of the initial exploitation they had successfully accessed password hashes and multi-factor authentication secrets. They also established an NT LAN Manager (NTLM)-relay tunnel into Active Directory and attempted Domain Admin privilege escalation.

We observed an attacker enumerating the compromised endpoint. The commands and behavioral markers used in the attack are strong indicators of an agentic attacker. Each command batch is wrapped in section-header delimiters, such as ==SHELLUSER== and ==PASSWD==. These delimiters produce machine-parseable output for an AI model to read. We also noted the use of the short, serially spaced tasks and quick pivots after failures. Figure 1 shows the commands that were executed, as seen in Cortex XDR.

At the time of publication, Palo Alto Networks [Cortex Xpanse](https://docs-cortex.paloaltonetworks.com/p/XPANSE) has identified the presence of over 22.6 million exposed instances potentially vulnerable to CVE-2026-109618 and CVE-2026-109619 based on our telemetry.
