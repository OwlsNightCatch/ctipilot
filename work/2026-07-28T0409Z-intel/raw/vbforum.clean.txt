## Security Patch Released for vBulletin 6.2.1, 6.2.0 and 6.1.6
Tue 30 Jun '26, 10:16am
A security issue has been found in the template parsing functionality of vBulletin 6.2.1. We have created a fix for the issue.
It is recommended that you apply this patch as soon as possible. To do so, download the patch for your version from [https://members.vbulletin.com/patches.php](https://members.vbulletin.com/patches.php) and upload the included files to your server. The process will overwrite existing files with the new files provided.
> Note: Security patches may introduce false reports of altered files in the Suspect Files Diagnostic.
Patches Released:
 * vBulletin 6.2.1 Patch Level 1
 * vBulletin 6.2.0 Patch Level 1
 * vBulletin 6.1.6 Patch Level 1
If you are using an older version of vBulletin, you should upgrade to vBulletin 6.2.1 Patch Level 1 as soon as possible.
Note: vBulletin Cloud has been already been patched.
Translations provided by Google.
