    N-central: 4EverAble2Shell exploited on 21+ servers, Agent2Shell adds SYSTEM on agents; disable Legacy API

    first published 2026-11-10 03:51 UTCupdated 2026-11-14 04:00 UTC

    Defender actions

    • Confirm on every on-premises N-central server, yours or your IT provider's, that the Legacy API is disabled and not reachable from the internet, and keep Hotfix 2 (build 2026.4.1.26) and the Agent and Probe upgrades in place; on any server that had the Legacy API on, check the web logs for POST requests to the Axis endpoint /dms/services/ServerUI carrying a SOAP fault and the host for a symlink at the N-central flag file path, and treat a hit as a full compromise, because Hotfix 2 does not fix the chain and 19 of the 21 compromised servers Huntback found already ran it.

    Analysis

    An independent researcher published what Huntress counts as 33 critical flaws in the N-central appliance, chaining into four exploits, and N-able took its hosted environments offline on 2026-11-09 (Huntress, 2026-11-09); the chain BleepingComputer calls most critical abuses an unauthenticated XML external entity flaw to steal a trusted local session and run commands as the service user (BleepingComputer, 2026-11-09).

    On 2026-11-10 N-able released N-central 2026.4 Hotfix 2, build 2026.4.1.26, "a critical security update", for which Huntress lists seven CVE ids (N-able, 2026-11-10; Huntress, 2026-11-10; N-able CNA record, 2026-11-10; N-able CNA record, 2026-11-10). N-able reported scanning for that set but no successful exploitation (Huntress, 2026-11-10), and none of the seven is in CISA's catalog (Tenable, 2026-11-12).

    On 2026-11-12 the researcher published a second set. 4EverAble2Shell is unauthenticated command execution as root that requires the Legacy API to be enabled, per BleepingComputer; it chains CVE-2026-90436, an Apache Axis 1.x deserialization flaw for which Apache does not expect a fix, with a root escalation in N-central's maintenance helper (BleepingComputer, 2026-11-12; Apache Axis project, 2026-11-06; Huntback, 2026-11-12). Huntback counts at least 21 servers, 19 of them on Hotfix 2, in North America, South Africa and Europe but not Switzerland, and Previdian's honeypot recorded attempts at the chain (Huntback, 2026-11-12; Previdian, 2026-11-12). Agent2Shell is a set of more than ten issues in how the server talks to Windows Agents and Probes, two chains of which let an unauthenticated attacker who can reach the server run commands as SYSTEM on managed endpoints; N-able confirmed it also requires the non-default Legacy API (The Hacker News, 2026-11-12; Huntress, 2026-11-13). N-able has published indicators of compromise for customers that have not disabled the Legacy API, has no fix for the new claims and plans a follow-up hotfix (Huntress, 2026-11-13; Tenable, 2026-11-12).

    Exposure
    An on-premises N-central server, yours or an IT provider's: below build 2026.4.1.26 for the first set, and any build up to Hotfix 2 for the second when the Legacy API, off by default, is on and reachable (Huntress, 2026-11-13). A compromised server reaches the systems N-central manages (Field Effect, 2026-11-09).
    Detection
    In N-central's authentication and audit logs from 2026-11-08 onward, unexpected logins, new administrator accounts and changes to stored credentials or API integrations; on managed endpoints, unscheduled software deployments, scripts and remote-control sessions (Huntress, 2026-11-09; Field Effect, 2026-11-09). For 4EverAble2Shell, Huntback names POST requests to the Axis endpoint /dms/services/ServerUI, a symlink at the N-central flag file path, a systemd unit or cron entry relaunching a miner and a hidden miner directory under /tmp or /var/tmp (Huntback, 2026-11-12). Huntress's Agent2Shell indicators come from static analysis of the proof of concept, not attacks seen: SYSTEM PowerShell with an encoded command spawned by the Agent, where PowerShell as an Agent child is common and the command is what matters (Huntress, 2026-11-13).
    Defender takeaway
    Upgrade on-premises servers to Hotfix 2, then Agents and Probes, and confirm the Legacy API is disabled and not internet-reachable, because Hotfix 2 does not fix 4EverAble2Shell and 19 of the 21 compromised servers already ran it (Huntback, 2026-11-12); treat a hit as a full compromise, ask each IT provider managing your endpoints through N-central whether it runs a server on premises and has upgraded it, and rotate the administrator, service and integration credentials the platform holds where activity looks unauthorised (Field Effect, 2026-11-09).

    Updates3

    Update11 Nov 2026 03:49 UTC

    N-able released N-central 2026.4 Hotfix 2, build 2026.4.1.26, on 2026-11-10 as a critical security update; hosted servers are already upgraded, on-premises customers must upgrade their own servers, and every customer must upgrade Agents first and then Probes (N-able, 2026-11-10). Huntress lists seven CVE ids for the fixed flaws and relays N-able's status-page statement that it observed "scanning activity associated with the published proof-of-concept code" but no evidence that any customer environment was successfully exploited; Huntress has seen no exploitation in its partners' environments, and N-able's guidance is to keep on-premises servers offline until the upgrade is complete (Huntress, 2026-11-10). After the hotfix the built-in remote control is temporarily disabled and Take Control still works (N-able, 2026-11-10).

    Update13 Nov 2026 03:54 UTC

    The researcher's second exploit set, 4EverAble2Shell, published on 2026-11-12, works against Hotfix 2 builds when the Legacy API is turned on and reachable, and no fix exists. It pairs CVE-2026-90436 in the Apache Axis 1.x SOAP engine (Apache Axis project, 2026-11-06) with a separate root escalation (Huntback, 2026-11-12; BleepingComputer, 2026-11-12). Huntback counts at least 21 production servers, 19 of them on Hotfix 2, mining for one operator (Huntback, 2026-11-12), Previdian's honeypot recorded attempts at the chain (Previdian, 2026-11-12), and BleepingComputer relays both (BleepingComputer, 2026-11-12). N-able said on 2026-11-12 that it had seen no signs of compromise, had no fix for the new claims and planned a follow-up hotfix (Tenable, 2026-11-12); Huntress says a Hotfix 2 server with the Legacy API disabled is not exposed to this chain (Huntress, 2026-11-12).

    Update14 Nov 2026 04:00 UTC

    The researcher's 2026-11-12 disclosure also includes Agent2Shell, which The Hacker News describes as more than ten zero-day flaws used to run commands as SYSTEM on managed Windows agents, assuming the attacker knows the target appliance ID (The Hacker News, 2026-11-12). Huntress describes it as a set of more than ten issues in how the N-central server communicates with Windows Agents and Probes, two chains of which let an unauthenticated attacker who can reach the server run commands on managed Windows endpoints, including as SYSTEM (Huntress, 2026-11-13). Huntress relays that N-able confirmed Agent2Shell, like 4EverAble2Shell, requires the non-default Legacy API to be enabled, which settles the question Huntress and Tenable had left open on 2026-11-12, and that on 2026-11-13 at 13:40 UTC N-able said it had identified indicators of compromise for customers that have not disabled the Legacy API (Huntress, 2026-11-13); the statement that N-able had seen no signs of compromise dates from 2026-11-12 (Tenable, 2026-11-12). Huntress has not observed exploitation of these issues in its partners' environments, and its Agent2Shell indicators come from static analysis of the proof of concept, not from attacks seen (Huntress, 2026-11-13). Tenable adds that N-able has temporarily deactivated the Intune integration for on-premises customers running it (Tenable, 2026-11-12).
