    N-central: Hotfix 3 fixes 17 more CVEs and blocks the Legacy API; 4EverAble2Shell exploited; upgrade Agents too

    first published 2026-11-10 03:51 UTCupdated 2026-11-22 14:52 UTC

    Defender actions

    • Upgrade every on-premises N-central server to 2026.4 Hotfix 3 (build 2026.4.1.39) and every Agent and Probe to 2026.4.1 HF3 even if already on Hotfix 2, confirm the Legacy API is disabled and not reachable from the internet, and on any server that had the Legacy API on check the web logs for POST requests to the Axis endpoint /dms/services/ServerUI carrying a SOAP fault and the host for a symlink at the N-central flag file path, treating a hit as a full compromise, because public proof-of-concept code exists for all 17 new CVE ids, Hotfix 2 did not stop 4EverAble2Shell and N-able does not say Hotfix 3 fixes it.

    Analysis

    An independent researcher published what Huntress counts as 33 critical flaws in the N-central appliance, chaining into four exploits, and N-able took its hosted environments offline on 2026-11-09 (Huntress, 2026-11-09).

    On 2026-11-10 N-able released N-central 2026.4 Hotfix 2, build 2026.4.1.26, for which Huntress lists seven CVE ids (N-able, 2026-11-10; Huntress, 2026-11-10; N-able CNA record, 2026-11-10; N-able CNA record, 2026-11-10).

    On 2026-11-12 the researcher published a second set. 4EverAble2Shell is unauthenticated command execution as root that requires the Legacy API to be enabled, per BleepingComputer; it chains CVE-2026-90436, an Apache Axis 1.x deserialization flaw for which Apache does not expect a fix, with a root escalation in N-central's maintenance helper (BleepingComputer, 2026-11-12; Apache Axis project, 2026-11-06; Huntback, 2026-11-12). Huntback counts at least 21 servers, 19 of them on Hotfix 2, in North America, South Africa and Europe but not Switzerland, and Previdian's sensors recorded attempts at the chain (Huntback, 2026-11-12; Previdian, 2026-11-12). Agent2Shell is a set of more than ten issues in how the server talks to Windows Agents and Probes, two chains of which let an unauthenticated attacker who can reach the server run commands as SYSTEM on managed endpoints; N-able confirmed it also requires the non-default Legacy API (The Hacker News, 2026-11-12; Huntress, 2026-11-13). N-able has published indicators of compromise for customers that have not disabled the Legacy API (Huntress, 2026-11-13). Hotfix 3 of 2026-11-16 fixes 17 more CVE ids, hardens how Agents and Probes authenticate and blocks the Legacy API permanently, without naming 4EverAble2Shell or Agent2Shell or saying either is fixed (N-able, 2026-11-16); Huntress reports public proof-of-concept code for all 17 and no exploitation of them in its partners' environments (Huntress, 2026-11-17).

    Exposure
    An on-premises N-central server, yours or an IT provider's, below build 2026.4.1.39, and for the second set any build up to Hotfix 2 when the Legacy API, off by default, is on and reachable (Huntress, 2026-11-13); an Agent or Probe not on Hotfix 3 can be impersonated (N-able, 2026-11-16). A compromised server reaches the systems N-central manages (Field Effect, 2026-11-09).
    Detection
    In N-central's authentication and audit logs from 2026-11-08 onward, unexpected logins, new administrator accounts and changes to stored credentials or API integrations; on managed endpoints, unscheduled software deployments, scripts and remote-control sessions (Huntress, 2026-11-09; Field Effect, 2026-11-09). For 4EverAble2Shell, Huntback names POST requests to the Axis endpoint /dms/services/ServerUI, a symlink at the N-central flag file path, a systemd unit or cron entry relaunching a miner and a hidden miner directory under /tmp or /var/tmp (Huntback, 2026-11-12). Huntress's Agent2Shell indicators are static analysis only: SYSTEM PowerShell with an encoded command spawned by the Agent, where an Agent child PowerShell is common and the command is what matters (Huntress, 2026-11-13).
    Defender takeaway
    Upgrade on-premises servers to Hotfix 3, then every Agent and Probe, those already on Hotfix 2 included (N-able, 2026-11-16), and confirm the Legacy API is disabled and not internet-reachable, because Hotfix 2 did not stop 4EverAble2Shell, 19 of the 21 compromised servers already ran it (Huntback, 2026-11-12) and N-able does not say Hotfix 3 fixes it; treat a hit as a full compromise and rotate the administrator, service and integration credentials the platform holds where activity looks unauthorised (Field Effect, 2026-11-09). Ask each IT provider managing your endpoints through N-central whether it runs a server on premises and has upgraded it.

    Updates5

    Update11 Nov 2026 03:49 UTC

    N-able released N-central 2026.4 Hotfix 2, build 2026.4.1.26, on 2026-11-10 as a critical security update; hosted servers are already upgraded, on-premises customers must upgrade their own servers, and every customer must upgrade Agents and Probes, Agents first as N-able recommends (N-able, 2026-11-10). Huntress lists seven CVE ids for the fixed flaws and relays N-able's status-page statement that it observed "scanning activity associated with the published proof-of-concept code" but no evidence that any customer environment was successfully exploited; Huntress has seen no exploitation in its partners' environments, and N-able's guidance is to keep on-premises servers offline until the upgrade is complete (Huntress, 2026-11-10). After the hotfix the built-in remote control is temporarily disabled and Take Control still works (N-able, 2026-11-10).

    Update13 Nov 2026 03:54 UTC

    The researcher's second exploit set, 4EverAble2Shell, published on 2026-11-12, works against Hotfix 2 builds when the Legacy API is turned on and reachable, and no fix exists. It pairs CVE-2026-90436 in the Apache Axis 1.x SOAP engine (Apache Axis project, 2026-11-06) with a separate root escalation (Huntback, 2026-11-12; BleepingComputer, 2026-11-12). Huntback counts at least 21 production servers, 19 of them on Hotfix 2, mining for one operator (Huntback, 2026-11-12), Previdian's sensors recorded attempts at the chain (Previdian, 2026-11-12), and BleepingComputer relays both (BleepingComputer, 2026-11-12). N-able said on 2026-11-12 that it had seen no signs of compromise, had no fix for the new claims and planned a follow-up hotfix (Tenable, 2026-11-12); Huntress says a Hotfix 2 server with the Legacy API disabled is not exposed to this chain (Huntress, 2026-11-12).

    Update14 Nov 2026 04:00 UTC

    The researcher's 2026-11-12 disclosure also includes Agent2Shell, which The Hacker News describes as more than ten zero-day flaws used to run commands as SYSTEM on managed Windows agents, assuming the attacker knows the target appliance ID (The Hacker News, 2026-11-12). Huntress describes it as a set of more than ten issues in how the N-central server communicates with Windows Agents and Probes, two chains of which let an unauthenticated attacker who can reach the server run commands on managed Windows endpoints, including as SYSTEM (Huntress, 2026-11-13). Huntress relays that N-able confirmed Agent2Shell, like 4EverAble2Shell, requires the non-default Legacy API to be enabled, which settles the question Huntress and Tenable had left open on 2026-11-12, and that on 2026-11-13 at 13:40 UTC N-able said it had identified indicators of compromise for customers that have not disabled the Legacy API (Huntress, 2026-11-13); the statement that N-able had seen no signs of compromise dates from 2026-11-12 (Tenable, 2026-11-12). Huntress has not observed exploitation of these issues in its partners' environments, and its Agent2Shell indicators come from static analysis of the proof of concept, not from attacks seen (Huntress, 2026-11-13). Tenable adds that N-able has temporarily deactivated the Intune integration for on-premises customers running it (Tenable, 2026-11-12).

    Update18 Nov 2026 05:12 UTC

    N-able released N-central 2026.4 Hotfix 3, build 2026.4.1.39, on 2026-11-16 as a critical security update that builds on and supersedes Hotfix 2; it fixes 17 further CVE ids, adds missing authentication and permission checks to server operations, hardens how Agents and Probes authenticate with the server, adds validation to file publishing, path and XML import handling, and permanently blocks the legacy APIs (N-able, 2026-11-16). Agents and Probes that are not upgraded are susceptible to impersonation, and all customers, hosted and on-premises, must upgrade every Agent and Probe to 2026.4.1 HF3 whether or not they already run Hotfix 2 (N-able, 2026-11-16).

    The release notes name neither 4EverAble2Shell nor Agent2Shell nor the Apache Axis flaw and do not say they are fixed; what changes is the Legacy API, which N-able itself said both chains need and which is now blocked permanently (N-able, 2026-11-16; Huntress, 2026-11-17). Among the 17 ids, the release notes title CVE-2026-129272 "MMS3 appliance authentication bypass via predictable passcode", CVE-2026-129280 "ServerUI SOAP operations missing authorisation checks" and CVE-2026-129286 "SIS GenericFiles version path traversal leads to RCE", and Huntress counts three critical, eight high and six medium scores, all assigned by N-able as CVE numbering authority (N-able, 2026-11-16; Huntress, 2026-11-17).

    Huntress reports that public proof-of-concept code for all 17 CVE ids appeared on the evening of 2026-11-16, shortly after the hotfix, says any unpatched server should be treated as exposed, and has not observed exploitation of them in its partners' environments (Huntress, 2026-11-17). Field Effect reports that technical details on 24 further N-central vulnerabilities were published and are reported to be addressed by Hotfix 3, a count that the 17 CVE ids in N-able's notes do not reconcile (Field Effect, 2026-11-09). Huntress advises confirming the Patch Management Engine is at 2.14.4.5829 or later, rotating secrets embedded in Automation Manager policies on a server that was exposed before patching, not relying on Take Control audit records from an unpatched server, and enforcing MFA on all N-central accounts (Huntress, 2026-11-17).

    Update22 Nov 2026 14:52 UTC

    CISA added the Apache Axis flaw CVE-2026-90436 to its Known Exploited Vulnerabilities catalog on 2026-11-18 (CISA, 2026-11-18). N-able's own remediation update reads the agent-side risk more narrowly than Huntress: it says the Legacy API is off by default, and that exploiting agent impersonation needs an existing foothold on an endpoint and yields only the information an agent receives and the values an agent can set (N-able, 2026-11-13), while Huntress describes two Agent2Shell chains that let an unauthenticated attacker who can reach the server run commands on managed Windows endpoints (Huntress, 2026-11-17).
