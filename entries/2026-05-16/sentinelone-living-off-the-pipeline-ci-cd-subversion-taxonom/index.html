    SentinelOne "Living Off the Pipeline": attackers subverted TeamCity, GitLab automation, self-hosted runners and developer workstations in 2025

    SentinelOne: attackers turn build servers, CI/CD runners and developer workstations into the intrusion path

    first published 2026-05-16 05:00 UTC

    Analysis

    SentinelOne's post of 2026-05-15 describes how attackers in 2025 went after the infrastructure that builds and ships software, not only its dependencies (SentinelOne, 2026-05-15). In one case attackers exploited a vulnerable self-hosted TeamCity server (the post links JetBrains' advisory for CVE-2023-42793), created a benign-looking build configuration that a trusted build agent ran with SYSTEM privileges, deployed a backdoor into internal environments and stayed undetected for more than a year (SentinelOne, 2026-05-15). JetBrains fixed CVE-2023-42793, an unauthenticated remote-code-execution flaw, in TeamCity On-Premises 2023.05.4 (JetBrains, 2023-09-21) and warned that backdoors planted before the patch persist after it (JetBrains, 2023-10-18). In an intrusion from SentinelOne's annual threat report, a compromised GitLab service-account token was used to create projects with malicious Ansible playbooks that the organization's pipeline then executed automatically (SentinelOne, 2026-05-15).

    The post's other examples target people and runners: Contagious Interview sent developers in cryptocurrency and blockchain fraudulent job offers leading to fake skill-assessment sites, where a fabricated error told them to run commands that silently installed malware with access to their SSH keys, tokens and credentials, and the Sha1-Hulud campaign registered infected systems as self-hosted GitHub runners under attacker-defined names and used workflows that ran code when someone commented in a repository discussion (SentinelOne, 2026-05-15). Malicious versions of popular build packages ran reconnaissance scripts during installation that harvested tokens and inspected environments, and phished maintainer accounts appended malicious code to legitimate package updates (SentinelOne, 2026-05-15).

    Exposure
    Organizations running self-hosted build servers and runners, which SentinelOne notes are often granted broad access to repositories, secrets and deployment workflows (SentinelOne, 2026-05-15); TeamCity On-Premises servers before 2023.05.4 are exposed to CVE-2023-42793 (JetBrains, 2023-09-21).
    Detection
    In CI/CD platform audit logs, new runner registrations and unusual runner names, new or modified pipelines created by service accounts, jobs touching unfamiliar repositories and workflows that open network tunnels; on the build runners themselves, process and credential-access telemetry for suspicious child processes, credential access attempts, reverse tunnels and persistence (SentinelOne, 2026-05-15).

    Triage: compiling, downloading packages, invoking scripts and opening connections are normal build activity, so a malicious job under a valid service account on a trusted runner looks legitimate unless the account acts outside its role; SentinelOne's discriminators are who created the job, what changed, where the runner was registered and which secrets were accessed (SentinelOne, 2026-05-15).

    Defender takeaway
    Treat build servers and runners as high-value systems and alert on runner registrations and pipeline changes made by service accounts (SentinelOne, 2026-05-15). A TeamCity server patched to 2023.05.4 after early October 2023 still needs a compromise assessment of the server and its build agents, because JetBrains says backdoors planted earlier are likely to persist after the patch (JetBrains, 2023-10-18).
