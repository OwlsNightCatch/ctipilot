    Cursor marketplace: a tampered Claude Code extension (versions 2.1.312 and 2.1.313) planted an SSH key, a reverse tunnel and persistence for about eleven hours on 2026-10-29; uninstalling it does not remove the persistence

    Cursor marketplace served a trojanised Claude Code extension for 11 hours; uninstalling leaves the SSH backdoor

    first published 2026-10-31 03:50 UTC

    Defender actions

    • On every developer endpoint that runs Cursor, check extension-install telemetry for Anthropic.claude-code 2.1.312 or 2.1.313 installed between 09:27 and 20:35 UTC on 2026-10-29; where it is found, isolate the host, remove the unauthorized SSH key, the persistence and any running tunnel process, because uninstalling the extension removes none of them, and rotate every credential reachable from the host from a trusted system.

    Analysis

    Between about 2:27am PT and 1:35pm PT on 2026-10-29 (09:27 to 20:35 UTC) a maliciously modified copy of Anthropic's Claude Code extension, versions 2.1.312 and 2.1.313 for macOS and Windows, was served from the Cursor VS Code Extension Marketplace; Cursor removed it, shut the marketplace down briefly, rotated its keys, rebuilt it and had the hosting provider take the attacker's server offline (Cursor, 2026-10-29). Anthropic told Microsoft its systems were not compromised and that it did not build the package, and Microsoft confirms the packages were never published to the Visual Studio Marketplace or npm (Microsoft Threat Intelligence, 2026-10-30). How the attacker published under Anthropic's name is not disclosed in any source read. Cursor estimates up to 5,000 affected users (Sophos X-Ops, 2026-10-30).

    The injected loader runs when the extension module loads. It reports host and user data (hostname, username, operating system, home and working directories, the configured Git email, environment-variable names and public IP address), appends an attacker-controlled SSH public key to authorized_keys, tries to enable the local SSH service and open a reverse SSH tunnel, and installs persistence outside the extension: a LaunchAgent on macOS, and on Windows a scheduled task that asks to run as SYSTEM with a Startup-folder fallback, with background scripts retrying the tunnel about every 60 seconds (Cursor, 2026-10-29). Microsoft's analysis adds a user crontab entry for Linux (Microsoft Threat Intelligence, 2026-10-30). Because of coding errors the step that enables SSH fails unless Cursor was started with administrator privileges, so on most hosts the attacker could not log in through the tunnel, but the key, the persistence and the host report still happened (Cursor, 2026-10-29).

    Exposure
    Any macOS or Windows host on which Cursor installed or auto-updated Anthropic.claude-code 2.1.312 or 2.1.313 inside the window; the code also carries Linux routines though Cursor names only macOS and Windows packages (heise online, 2026-10-30). Extension-install telemetry shows the version. NCSC Switzerland carried the incident on 2026-10-30 but places the backdoored extension on Open VSX and says Anthropic pulled versions from npm and the VS Code marketplace (NCSC Switzerland, 2026-10-30); Microsoft says the packages never reached the Visual Studio Marketplace or npm, and Cursor and Phorion name the Cursor marketplace, so the entry follows them.
    Detection
    In process-creation telemetry, an editor's extension host starting ssh or autossh with remote port forwarding and no command; in file-write telemetry, an editor process modifying authorized_keys; and, shortly after an extension update, a new LaunchAgent, scheduled task, Startup-folder script or @reboot crontab entry named after system-monitoring components. Phorion advises matching the attacker key's fingerprint rather than the comment string it carries (Phorion, 2026-10-30). Removing the extension does not remove the persistence scripts, which keep running (Cursor, 2026-10-29).

    Triage: a running SSH process is not proof the attacker got in, since both ends must allow the connection (Microsoft Threat Intelligence, 2026-10-30); administrators run tunnels too, and what separates this one is an editor extension as the parent process and persistence written to user-writable locations rather than a managed service.

    Defender takeaway
    Treat a host that ran either version as backdoored whether or not the tunnel connected: remove the key, the persistence and the tunnel processes, rebuild where compromise cannot be excluded, and rotate credentials reachable from it. heise reports a cleaned release, with 2.1.314 as the minimum to install (heise online, 2026-10-30).
