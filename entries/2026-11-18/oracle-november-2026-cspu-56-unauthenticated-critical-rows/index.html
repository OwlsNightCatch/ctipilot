    NOTABLECVE-2026-114835 +17NATOA2vulnerability

    Oracle's November 2026 Critical Security Patch Update: 56 of its 62 rows at CVSS 9.0 or above are reachable over the network without authentication, six of them at CVSS 10.0 in Access Manager, WebLogic Server, Platform Security for Java and Business Intelligence Enterprise Edition; no row is marked exploited

    Oracle CSPU: 56 unauthenticated rows at CVSS 9.0+, six at 10.0 in Access Manager, WebLogic, BI; none exploited

    first published 2026-11-18 05:10 UTC

    Defender actions

    • Block T3 and IIOP to every WebLogic Server from networks that untrusted hosts can reach and apply the November 2026 CSPU first to internet-reachable Access Manager, WebLogic Server, E-Business Suite and APEX or REST Data Services instances, because Oracle marks 56 rows at CVSS 9.0 or above as exploitable without authentication and names blocking the required network protocols as its interim measure for attacks that need no privileges.

    Analysis

    Oracle's Critical Security Patch Update of 2026-11-17 carries 655 new patches (Oracle, 2026-11-17). Its risk matrices score 62 rows at CVSS 3.1 9.0 or above, 56 of them marked remotely exploitable without authentication and without privileges (Oracle, 2026-11-17); Tenable counts 62 critical patches across 57 CVEs (Tenable, 2026-11-17). Six of them score 10.0 with changed scope: Oracle Access Manager 12.2.1.4.0 and 14.1.2.1.0 in the Admin Console (CVE-2026-114835) and twice in the Authentication Engine (CVE-2026-91500, CVE-2026-91510), WebLogic Server TopLink Integration (CVE-2026-91569), Platform Security for Java (CVE-2026-114824) and Business Intelligence Enterprise Edition Platform Security (CVE-2026-114784), all over HTTP (Oracle, 2026-11-17).

    WebLogic Server 12.2.1.4.0 to 15.1.1.0.0 carries further unauthenticated rows at 9.8: Core over T3 and IIOP (CVE-2026-91470) and over SOAP (CVE-2026-91456), and TopLink Integration over HTTP (CVE-2026-91570, CVE-2026-91583) and TCP (CVE-2026-91585); Oracle words the T3 and IIOP row as an easily exploitable flaw that lets an unauthenticated attacker with network access compromise WebLogic Server (Oracle, 2026-11-17). E-Business Suite 12.2.3 to 12.2.15 has four unauthenticated HTTP rows at 9.8 in Attachments (CVE-2026-114880), Application Object Library (CVE-2026-114924), Applications Framework REST Services (CVE-2026-114925) and Universal Work Queue (CVE-2026-114863), and APEX and REST Data Services have two at 9.8 over HTTPS (CVE-2026-114849, CVE-2026-114850) (Oracle, 2026-11-17). Oracle's footnote says the patch for the E-Business Suite row CVE-2026-114918 also addresses CVE-2025-61882 (Oracle, 2026-11-17), which CISA lists as exploited with known ransomware use (CISA, 2026-11-17). The release also carries three rows for the Brotli flaw CVE-2026-111497 in Communications Diameter Signaling Router, Communications Unified Assurance and PeopleSoft PeopleTools (Oracle, 2026-11-17).

    Oracle's matrices carry no exploitation flag, and its interim relief is blocking the network protocols an attack requires or, for attacks that need certain privileges or package access, removing those; patches exist only for versions under Premier or Extended Support, and Oracle says earlier versions are likely affected too (Oracle, 2026-11-17).

    Exposure
    Access Manager, WebLogic Server, E-Business Suite, APEX or REST Data Services, Platform Security for Java and Business Intelligence Enterprise Edition instances on the listed versions that untrusted networks can reach over HTTP, HTTPS, SOAP, TCP, T3 or IIOP (Oracle, 2026-11-17).
    Defender takeaway
    Apply the November 2026 patches to internet-reachable identity, middleware, ERP and APEX instances first, and until then block the protocols a row needs, T3 and IIOP for the WebLogic Core row (Oracle, 2026-11-17). Oracle names no per-flaw workaround, so unsupported versions have no vendor fix.
