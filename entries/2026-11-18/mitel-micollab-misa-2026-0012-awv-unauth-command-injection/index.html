    Mitel MiCollab 10.3 (10.3.0.18) and earlier, MISA-2026-0012: an unauthenticated blind command injection in the Audio, Web and Video Conferencing component (CVSS 3.1 10.0) and four more flaws there, one an XML injection that can run commands (9.0); CVE-2026-133323 and CVE-2026-133303 lead the five assigned CVE ids, patch KB000129195, Accenture APEX Labs reports exploitation before the advisory and CISA lists all five as exploited since 2026-11-25

    Mitel MiCollab AWV flaws exploited pre-advisory per Accenture APEX, CISA lists them; patching alone does not evict

    first published 2026-11-18 05:11 UTCupdated 2026-11-27 04:52 UTC

    Defender actions

    • On every MiCollab on 10.3 (10.3.0.18) or earlier whose AWV component was reachable from outside, including through a MiVoice Border Gateway web proxy, take a forensic image first, then apply Mitel's patch KB000129195 (after moving to 10.3.0.18 where needed) and restrict external access to the Audio, Web and Video Conferencing component, then reset the LDAP connector account and any Kerberoastable service accounts and rotate administrator, SIP trunk and file-share credentials, because APEX Labs found exploitation before Mitel's advisory, root within about 30 minutes and directory credentials taken from the LDAP configuration.

    Analysis

    Mitel's advisory MISA-2026-0012, first issued on 2026-11-16, covers five flaws in the Audio, Web and Video Conferencing (AWV) component of MiCollab 10.3 (10.3.0.18) and earlier; Mitel tracks them by internal ids and, since its revision 2.0 of 2026-11-24, lists the CVE identifiers against them (Mitel, 2026-11-16); MITRE published the record for CVE-2026-133323 on 2026-11-19 (ENISA EUVD, 2026-11-19). MTLVULN-1864 lets an unauthenticated attacker conduct a blind command injection through insufficient parameter sanitization and is scored CVSS 3.1 10.0 with changed scope; MTLVULN-1862 lets an unauthenticated attacker leverage pre-staged malicious content for an XML injection that could run arbitrary commands, scored 9.0 with high attack complexity (Mitel, 2026-11-16). Three further flaws are rated Medium: an unauthenticated arbitrary file upload through weak file-type validation (MTLVULN-1861, 5.3), unauthorized access that needs a system-generated random identifier or pre-staged content (MTLVULN-1863, 5.9) and an authentication bypass (MTLVULN-1877, 5.3) (Mitel, 2026-11-16). Mitel says exploiting them together can significantly amplify their impact (Mitel, 2026-11-16).

    Accenture APEX Labs reports exploitation before the advisory: web-shell activity at one victim before 23:00 UTC on 2026-11-15, root within about 30 minutes, and the credentials stored for MiCollab's LDAP connector used against a domain controller 32 minutes after the first request (Accenture APEX Labs, 2026-11-24). The internet-facing reverse proxy at that victim did not stop it, and APEX does not say which of the five flaws were used (Accenture APEX Labs, 2026-11-24).

    The fix is a patch for release 10.3 (10.3.0.18), delivered through knowledge-base article KB000129195 on Mitel's customer portal, or an upgrade to a later release that Mitel does not name; Mitel's partners can supply it to customers without portal access (Mitel, 2026-11-16). Mitel's July advisory named 10.3 (10.3.0.18) as the release that fixed its earlier AWV command injection, so a system moved there in July is inside the new affected range (Mitel, 2026-07-22). CERT-FR lists the advisory on 2026-11-17 (CERT-FR, 2026-11-17); BSI's revision of 2026-11-25 rates it critical, says active exploitation was reported and describes a remote anonymous attacker who can manipulate files, run code with the service's rights and bypass security measures (BSI, 2026-11-25).

    Exposure
    MiCollab 10.3 (10.3.0.18) and earlier whose AWV component external users can reach, including through a reverse proxy or MiVoice Border Gateway web proxy, which APEX says cannot be assumed to protect it (Accenture APEX Labs, 2026-11-24); Mitel assesses only supported versions and states no branch before 10.3 (Mitel, 2026-11-16).
    Detection
    Child processes of the AWV service, new files in the component's upload paths and unauthenticated requests to conferencing endpoints that carry shell metacharacters or XML payloads, which follow from the command-injection, upload and XML-injection mechanisms the advisory names (Mitel, 2026-11-16). APEX adds POSTs to AWV CGI scripts from unfamiliar sources followed by requests for new files in the web pictures directory, the LDAP connector account authenticating to many domain controllers, and system logs that suddenly shrink (Accenture APEX Labs, 2026-11-24).
    Defender takeaway
    Apply the patch now; where that waits, restrict external access to the AWV component, the mitigation Mitel names (Mitel, 2026-11-16). APEX says patching alone will not close an intrusion that started earlier, and the actor filtered local logs: image the server first, compare its logs with proxy and WAF logs, and treat a suspected compromise as a directory compromise by resetting the LDAP connector account and Kerberoastable service accounts (Accenture APEX Labs, 2026-11-24).

    Improvement20 Nov 2026 05:11 UTC

    MITRE published CVE records for all five flaws on 2026-11-19, which Mitel's advisory page did not yet list on that date. MTLVULN-1864 is CVE-2026-133323, the blind command injection (CVSS 3.1 10.0) (ENISA EUVD, 2026-11-19); MTLVULN-1862 is CVE-2026-133303, the XML injection that leverages pre-staged content (9.0) (ENISA EUVD, 2026-11-19); MTLVULN-1861 is CVE-2026-133275, the file upload (5.3) (ENISA EUVD, 2026-11-19); MTLVULN-1863 is CVE-2026-133311, the unauthorized access that needs an identifier or pre-staged content (5.9) (ENISA EUVD, 2026-11-19); and MTLVULN-1877 is CVE-2026-133324, the authentication bypass (5.3) (ENISA EUVD, 2026-11-19). Each record's score and affected range match Mitel's table, so the patch and the access restriction above are unchanged.

    Update26 Nov 2026 05:05 UTC

    CISA added all five MiCollab AWV flaws to its Known Exploited Vulnerabilities catalogue on 2026-11-25 (CISA, 2026-11-25). The catalogue describes CVE-2026-133323 as an OS command injection in the Audio, Web and Video Conferencing component that could allow an unauthenticated attacker to execute arbitrary system commands, and lists CVE-2026-133303 (XML injection), CVE-2026-133275 (unrestricted file upload), CVE-2026-133311 (weak authentication) and CVE-2026-133324 (not failing securely) with it (CISA KEV catalogue, 2026-11-25). The catalogue names no actor, victim, campaign or technique and does not say which of the five was used.

    Mitel's advisory, revised to version 2.0 on 2026-11-24, lists the CVE ids against its tracking ids, still makes no exploitation statement, and adds that the security update will be included in later MiCollab releases without naming one; the affected range, the patch and the access restriction are unchanged (Mitel, 2026-11-16). As of that revision, no source read named an exploiting actor, a victim or the number of systems hit.

    Update27 Nov 2026 04:52 UTC

    Accenture APEX Labs reports that the MISA-2026-0012 flaws were exploited before Mitel published its advisory and patch. At one victim organisation it places web-shell activity before 23:00 UTC on 2026-11-15, with high confidence, when it was still 15 November in every time zone from UTC−12 to UTC+1 and Mitel dated its advisory 16 November (Accenture APEX Labs, 2026-11-24). Counted from the first observed request, the actor checked the version, bypassed authentication within a minute, had two uploads accepted at 9 minutes, ran its first web-shell command as the web service account at 12 minutes, reached root between 15 and 30 minutes with system logs reset as a side effect, and at 32 minutes used the credentials recovered from MiCollab's LDAP configuration to authenticate to a domain controller over LDAPS; it then filtered web-shell requests out of the local web, error and admin logs and, 20 to 23 hours in, dumped databases on a backup server and a database server and uploaded the archives over many short HTTPS sessions (Accenture APEX Labs, 2026-11-24). APEX withholds how root was obtained and does not say which of the five flaws were used.

    A second organisation's MiCollab server, on a 10.0-series release exposed to this advisory and to the July one, has held a persistent HTTPS channel to the same actor server since 2026-11-09, and APEX has not determined how it was compromised. APEX assesses that AI-assisted tooling operating on the actor's server drove parts of the intrusion, an inference from sampled traffic to two commercial AI API services that it says cannot show exactly how they were used, and it names no group (Accenture APEX Labs, 2026-11-24). Mitel's advisory is unchanged at revision 2.0 and makes no exploitation statement; BSI's revision of 2026-11-25 rates it critical and says active exploitation was reported (BSI, 2026-11-25).
