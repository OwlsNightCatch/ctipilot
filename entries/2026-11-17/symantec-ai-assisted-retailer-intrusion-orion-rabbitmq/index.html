    Symantec: a September 2026 intrusion at a US retailer shows attackers switching to AI-generated PowerShell and, about ten minutes after first querying SolarWinds Orion, using the RabbitMQ Erlang cookie bundled with it to run a command on a second server

    Symantec: AI-assisted retailer intrusion pivots through SolarWinds Orion's bundled RabbitMQ Erlang cookie

    first published 2026-11-17 04:39 UTC

    Analysis

    Symantec's Threat Hunter Team describes a September 2026 intrusion at a US retail organization in which the attackers first worked by hand on a compromised web server, with typing errors and every staged payload terminated by security software, and then, the next day, submitted about 50 long, error-free PowerShell scripts over roughly two hours, with labelled output sections and comments that read as a model's reasoning (Symantec, 2026-11-12). Symantec assesses AI assistance with high confidence and an operator relaying output to an AI tool, not an autonomous agent, with moderate confidence; it could not identify the model (Symantec, 2026-11-12). The initial infection vector is unknown (Symantec, 2026-11-12).

    The earliest activity, on 2026-09-18, ran cmd.exe directly under sqlservr.exe on three SQL Servers, which Symantec reads as commands issued through the database service, most likely xp_cmdshell; on one host the attackers compiled the public EfsPotato exploit with csc.exe from base64 text decoded by certutil and saved the SAM, SYSTEM and SECURITY hives (Symantec, 2026-11-12). On a web server compromised through w3wp.exe they side-loaded payloads with a legitimate Bitdefender executable (bdreinit.exe with log.dll) and a G DATA executable (ask.exe with ask.dll) from ProgramData, used a utility called BreakChain to relaunch them so they no longer appeared as children of w3wp.exe, copied one to a file named w3wp.exe, and planted ASP web shells in the application's images folder (Symantec, 2026-11-12). The AI-style scripts then harvested credentials from connection strings, FileZilla, WinSCP and PuTTY settings, saved RDP files and IIS configuration, read the Erlang cookie file of the RabbitMQ broker that ships with Orion; running Orion's bundled erl.exe with that cookie, they called the broker on a second web server to run an encoded operating system command (Symantec, 2026-11-12). Later activity searched a probable domain controller for NTDS.dit, SYSVOL cpassword values and LAPS passwords and ran a Chisel tunnelling tool and a password sprayer (Symantec, 2026-11-12).

    Symantec says no second-phase technique was new and suggests a possible link, through a shared address and the retail focus, to the operation Gambit Security described on 2026-09-22 (Symantec, 2026-11-12). No Swiss or public-sector victim is named; the case matters for the transferable chain and its AI-assisted tempo.

    Exposure
    Windows estates running SolarWinds Orion with its bundled RabbitMQ broker alongside SQL Server hosts and IIS web applications; the Erlang cookie file on the Orion host is the pivot.
    Detection
    Process-creation telemetry with parent lineage for cmd.exe or PowerShell started under sqlservr.exe or w3wp.exe, csc.exe started by PowerShell on a server, certutil decoding a text file in ProgramData, a vendor-signed executable running from ProgramData beside an unsigned DLL, an executable named w3wp.exe outside the IIS directory, and erl.exe started from the Orion directory with a cookie argument and a remote broker call; registry hive save events for SAM, SYSTEM and SECURITY.

    Triage: long, labelled PowerShell is not the signal on its own, because administrators write such scripts too; a parent of sqlservr.exe or w3wp.exe rather than an administrator session, credential-store targets and a blocked loader returning rebuilt are.

    Defender takeaway
    Hunt SQL Server and IIS hosts for this lineage, treat an Orion server as a lateral-movement bridge to every host that runs its RabbitMQ node, and alert on behavior rather than file names, since the tools were renamed and rebuilt after each block.
