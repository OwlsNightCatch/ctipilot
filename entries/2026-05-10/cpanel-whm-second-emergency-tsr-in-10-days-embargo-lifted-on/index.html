    cPanel & WHM security update of 2026-05-08: CVE-2026-29202 Perl code injection, CVE-2026-29203 symlink chmod and CVE-2026-29201 arbitrary file read

    cPanel patches authenticated Perl code injection (CVE-2026-29202) and two file-permission flaws across cPanel & WHM

    first published 2026-05-10 05:00 UTC

    Analysis

    cPanel published patches and one advisory per CVE for three cPanel & WHM and WP Squared vulnerabilities on 2026-05-08 (cPanel, CVE-2026-29202). CVE-2026-29202 is a Perl code-injection flaw in the plugin parameter of the create_user API call (cPanel, CVE-2026-29202) that gives arbitrary Perl code execution as the already authenticated account's system user (The Hacker News, 2026-05-09). CVE-2026-29203 is an unsafe symlink handling error that lets a user chmod an arbitrary file, allowing denial of service and possible privilege escalation (cPanel, CVE-2026-29203). CVE-2026-29201 is an arbitrary file read in the feature::LOADFEATUREFILE adminbin call, where a relative path in the feature file name makes an arbitrary file world-readable (cPanel, CVE-2026-29201). The CVE records, as ENISA's EUVD carries them, score CVE-2026-29202 and CVE-2026-29203 at 5.3 under CVSS 4.0 (EUVD-2026-28811; EUVD-2026-28812) and CVE-2026-29201 at 8.6 under CVSS 3.1 with no privileges required (EUVD-2026-28810); The Hacker News reports 8.8, 8.8 and 4.3, and no evidence of exploitation in the wild as of 2026-05-09 (The Hacker News, 2026-05-09).

    The fixed releases are cPanel & WHM version 11.136.0.9, 11.134.0.25, 11.132.0.31, 11.130.0.22, 11.126.0.58, 11.124.0.37, 11.118.0.66, 11.110.0.117, 11.102.0.41, 11.94.0.30 and 11.86.0.43 or higher, WP Squared version 11.136.1.11 or higher, and version 11.110.0.116 as a direct update for CentOS 6 and CloudLinux 6 (cPanel, CVE-2026-29202). The update followed by ten days cPanel's advisory for CVE-2026-41940, an authentication bypass (cPanel, CVE-2026-41940) that hosting provider KnownHost reported exploited in the wild since 2026-02-23 (SecurityWeek, 2026-04-30); Shadowserver counted at least 44,000 IP addresses likely compromised through it scanning its honeypots on 2026-04-30 (The Hacker News, 2026-05-04).

    Exposure
    Every cPanel & WHM and WP Squared server below the fixed release of its branch; CVE-2026-29202 needs an authenticated account (The Hacker News, 2026-05-09) and CVE-2026-29203 a user on the server (cPanel, CVE-2026-29203). The patch ships through the standard automatic update, so servers with automatic updates disabled or version-pinned in the update configuration are the ones left behind (NCSC-CH, 2026-05-08), and the running version is read with /usr/local/cpanel/cpanel -V (cPanel, CVE-2026-29202).
    Detection
    File-permission telemetry on the server: the two file flaws show as system files made world-readable through the adminbin call (cPanel, CVE-2026-29201) or chmod'ed through a symlink by a user account (cPanel, CVE-2026-29203).
    Defender takeaway
    No out-of-band action where automatic updates run; on pinned or manually updated servers run /scripts/upcp --force and confirm the version afterwards, as cPanel instructs (cPanel, CVE-2026-29202).
