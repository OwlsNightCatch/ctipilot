    Showboat Linux post-exploitation framework and JFMBackdoor for Windows used against telecom providers; PwC attributes the operation to Red Lamassu (Calypso)

    Lumen and PwC detail Showboat, a Linux implant that hides and proxies inside telcos, and Red Lamassu's JFMBackdoor

    first published 2026-05-22 05:00 UTC

    Analysis

    Lumen's Black Lotus Labs published Showboat on 2026-05-20: a modular Linux post-exploitation framework, used since at least mid-2022, that spawns a remote shell, uploads and downloads files, acts as a SOCKS5 proxy and port mapper into internal hosts, can persist as a service and swap C2 nodes, and has a "hide" command that conceals its process with code fetched from Pastebin or online forums used as a dead drop (Lumen, 2026-05-20). It reports the host data it gathers in a PNG field as an encrypted, base64-encoded string, and Lumen found it on VirusTotal rather than on a live system, so the initial access vector is unknown (Lumen, 2026-05-20). PwC, publishing in tandem on 2026-05-21, found a Showboat sample, which it calls kworker, in an open directory active from July to October 2025 next to JFMBackdoor: a batch script downloads the files into the victim's temp directory and runs the legitimate fltMC.exe, which side-loads a malicious FLTLIB.dll that decrypts its configuration and loads the backdoor in memory through a shellcode stub; JFMBackdoor then offers a remote shell, full file operations including timestomping, TCP proxying and screenshots it base64-encodes and XOR-encrypts for exfiltration (PwC, 2026-05-21). Lumen's telemetry confirms two victims, an Afghanistan-based ISP whose Outlook server talked to a C2 node from 2025-12-01 to 2026-02-03 and an entity in Azerbaijan, finds two potential compromises in the United States, and links C2 traffic with the Donbas region, with moderate confidence, to a separate cluster sharing the tooling; the C2 nodes cluster on a shared self-signed certificate (Lumen, 2026-05-20). PwC ties the open directory to a telecommunications provider in Afghanistan and attributes it to Red Lamassu (also known as Calypso), a China-based actor likely operating from Sichuan Province that it has tracked since 2019 against telecom organizations in Asia (PwC, 2026-05-21), while Lumen attributes Showboat only to at least one and likely several PRC-aligned clusters (Lumen, 2026-05-20).

    Exposure
    Telecommunications providers, chiefly in Asia and the Middle East (PwC, 2026-05-21) (Lumen, 2026-05-20), and in particular their Linux servers and routers, which Lumen notes typically run no EDR (Lumen, 2026-05-20).
    Detection
    Network and host telemetry on Linux servers: east-west traffic from servers that does not map to a business process, which Lumen recommends monitoring, and, from Showboat's functions, a server process fetching Pastebin or forum content, a SOCKS5 listener or port mapper on a server, and a new service persisting an unfamiliar binary (Lumen, 2026-05-20). On Windows, a legitimate binary such as fltMC.exe launched from the temp directory next to a FLTLIB.dll is the side-loading pattern PwC describes (PwC, 2026-05-21).
    Defender takeaway
    Telecom operators hunt their Linux server and router estate for these behaviors rather than waiting for EDR alerts; Lumen calls the presence of such implants an early warning sign of broader compromise (Lumen, 2026-05-20).

    Correction21 Oct 2026 20:43 UTC

    The confirmed victims are an Afghanistan-based ISP and an entity in Azerbaijan; Lumen calls the US cases potential compromises, links the traffic from Ukraine's Donbas region with moderate confidence to a separate cluster sharing the tooling, and neither source places European telecoms in the targeting (Lumen, 2026-05-20). Showboat is not described as masquerading as a kernel worker thread: kworker is PwC's name for the malware and the sample PwC found was named systemd-ac-update (PwC, 2026-05-21), while Lumen documents process hiding and service persistence (Lumen, 2026-05-20).

    The campaign dates from at least mid-2022 (Lumen, 2026-05-20), whereas PwC has tracked Red Lamassu since 2019; JFMBackdoor offers remote shell access, file system operations, network proxying, screenshot capture and self-removal (PwC, 2026-05-21); and the self-signed certificate clusters the C2 nodes rather than linking the victims (Lumen, 2026-05-20).
