    Windows BitLocker "YellowKey" (CVE-2026-45585) and CTFMON "GreenPlasma" (CVE-2026-45586) zero-days: public PoCs in May, fixed in the June 2026 Windows updates

    Leaked BitLocker bypass "YellowKey" and CTFMON privilege escalation "GreenPlasma" were fixed in the June 2026 updates

    first published 2026-05-15 05:00 UTCupdated 2026-10-21 15:38 UTC

    Analysis

    On 2026-05-13 BleepingComputer and The Register reported that the researcher Nightmare Eclipse (also Chaotic Eclipse) had published exploit code for two Windows zero-days, YellowKey and GreenPlasma (BleepingComputer, 2026-05-13) (The Register, 2026-05-13). The researcher's earlier BlueHammer (CVE-2026-33825) and RedSun drops began to be exploited in the wild shortly after release (BleepingComputer, 2026-05-13).

    YellowKey is a BitLocker bypass that needs physical access. The researcher says it affects Windows 11 and Windows Server 2022/2025 and works by placing crafted FsTx files on a USB drive or the EFI partition, rebooting into the Windows Recovery Environment (WinRE) and holding CTRL to trigger a shell (BleepingComputer, 2026-05-13). Will Dormann reproduced it with the files on a USB drive but not on the EFI partition: to boot WinRE, Windows replays the NTFS logs in \System Volume Information\FsTx directories on attached drives, the replay deletes X:\Windows\System32\winpeshl.ini, and WinRE then opens CMD.EXE instead of the recovery environment, with the disk still unlocked (BleepingComputer, 2026-05-13). Because it abuses TPM-only automatic unlock, the public exploit works only on the original device, not on a removed drive, and does not work with TPM+PIN (BleepingComputer, 2026-05-13). Microsoft tracks it as CVE-2026-45585, a security feature bypass by physical attack (CWE-77, CVSS 6.8), publicly disclosed and not exploited; its fixed builds are Windows 11 24H2 build 10.0.26100.8655, 25H2 build 10.0.26200.8655, 26H1 build 10.0.28000.2269 and Windows Server 2025 build 10.0.26100.32995, and its product table does not list Windows Server 2022 (MSRC CVE-2026-45585).

    Contradiction: the researcher says an unpublished variant also defeats TPM+PIN (BleepingComputer, 2026-05-13); Microsoft states that "if you are using TPM+PIN the vulnerability is not exploitable" (MSRC CVE-2026-45585).

    GreenPlasma is a local privilege escalation in CTFMON: an unprivileged user can create arbitrary memory-section objects within directory objects writable by SYSTEM, and the leaked PoC lacks the component needed for a full SYSTEM shell (BleepingComputer, 2026-05-13); in its current state it triggers a UAC consent prompt in default Windows configurations (The Register, 2026-05-13). Microsoft tracks it as CVE-2026-45586, a link-following flaw (CWE-59, CVSS 7.8) in the Windows Collaborative Translation Framework that lets an authorized local attacker gain SYSTEM privileges, released on 2026-06-09 with fixes for Windows 10, Windows 11 and Windows Server 2012 to 2025, publicly disclosed and not exploited (MSRC CVE-2026-45586).

    Exposure
    For YellowKey, TPM-only BitLocker devices (BleepingComputer, 2026-05-13) on Windows 11 24H2, 25H2 or 26H1 or Windows Server 2025 below the fixed builds, given physical access (MSRC CVE-2026-45585). For GreenPlasma, any Windows 10, Windows 11 or Windows Server 2012 to 2025 system without the June 2026 update, for an attacker who already runs code as a local user (MSRC CVE-2026-45586).
    Detection
    No cited source describes an artifact YellowKey leaves inside Windows; the attacker's media carries \System Volume Information\FsTx directories that WinRE replays at boot (BleepingComputer, 2026-05-13). GreenPlasma's public partial PoC raises a UAC consent prompt in default configurations (The Register, 2026-05-13).
    Defender takeaway
    The June 2026 Windows update fixes YellowKey (MSRC CVE-2026-45585) and GreenPlasma (MSRC CVE-2026-45586), and Microsoft's interim WinRE script need not be reverted, since the update keeps its behavior (MSRC CVE-2026-45585). Microsoft says TPM+PIN makes YellowKey not exploitable (MSRC CVE-2026-45585), which the researcher disputes (BleepingComputer, 2026-05-13), and Kevin Beaumont advised TPM+PIN along with a BIOS password (BleepingComputer, 2026-05-13).

    Updates2

    Update20 May 2026 05:00 UTC

    Microsoft formally assigned CVE-2026-45585 to the BitLocker / WinRE bypass disclosed by "Nightmare Eclipse" on 2026-05-12 and confirmed there is still no security update. The MSRC update guide entry, published 2026-05-19, classifies it as CWE-77 (command injection in BitLocker / Windows Recovery Environment), CVSS 6.8 (AV:P/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H), with exploit-code maturity rated E:P (proof-of-concept) and remediation level RL:W (workaround only).

    Microsoft's interim mitigation, which it recommends that customers "consider implementing" if they are concerned their devices and data are at risk of being compromised or stolen, is per-device work: mount the WinRE image, remove the autofstx.exe entry from the BootExecute registry value inside the WinRE image, commit the image, then re-establish BitLocker trust for WinRE (MSRC CVE-2026-45585). The MSRC FAQ states: "A successful attacker could bypass the BitLocker Device Encryption feature on the system storage device. An attacker with physical access to the target could exploit this vulnerability to gain access to encrypted data."

    A pre-boot PIN avoids depending on the WinRE edit: the public exploit relies on TPM-only automatic unlock and does not work with TPM+PIN (BleepingComputer, 2026-05-13), and NCSC-CH advises that BIOS passwords and a BitLocker PIN mitigate the current public PoC (NCSC-CH Security Hub #12574, 2026-05-14).

    Update21 Oct 2026 15:38 UTC

    Microsoft fixed both flaws in the June 2026 Windows updates of 2026-06-09. Revision 2 of the CVE-2026-45585 record "Added links to June 2026 Windows security updates", with fixed builds Windows 11 24H2 build 10.0.26100.8655, 25H2 build 10.0.26200.8655, 26H1 build 10.0.28000.2269 and Windows Server 2025 build 10.0.26100.32995 (MSRC CVE-2026-45585). GreenPlasma received its own identifier, CVE-2026-45586, released the same day with fixes for Windows 10, Windows 11 and Windows Server 2012 to 2025 (MSRC CVE-2026-45586), and BleepingComputer reported that the June 2026 Patch Tuesday fixed GreenPlasma, MiniPlasma and YellowKey (BleepingComputer, 2026-06-10). Before the fix, on 2026-05-21, Microsoft had replaced its manual WinRE steps with a script that removes autofstx.exe from the WinRE BootExecute value and re-seals WinRE so BitLocker trust remains intact (MSRC CVE-2026-45585). Microsoft marks neither flaw as exploited (MSRC CVE-2026-45585) (MSRC CVE-2026-45586).
