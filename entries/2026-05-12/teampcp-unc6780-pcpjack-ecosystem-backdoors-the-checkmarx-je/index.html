    Checkmarx Jenkins AST plugin backdoored: rogue build 2026.5.09 swept build hosts for credentials on 2026-05-09/10, the third wave of malicious Checkmarx artifacts since March (TeamPCP claimed)

    A rogue Checkmarx Jenkins AST plugin build that hunts credentials was live for about 31 hours; TeamPCP claimed it

    first published 2026-05-12 05:00 UTC

    Analysis

    On Saturday 2026-05-09 a rogue build, version 2026.5.09, of the Checkmarx Jenkins AST plugin was uploaded to repo.jenkins-ci.org outside the plugin's release pipeline; it broke the plugin's version scheme and had no git tag or GitHub release (BleepingComputer, 2026-05-11). Checkmarx says an external service account modified the plugin and published it to the Jenkins Marketplace, that the malicious window ran from 2026-05-09 01:25 UTC to 2026-05-10 08:47 UTC, and that the attacker used access obtained in the March incident, which began with credentials taken in the Trivy supply-chain attack on 2026-03-19 (Checkmarx, updated 2026-07-06). It is the third wave of malicious Checkmarx artifacts after GitHub Actions and Open VSX extensions on 2026-03-23 and a KICS Docker image, VS Code and DevAssist extensions and a GitHub Action on 2026-04-22 (Checkmarx, updated 2026-07-06). The payload determines the operating system (Windows, Linux or macOS), then walks a list of file paths for common applications on that system looking for credentials, with crypto wallets, VPNs, AWS and GitHub among the targets; Checkmarx had found no references to Jenkins in it, and Mandiant found no threat-actor access to the Checkmarx One SaaS environment (Checkmarx, updated 2026-07-06).

    TeamPCP claimed the compromise (BleepingComputer, 2026-05-11), and researcher Adnan Khan and SOCRadar report that the group gained access to the plugin's GitHub repository and renamed it "Checkmarx-Fully-Hacked-by-TeamPCP-and-Their-Customers-Should-Cancel-Now", with the description "Checkmarx fails to rotate secrets again. with love – TeamPCP" (The Hacker News, 2026-05-11). Google Threat Intelligence Group tracks TeamPCP as UNC6780 and says that in the late-March compromises (Trivy, Checkmarx, LiteLLM, BerriAI) the group embedded the SANDCLOCK credential stealer to extract cloud secrets such as AWS keys and GitHub tokens from build environments (GTIG, 2026-05-11).

    Exposure
    Any Jenkins instance that installed or updated the Checkmarx AST plugin to build 2026.5.09 during the malicious window (SOCRadar, 2026-05-11); Checkmarx names 2.0.13-829.vc72453fa_1c16 of 2025-12-17 or earlier and the clean replacements 2.0.13-848.v76e89de8a_053 and 2.0.13-847.v08c0072b_2fd5 as safe (Checkmarx, updated 2026-07-06).
    Detection
    In Jenkins plugin inventories and update history, the checkmarx-ast-scanner plugin at version 2026.5.09; on hosts that ran it, file-access telemetry showing the build process reading the credential files of wallets, VPN clients, AWS and GitHub, which is what the payload's path sweep produces (Checkmarx, updated 2026-07-06). Checkmarx also advises restricting CI runner egress to an allowlist and monitoring outbound connections for unexpected domains (Checkmarx, updated 2026-07-06).
    Defender takeaway
    Where a pipeline ran build 2026.5.09, rotate all credentials that pipeline had access to, as Checkmarx recommends (Checkmarx, updated 2026-07-06), and investigate for lateral movement or persistence (BleepingComputer, 2026-05-11). Checkmarx's standing advice holds beyond this build: pin to specific SHAs rather than mutable tags and treat CI runner credentials as short-lived and tightly scoped (Checkmarx, updated 2026-07-06).

    Correction21 Oct 2026 15:57 UTC

    No CVE covers the rogue plugin build: CVE-2026-33634 is the Trivy flaw in which a threat actor used compromised credentials on 2026-03-19 to publish a malicious Trivy release and move the trivy-action tags to credential-stealing code (GitHub Advisory Database, 2026-03-21), the attack Checkmarx names as the source of the attacker's access (Checkmarx, updated 2026-07-06). No source names SANDCLOCK as the Jenkins payload; GTIG uses the name for the stealer of the late-March compromises and describes it extracting cloud secrets such as AWS keys and GitHub tokens, not LLM API keys (GTIG, 2026-05-11). Checkmarx lists crypto wallets, VPNs, AWS and GitHub among the applications the payload targets, and Mandiant found no threat-actor access to the Checkmarx One SaaS environment (Checkmarx, updated 2026-07-06).

    The earlier waves were GitHub Actions and Open VSX extensions in March and the KICS Docker image with updated extensions and a GitHub Action in April (Checkmarx, updated 2026-07-06). PCPJack is a separate cloud worm whose first act is to evict TeamPCP tooling (SentinelLABS, 2026-05-07), and no cited source links it to the plugin. The defacement renamed the plugin's GitHub repository, not the build (The Hacker News, 2026-05-11), and exposure did not depend on auto-update: any instance that pulled build 2026.5.09 during the window installed the compromised plugin (SOCRadar, 2026-05-11).
