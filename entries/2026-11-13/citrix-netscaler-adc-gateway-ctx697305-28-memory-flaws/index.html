    Citrix NetScaler ADC and Gateway: 28 flaws fixed on 2026-11-12, among them CVE-2026-120868 (CVSS 4.0 9.3) in packet processing on every deployment in default configuration, plus an unauthenticated NetScaler Console authentication bypass (CVE-2026-120869); no exploitation reported

    NetScaler: 28 flaws fixed, one reaches every default ADC and Gateway; update to 14.1-73.57 or 13.1-64.39

    first published 2026-11-13 04:00 UTC

    Defender actions

    • Upgrade every customer-managed NetScaler ADC and Gateway to 14.1-73.57, 13.1-64.39 (14.1-73.58 FIPS; 13.1-37.293 for 13.1-FIPS and 13.1-NDcPP) and the NetScaler Console to 14.1-74.34, internet-facing Gateway and AAA appliances first, because CVE-2026-120868 affects every unpatched appliance in default configuration and neither bulletin offers a workaround; keep the management address (NSIP) and the Console IP off networks that untrusted hosts can reach.

    Analysis

    Cloud Software Group's bulletin CTX697305 of 2026-11-12 fixes 28 flaws in customer-managed NetScaler ADC and NetScaler Gateway (Cloud Software Group, 2026-11-12). The bulletin describes the impact as unpredictable or erroneous behaviour or denial of service, while its CVSS 4.0 vectors score confidentiality, integrity and availability impact High on ten rows, and no source says that code execution is possible (CERT-EU, 2026-11-12). The row that applies everywhere is CVE-2026-120868 (9.3), a memory overflow in packet processing with the precondition "All NetScaler ADC and NetScaler Gateway deployments (Default configuration / No additional feature required)" and no authentication or user interaction (Cloud Software Group, 2026-11-12). CVE-2026-107412 (9.5) covers several overflows on an appliance configured as a Gateway (SSL VPN, ICA Proxy, CVPN or RDP Proxy) or an AAA virtual server, which CERT-EU, citing the vendor, says can be reached without authentication (CERT-EU, 2026-11-12); further rows at 9.3 or 8.7 each depend on one configured feature, such as an SMPP, DNS-over-HTTPS or PUSH virtual server or a SAML, WebAuth, email OTP, certificate or LDAP authentication action, and CVE-2026-120863 needs only a path from an untrusted host to the management address NSIP or NSIP6 (Cloud Software Group, 2026-11-12). Bulletin CTX697320 fixes CVE-2026-120869, an unauthenticated authentication bypass on the NetScaler Console, scored 9.4 with an adjacent vector in the bulletin (Cloud Software Group, 2026-11-12) and 9.3 with a network vector in ENISA's record (ENISA EUVD, 2026-11-12).

    The fixed builds are 14.1-73.57, 13.1-64.39, 14.1-73.58 FIPS and 13.1-37.293 for 13.1-FIPS and 13.1-NDcPP (Cloud Software Group, 2026-11-12), and 14.1-74.34 for the Console (Cloud Software Group, 2026-11-12); Secure Private Access Hybrid deployments must upgrade their NetScaler instances (Cloud Software Group, 2026-11-12). Neither bulletin states an exploitation status or a workaround. CERT-EU writes that Citrix reports no exploitation and no confirmed public proof of concept (CERT-EU, 2026-11-12), NCSC Switzerland lists the exploitation status as unknown (NCSC Switzerland, 2026-11-12), and none of the CVEs is in CISA's catalog. heise reports that Citrix will publish NetScaler security fixes monthly on a fixed date close to Patch Tuesday from now on, with out-of-cycle updates for urgent cases such as active exploitation (heise, 2026-11-12).

    Exposure
    Every customer-managed NetScaler ADC or Gateway below the fixed build of its branch is in scope for CVE-2026-120868 whatever its configuration; the other rows apply where the named feature is configured, which the bulletin tells you to find with configuration searches such as add vpn vserver, add authentication vserver or add authentication samlAction (Cloud Software Group, 2026-11-12).
    Detection
    No source states a detection method or a check for compromise. The stated impact is a crash or denial of service, so unexplained packet-engine restarts, core files or reboots after inbound traffic to a Gateway or AAA virtual server are the telemetry to review; this is an inference, not a source statement. Where a logout had occurred, /var/log/httperror.log can hold authentication material (one of the rows), so limit who can read that file (Cloud Software Group, 2026-11-12).
    Defender takeaway
    Upgrade internet-facing Gateway and AAA appliances first, then every other ADC, to the fixed build of the branch, because CVE-2026-120868 needs no feature (CERT-EU, 2026-11-12) and neither bulletin offers a workaround (Cloud Software Group, 2026-11-12; Cloud Software Group, 2026-11-12); keep NSIP and the Console IP on a management network.
