    Cisco's final PHP2Shell advisory: Expressway needs 15.5.21, Duo Access Gateway 3.2.0; Cisco knows of no malicious use

    first published 2026-10-28 03:50 UTCupdated 2026-10-31 03:41 UTC

    Defender actions

    • Upgrade every Cisco Expressway-C, Expressway-E and Expressway Select unit to 15.5.21, including units already moved to X15.5.20 for CVE-2026-76466, which Cisco's table does not name as the PHP2Shell fix, and until then apply the workaround in bug CSCwx37062; take any Duo Access Gateway to 3.2.0.

    Analysis

    Cisco's advisory cisco-sa-php-october26-Jj384Daq, published on 2026-10-21 and final at version 1.10 on 2026-10-30, lists Expressway, Ultra-Reliable Wireless Backhaul, Duo Access Gateway and ISE Portal Builder as affected by CVE-2026-109618 and CVE-2026-109619, the PHP flaws behind PHP2Shell (Cisco PSIRT, 2026-10-30). Expressway Series and Expressway Select Series (bug CSCwx37062) have fixed release 15.5.21 and a workaround described in the bug record; Ultra-Reliable Wireless Backhaul and Unified Industrial Wireless Software (bug CSCwx37073) have fixed release 26.2.1.9, listed for November 2026, and a workaround, and there the attacker must be authenticated as an administrator, which lowers the CVSS 3.1 score to 6.6; Duo Access Gateway is fixed in 3.2.0; and ISE Portal Builder has a fix deployed with no customer action required (Cisco PSIRT, 2026-10-30). The advisory gives no affected-version ranges and no workaround steps; its bug records carry platform-specific information, workarounds and fixed releases, and a product it does not list is, in Cisco's review, not affected (Cisco PSIRT, 2026-10-28).

    Cisco says it is aware that a public announcement is available and knows of no malicious use of the flaws against any Cisco product (Cisco PSIRT, 2026-10-28); CISA added both flaws to its Known Exploited Vulnerabilities catalog on 2026-10-26 (CISA KEV, 2026-10-27). For Expressway the PHP fix is 15.5.21 (Cisco PSIRT, 2026-10-28), while the release Cisco names for the unauthenticated root command execution on clustered units, CVE-2026-76466, is X15.5.20 (Cisco PSIRT, 2026-10-21).

    Exposure
    Every Expressway Series and Expressway Select unit and every Duo Access Gateway not on a release Cisco lists as fixed (15.5.21 and 3.2.0), since Cisco gives no affected-version ranges; the advisory names no version-check command and no component that runs the PHP; its bug records CSCwx37062 and CSCwx37073 carry platform-specific information (Cisco PSIRT, 2026-10-28).
    Detection
    Cisco publishes no indicator and reports no attack on its products, but lists Snort rules 67359 and 67360 as action links for the advisory (Cisco PSIRT, 2026-10-28); beyond that, CISA's PHP alert advises monitoring for PHP worker processes launching shells or downloading tools (CISA, 2026-10-21), which on these products would be processes started by the web worker account (an inference, since Cisco does not describe how they run PHP).
    Defender takeaway
    Move Expressway to 15.5.21 and Duo Access Gateway to 3.2.0, the fixed releases the table names (Cisco PSIRT, 2026-10-28); an Expressway already upgraded to X15.5.20 for the clustered-device flaw (Cisco PSIRT, 2026-10-21) is not named as fixed in the PHP table, which lists only 15.5.21 (an inference from the table, not a Cisco statement), so apply the bug record's workaround until 15.5.21 is installed (Cisco PSIRT, 2026-10-28). Ultra-Reliable Wireless Backhaul has no fixed release before November 2026, so its workaround is the control until then.
