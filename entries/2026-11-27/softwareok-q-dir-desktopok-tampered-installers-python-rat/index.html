    SoftwareOK: Q-Dir 12.83 to 12.85 and DesktopOK 12.82 and 12.85 installers from the vendor's official site carried a Python remote-access tool, ASEC says the update function may have been affected too, and reinstalling may not remove it

    SoftwareOK Q-Dir and DesktopOK installers carried a Python RAT; check hashes, reinstalling may not remove it

    first published 2026-11-27 04:41 UTC

    Defender actions

    • Inventory every Windows endpoint that installed or updated Q-Dir or DesktopOK since 2026-10-28, compare each installer's SHA-256 with the value on SoftwareOK's download page, and isolate any host with a bundled Python interpreter under ProgramData or a scheduled task that runs one, treating its credentials as stolen, because ASEC says simply uninstalling and reinstalling the program may not remove a Python RAT already installed.

    Analysis

    AhnLab's ASEC reports that Q-Dir 12.83.0.0, 12.84.0.0 and 12.85.0.0 and DesktopOK 12.82.0.0 and 12.85.0.0 were replaced with tampered installers on SoftwareOK's official distribution path, and that the SHA-256 of some files downloaded from the official site did not match the value posted on its download page. ASEC says the evidence indicates malicious files were also generated during the update process of installed copies, a point it later hedges (users of the update function "may have been affected"), and that it has not identified how the files were replaced (ASEC, 2026-11-25).

    The tampered installer embeds the genuine, correctly signed Q-Dir or DesktopOK executable and runs it from the public user folder so the program appears to work. It then downloads the legitimate 7-Zip console extractor and a package holding a Python runtime and a remote-access tool, unpacks it under a Microsoft-looking folder in ProgramData and persists through a scheduled task, named to look like Edge, that runs the windowless Python interpreter. The tool runs shell commands and Python code, transfers files, takes screenshots and collects system information, and it compares running processes with a list of 1,206 security-product process names and sends the matches to its server. ASEC does not describe the server protocol, names no malware family or actor, and reads Chinese-language comments in the code only as a hint (ASEC, 2026-11-25).

    ASEC gives no distribution window. SoftwareOK's release pages date Q-Dir 12.83 to 4 November, 12.84 to 13 November and 12.85 to 21 November (SoftwareOK, 2026-11-21) and DesktopOK 12.82 to 28 October and 12.85 to 19 November (SoftwareOK, 2026-11-26), which bounds only when the listed versions could first have reached users, and its Q-Dir download page carries no notice about tampering as of 2026-11-27 (SoftwareOK, 2026-11-27).

    Exposure
    Any Windows endpoint on which the listed versions were installed or updated since 2026-10-28; ASEC adds that other versions installed or updated while the tampered files were distributed may be affected. The installed program is the genuine signed one, so a signature check on it passes; the check that finds the tampering is the installer's SHA-256 against the vendor page.
    Detection
    Software-inventory telemetry for the listed versions; in scheduled-task creation and process-creation telemetry, a task running a bundled Python interpreter from under ProgramData and an extractor tool started by an installer; and egress from that interpreter. After removal ASEC says to look for the Python environment, scheduled tasks, related files and external connections.
    Defender takeaway
    Treat every host that ran an affected installer or updater as compromised: isolate it, remove the tool and rotate the credentials used on it, because ASEC says uninstalling and reinstalling the utility may not remove the remote-access tool.
