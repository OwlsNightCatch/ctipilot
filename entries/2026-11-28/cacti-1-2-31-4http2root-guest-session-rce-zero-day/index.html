    NOTABLENATOB2vulnerability

    Cacti Core 1.2.31 (4HTTP2ROOT): an anonymous guest session reaches a stored SQL injection and command execution as the web or poller account in four requests, public proof of concept, no CVE id and no release; the chain needs the guest account enabled, which Cacti's documentation says is off by default

    Cacti 1.2.31 zero-day 4HTTP2ROOT: guest-session RCE, public PoC, no release; disable the guest user, restrict the UI

    first published 2026-11-28 04:55 UTC

    Analysis

    A researcher using the handle ek0ms savi0r published a write-up and proof of concept on 2026-11-26 for unauthenticated command execution on Cacti Core 1.2.31 in four HTTP requests that start from an anonymous guest session, a chain its repository calls 4HTTP2SHELL (ek0ms savi0r, 2026-11-26) and watchTowr named 4HTTP2ROOT (watchTowr, 2026-11-26). BleepingComputer relays the researcher's statement that the flaw was not reported to Cacti before release, and no fixed version exists: watchTowr says Cacti has not published one, and the project's releases page lists 1.2.31 as its newest release on 2026-11-28 (BleepingComputer, 2026-11-27; watchTowr, 2026-11-26; Cacti releases, 2026-11-28).

    As RavenAI and The Hacker News describe the chain, the guest profile page stores a non-numeric graph page size; a graph-preview request concatenates it into a query that accepts a second statement, which rewrites a poller entry's command; and a realtime-graph request runs that command inside the web request as the web server and poller account, often a low-privileged web user according to watchTowr (RavenAI, 2026-11-26; The Hacker News, 2026-11-27; watchTowr, 2026-11-26). The guest account must be enabled for the chain to work, and Cacti's documentation says guest or anonymous access is disabled by default and works only when the Guest user is enabled and set as the guest user (watchTowr, 2026-11-26; Cacti documentation, 2026-11-28). Only 1.2.31 was tested, and it is unclear whether earlier versions are affected (BleepingComputer, 2026-11-27). Cacti stores SNMP strings and device logins, so a compromised server is a foothold into the monitored network (watchTowr, 2026-11-26).

    watchTowr reports no exploitation as of 2026-11-27, while Previdian's honeypots recorded SQL-injection attempts from 2026-11-27 that it says do not show the target was vulnerable or that an attempt succeeded (watchTowr, 2026-11-26; Previdian, 2026-11-26; Previdian tracker, 2026-11-26). BSI classifies the issue as critical (BSI, 2026-11-26). On 2026-11-28 the project merged unreleased 1.2.x hardening commits that reject guest profile writes, validate the page size and require graph access before a realtime command, without referring to the disclosure and with no release or advisory yet (Cacti pull request 9014, 2026-11-28).

    Exposure
    Cacti Core 1.2.31 with the Guest user enabled and set as the anonymous user, reachable from wherever an attacker can load the web interface.
    Detection
    In web access logs, one client requesting the guest profile page, a profile update, a graph preview and a realtime graph in sequence; in the application log, a PHP warning about a non-numeric value in a graph display setting; in the Cacti database, a poller entry whose command is anything other than a normal poller command; on the host, new files written by the poller or web account, a shell or marker file among them (RavenAI, 2026-11-26; watchTowr, 2026-11-26). No release exists, so check guest-reachable servers for these artifacts and treat stored SNMP strings and device logins as exposed on a hit.

    Triage: each request alone is ordinary guest behavior, so the stronger pivots are the non-numeric display-setting warning and a changed poller entry followed by a realtime-graph request (RavenAI, 2026-11-26).

    Defender takeaway
    Where the guest account is on, disable it and restrict the web interface to trusted internal networks now and review poller entries for unexpected commands; where it is off, the sources say the chain has no entry point, but watch for the first release with the hardening commits (watchTowr, 2026-11-26).
