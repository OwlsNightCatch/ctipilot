    Nx Console VS Code extension version 18.95.0 shipped a credential stealer, published with a contributor token stolen in the TanStack npm compromise

    Malicious Nx Console 18.95.0 stayed up to 36 minutes on two extension marketplaces, stealing developer credentials

    first published 2026-05-20 05:00 UTC

    Analysis

    An attacker published Nx Console version 18.95.0 to the Visual Studio Marketplace at 12:30 UTC on 2026-05-18, where it stayed until 12:48 UTC, and to Open VSX from 12:33 to 13:09 UTC (Nx GHSA-c9j4-9m59-847w, 2026-05-18), times StepSecurity's account puts at 12:36 UTC for the Marketplace publication (StepSecurity, 2026-05-18); the Marketplace upload passed Microsoft's automated verification, and a maintainer caught it from the routine publisher-notification e-mail (Nx, 2026-05-21). The attacker published as a legitimate core contributor whose GitHub CLI OAuth token had been exfiltrated seven days earlier by a credential stealer that arrived through the 2026-05-11 TanStack npm supply-chain compromise, and no approval gate stopped a single contributor from releasing (Nx, 2026-05-21). The attacker had also planted an unsigned orphan commit in the nrwl/nx repository; the code injected into the extension runs when any workspace opens, fetches the 498 KB obfuscated payload from that commit (StepSecurity, 2026-05-18) and installs the Bun JavaScript runtime to run it (The Hacker News, 2026-05-19). The payload harvests Vault, npm, AWS (including the instance and ECS metadata services), GitHub, 1Password and filesystem secrets, exfiltrates them over HTTPS, the GitHub API and DNS, writes a Python backdoor with a macOS LaunchAgent for persistence and on Linux attempts a sudoers change (Nx, 2026-05-21); the macOS backdoor takes commands signed with a 4096-bit RSA key through the GitHub Search API as a dead drop (StepSecurity, 2026-05-18). Microsoft counts 28 Marketplace installs and Open VSX 41 downloads, while Nx's own analytics registered about 6,000 activations; the Nx CLI, the official plugins and Nx Cloud were not affected (Nx, 2026-05-21).

    Exposure
    Nx Console 18.95.0 exactly, in VS Code or a fork such as Cursor, on any machine that had the extension with auto-update enabled between 12:30 and 13:09 UTC on 2026-05-18; 18.100.0 and later are clean, and code --list-extensions --show-versions shows the installed version (Nx, 2026-05-21).
    Detection
    Process lineage and file telemetry on developer machines: the extension's code launching a background task that runs npx against a package taken from a GitHub commit, a Bun runtime installed under the user profile, and a Python process running a script from a hidden directory under the user's .local/share, with a new LaunchAgent on macOS (StepSecurity, 2026-05-18) (Nx, 2026-05-21). On the source-control side the stolen token showed as workflow runs and bulk run deletions nobody made, which Nx says audit-log monitoring would have caught during the attacker's week in its repositories (Nx, 2026-05-21). Updating the extension does not remove the backdoor or its persistence, which keep exfiltrating until they are killed and deleted (Nx GHSA-c9j4-9m59-847w, 2026-05-18).
    Defender takeaway
    A machine that ran 18.95.0 is compromised: remove the persistence and rotate every credential reachable from it, tokens, secrets and SSH keys, then audit access logs for those accounts (Nx GHSA-c9j4-9m59-847w, 2026-05-18). For teams that publish software, Nx's lesson is that any pipeline able to publish to a public registry must require approval gating (Nx, 2026-05-21).

    Cited evidence

    Updates1

    Correction21 Oct 2026 16:09 UTC

    The malicious version was live on the Visual Studio Marketplace from 12:30 to 12:48 UTC and on Open VSX from 12:33 to 13:09 UTC (Nx GHSA-c9j4-9m59-847w, 2026-05-18); 12:36 to 12:47 UTC is only the span from the maintainer's alert e-mail to the Marketplace unpublish, and Nx gives the exposure window as 12:30 to 13:09 UTC (Nx, 2026-05-21). The publishing credential was a core contributor's GitHub CLI OAuth token, stolen a week earlier through the TanStack npm compromise (Nx, 2026-05-21). The 2.2 million installs are the extension's total (StepSecurity, 2026-05-18); only 18.95.0 was malicious, with 28 Marketplace installs by Microsoft's count and about 6,000 activations by Nx's, and the upload was not too short-lived to scan: it passed Microsoft's automated checks, basic malware scans included (Nx, 2026-05-21).
