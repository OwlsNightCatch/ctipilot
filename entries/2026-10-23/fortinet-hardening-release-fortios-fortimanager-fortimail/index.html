    Fortinet advisories: FortiAnalyzer and FortiManager 8.0 have no fix for a 9.8 JSON API flaw; FortiMail RCE rows too

    first published 2026-10-23 03:38 UTCupdated 2026-11-12 04:20 UTC

    Defender actions

    • Upgrade every FortiMail to 8.0.2, 7.6.7 or 7.4.9 (a 7.2 unit moves to a fixed release; 7.2.10 for CVE-2026-126150 is not released), every FortiAuthenticator to 8.0.4 or 6.6.11, every FortiOS to 8.0.2, 7.6.8, 7.4.13 or 7.2.14 (a 7.0 unit migrates), and every FortiManager and FortiAnalyzer on 7.6 or 7.4 to 7.6.8 or 7.4.12 (7.2 and 7.0 migrate), internet-facing units and FortiMail first, because the advisories describe unauthenticated code execution and account takeover and Fortinet warns that patch differences show attackers where the weakness sits; keep the FGFM and oftp ports and every administrative interface off untrusted networks.
    • On every FortiAnalyzer and FortiManager (Cloud variants included) on 8.0.0 through 8.0.2, set rpc-permit none on every administrator profile that has the JSON API enabled until Fortinet releases 8.0.3, because no 8.0 build fixes the unauthenticated 9.8 flaw CVE-2026-126170 and 8.0.2 is affected.

    Analysis

    Fortinet announced on 2026-10-21 coordinated security updates for FortiOS, FortiManager and FortiAnalyzer, released on 2026-10-22, and urged customers to treat them as a priority change because AI tools can help adversaries diff patches and build exploits within hours or days (Fortinet, 2026-10-21). The advisories withheld until Patch Tuesday were published on 2026-11-10; none of the 2026-11-10 advisories states exploitation, and NCSC.ch listed the status as unknown (NCSC.ch, 2026-10-22).

    The critical rows (CVSS 9.0 or higher) by product. FortiMail: unauthenticated path traversal and command injection that may give code or command execution (CVE-2026-126147 and CVE-2026-126148, 9.8) (Fortinet PSIRT, 2026-11-10; Fortinet PSIRT, 2026-11-10), two SQL injections (CVE-2026-126164 and CVE-2026-126263, 9.4; the second is authenticated in its page summary and unauthenticated in its metadata) (Fortinet PSIRT, 2026-11-10; Fortinet PSIRT, 2026-11-10) and three IBE webmail takeover or access flaws (CVE-2026-126156, CVE-2026-126150 and CVE-2026-126155, 9.1) (Fortinet PSIRT, 2026-11-10; Fortinet PSIRT, 2026-11-10; Fortinet PSIRT, 2026-11-10) and an unauthenticated access flaw in other users' secure email accounts (CVE-2026-126157, 9.1) (Fortinet PSIRT, 2026-11-10). FortiAnalyzer and FortiManager: an unauthenticated GUI flaw that may allow code or command execution only when the JSON API is enabled, which is off by default (CVE-2026-126170, 9.8) (Fortinet PSIRT, 2026-11-10), oftp port SQL injection and SSRF (CVE-2026-126262, 9.3; CVE-2026-126260, 9.0) (Fortinet PSIRT, 2026-11-10; Fortinet PSIRT, 2026-11-10), an administrator's access to other VDOMs (CVE-2026-126229, 9.1) (Fortinet PSIRT, 2026-11-10) and FGFM code execution (CVE-2026-126261, 9.0) (Fortinet PSIRT, 2026-11-10). FortiOS: the OSPF daemon (CVE-2026-126253, 9.3), HA FGSP command execution (CVE-2026-126259, 9.0) and iBGP (CVE-2026-126254, 9.6) (Fortinet PSIRT, 2026-11-10; Fortinet PSIRT, 2026-11-10; Fortinet PSIRT, 2026-11-10). FortiAuthenticator: two authentication bypasses (CVE-2026-126257, 9.0; CVE-2026-126251, 9.1) (Fortinet PSIRT, 2026-11-10; Fortinet PSIRT, 2026-11-10). FortiClient: an origin-validation flaw that needs victim interaction (CVE-2026-121529, 9.1) (Fortinet PSIRT, 2026-11-10).

    The October builds fix most rows: FortiOS 8.0.2, 7.6.8, 7.4.13 and 7.2.14; FortiManager and FortiAnalyzer 8.0.2, 7.6.8, 7.4.12 and 7.2.13; FortiMail 8.0.2, 7.6.7 and 7.4.9; FortiAuthenticator 8.0.4 and 6.6.11 (Fortinet, 2026-10-21). Not every row: no 8.0 build fixes CVE-2026-126170 until the upcoming 8.0.3, with rpc-permit none on admin profiles that have the JSON API enabled as the workaround (Fortinet PSIRT, 2026-11-10); FortiMail 7.2 awaits 7.2.10 for CVE-2026-126150 (Fortinet PSIRT, 2026-11-10); FortiAnalyzer and FortiManager 7.2 and 7.0 and FortiOS 7.0 must migrate (Fortinet PSIRT, 2026-11-10; Fortinet PSIRT, 2026-11-10; Fortinet PSIRT, 2026-11-10). The FortiMail builds also fix the exploited CVE-2026-104286 (Fortinet PSIRT, 2026-10-01).

    Exposure
    FortiMail 8.0.0 to 8.0.1, 7.6.0 to 7.6.6, 7.4.0 to 7.4.8 or any 7.2; FortiAuthenticator 8.0.0 to 8.0.3 and 6.6.0 to 6.6.10; FortiOS below the fixed builds and any 7.0; FortiAnalyzer and FortiManager 8.0.0 to 8.0.2 with the JSON API, oftp or FGFM port reachable; FortiClient 7.4.0 to 7.4.7 and 7.2.0 to 7.2.14.
    Detection
    Fortinet advises watching logs for unusual administrative access and unapproved configuration changes (Fortinet, 2026-10-21); for the new rows, FortiMail web logs for unauthenticated IBE webmail and HA join requests, FortiAnalyzer and FortiManager JSON API, oftp and FGFM connections from unexpected sources, and OSPF advertisements from unexpected hosts and unusual updates from iBGP neighbours.
    Defender takeaway
    Upgrade FortiMail, FortiAuthenticator and the internet-facing FortiOS, FortiManager and FortiAnalyzer units now; an unpatched FortiMail is exposed to the exploited flaw too. On FortiAnalyzer and FortiManager 8.0 apply the rpc-permit workaround until 8.0.3 ships, plan the migration off branches with no fix, and keep administrative interfaces and the FGFM and oftp ports off untrusted networks.

    Update11 Nov 2026 03:50 UTC

    Fortinet published the advisories it had withheld from the October hardening release on 2026-11-10. They name unauthenticated FortiMail flaws that may allow code or command execution through crafted requests (CVE-2026-126147, CVSS 9.8) (Fortinet PSIRT, 2026-11-10) and through HA join-request packets (CVE-2026-126148, 9.8) (Fortinet PSIRT, 2026-11-10), an unauthenticated SQL injection (CVE-2026-126164, 9.4) that Fortinet remediated in FortiMail Cloud on 2026-10-05 (Fortinet PSIRT, 2026-11-10), and two IBE webmail flaws that let an attacker take over an IBE recipient account (CVE-2026-126156, 9.1) (Fortinet PSIRT, 2026-11-10) or obtain an authenticated session as one (CVE-2026-126155, 9.1) (Fortinet PSIRT, 2026-11-10). Two FortiAuthenticator flaws, a hard-coded-password bypass (CVE-2026-126257, 9.0) (Fortinet PSIRT, 2026-11-10) and an incorrect-authorization authentication bypass (CVE-2026-126251, 9.1) (Fortinet PSIRT, 2026-11-10), a FortiOS and FortiSASE OSPF flaw that lets an unauthenticated attacker on the adjacent network broadcast link-state advertisements (CVE-2026-126253, 9.3) (Fortinet PSIRT, 2026-11-10) and unauthenticated code execution through the FortiManager FGFM port (CVE-2026-126261, 9.0) (Fortinet PSIRT, 2026-11-10) are the other rows that page named. The October builds fix most of them but not on every branch (FortiMail 7.2 and FortiOS 7.0 are told to migrate for some rows, as the update below sets out), FG-IR-26-275 lists lower minimum FortiManager builds (8.0.1, 7.6.8, 7.4.6 and 7.2.9) for the FGFM flaw, and none of the 2026-11-10 advisories states exploitation.

    Update12 Nov 2026 04:20 UTC

    The advisory pages carry ten more critical rows (CVSS 9.0 or higher), shown above, and the October builds do not fix every row: FortiAnalyzer and FortiManager 8.0.0 through 8.0.2 have no fixed build for CVE-2026-126170 until the upcoming 8.0.3 (Fortinet PSIRT, 2026-11-10), FortiMail 7.2 awaits 7.2.10 for CVE-2026-126150 (Fortinet PSIRT, 2026-11-10), FortiAnalyzer and FortiManager 7.2 and 7.0 must migrate for CVE-2026-126229 (Fortinet PSIRT, 2026-11-10), and FortiOS 7.0 must migrate for CVE-2026-126253 and CVE-2026-126259 (Fortinet PSIRT, 2026-11-10) (Fortinet PSIRT, 2026-11-10).
