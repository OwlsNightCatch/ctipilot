    Oracle October 2026 Critical Patch Update: six unauthenticated network CVSS 10.0 rows in Access Manager, SOA Suite, E-Business Suite and JD Edwards, and WebLogic CVSS 9.8 flaws reachable over HTTP and T3/IIOP

    Oracle's October CPU carries six unauthenticated CVSS 10.0 rows and two WebLogic 9.8 flaws; none is reported exploited

    first published 2026-10-21 03:41 UTC

    Analysis

    Oracle's Critical Patch Update advisory of 2026-10-20 contains 1295 new security patches (Oracle, 2026-10-20). Its risk matrices score 112 rows at CVSS 3.1 9.0 or higher, and 90 of those, covering 73 distinct CVE ids, are marked as remotely exploitable without authentication with a network attack vector (Oracle, 2026-10-20). Six rows score 10.0: CVE-2026-87337 in the Access Manager Authentication Engine (HTTP), CVE-2026-91231 in the SOA Suite Adapters (HTTP), CVE-2026-91216 and CVE-2026-91221 in the SOA Suite Fabric Layer (T3 and IIOP), CVE-2026-101809 in the E-Business Suite Workflow Notification Mailer (HTTP, 12.2.3 to 12.2.15) and CVE-2026-91299 in the JD Edwards EnterpriseOne Orchestrator security component (HTTP, 9.2.0.0 to 9.2.26.5) (Oracle, 2026-10-20). WebLogic Server 12.2.1.4.0, 14.1.1.0.0, 14.1.2.0.0 and 15.1.1.0.0 carry CVE-2026-91323 (HTTP) and CVE-2026-83399 (T3 and IIOP) at 9.8 and CVE-2026-87302 (HTTP) at 9.1; Identity Manager's End User Self Service has CVE-2026-91408 (T3 and IIOP, 9.8) and Access Manager's SAML path CVE-2026-87251 (9.8) (Oracle, 2026-10-20). The advisory states no exploitation for any row and carries only Oracle's standing sentence that it receives reports of attempts to exploit already-patched flaws (Oracle, 2026-10-20). Oracle points to My Oracle Support documents for patch availability (Oracle, 2026-10-20).

    Exposure
    A WebLogic, SOA Suite, Access Manager or Identity Manager server whose HTTP, T3 or IIOP listener, or SAML endpoint, answers from a network that is not the management network; an E-Business Suite 12.2.3 to 12.2.15 web tier with the Workflow Notification Mailer; a JD Edwards EnterpriseOne 9.2 server with the Orchestrator. The product version comes from the product's own version command or the inventory.
    Detection
    Oracle names no indicator, so no flaw-specific signature exists. Watch web and application-server access logs and the WebLogic and SOA server logs for requests to the affected components from untrusted sources, T3 and IIOP connections from unexpected networks in flow or load-balancer logs, and Java process-creation events where the middleware process spawns a shell, an interpreter or a download tool.
    Defender takeaway
    Apply the October 2026 update to the six 10.0 components first wherever they are reachable beyond the management network, then to the WebLogic and Identity Manager rows; where a patch cannot go in at once, take T3, IIOP and the administration console off untrusted networks. Oracle's next scheduled update is the Critical Security Patch Update of 17 November 2026 (Oracle, 2026-10-20).
