    The financial theft sits in the Optimizely files: Ohey says that on 2026-11-16 they switched to a script that swaps copied wallet addresses and skims card numbers in every browser and adds the router only on iPhones and iPads (Ohey, 2026-11-17).     Detection
    Web proxy and DNS telemetry for a vendor script that causes a further script load from a host unrelated to the vendor, payment-form POST bodies sent to an unfamiliar host, and response-body diffs of served third-party bundles; Content-Security-Policy script-src violation reports naming unknown hosts, which Amirul Cyber says stopped the payload on two affected sites (Amirul Cyber, 2026-11-16).     Defender takeaway
    Inventory third-party scripts on public, payment and e-government pages now and verify what each serves; a DNS or network block alone does not remove the poisoned trusted script (Hudson Rock, 2026-11-16), so keep the evidence, remove the file and set an allow-listed script-src policy.

    TGR-STA-0049: Unit 42 describes the PerfectPioneer and KUKURAT implants, which use HTTP/3 over QUIC for command and control against government networks entered through unpatched Exchange servers, then spread through domain logon scripts and grant FullAccess on every mailbox

    Unit 42 describes a campaign by TGR-STA-0049, also tracked as REF7707, Earth Alux and Ink Dragon, against Southeast Asian government entities since at least July 2025, and says the group's targeting also includes government organizations in South America and Europe (Unit 42, 2026-11-16). Server exploitation is the primary entry: unpatched Microsoft Exchange and web servers receive web shells, among them variants of ASPXSpy, Godzilla, Bysunue.aspx and Suo5, while phishing with decoy PDFs from lookalike government domains is secondary (Unit 42, 2026-11-16). The implants are two previously undocumented families: the Go-based PerfectPioneer RAT, active since July 2025 and run through DLL side-loading of a modified legitimate executable, decoy installers or phishing, and its modular C++ successor KUKURAT, deployed since March 2026, which loads at least 12 DLL modules from the command server into memory (Unit 42, 2026-11-16). Unit 42 says both families use HTTP/3 over QUIC as the primary command channel, with an automatic HTTP/2 fallback in the PerfectPioneer variant it analyzes, separate HTTP/2 and HTTP/3 builds of KUKURAT, and two PerfectPioneer variants, RatAAkk-tt and PerfectRat, that rely on HTTP/2 alone, and that some firewalls and inspection engines handle QUIC less well than TCP traffic (Unit 42, 2026-11-16). Two of the six PerfectPioneer variants, Pioneer and rat_http3_cc, carry a built-in blocklist that stops operators running noisy or destructive commands, and KUKURAT generates synthetic network, registry and file activity as camouflage (Unit 42, 2026-11-16).

    After taking a domain controller, the operators installed malicious domain logon scripts, so each user's logon pulled KUKURAT; they also used PsExec, WMI and WinRM (Unit 42, 2026-11-16). Credentials came from LSASS dumps taken with rundll32 calling comsvcs.dll by ordinal rather than by the MiniDump name, from DCSync, and from Mimikatz, ProcDump, SharpDPAPI and SAM and SYSTEM hive dumps (Unit 42, 2026-11-16). On Exchange, the operators first listed accounts holding the ApplicationImpersonation role and, when none was found, ran a hidden PowerShell loop that granted a compromised account FullAccess on every mailbox (Unit 42, 2026-11-16). The exfiltration targeted pdf, docx, xlsx and png files whose names suggest international relations and internal political affairs (Unit 42, 2026-11-16).

    Exposure
    On-premises Exchange and other web servers that are unpatched and internet-facing, and Active Directory domains in which an attacker with domain controller access can edit logon scripts in SYSVOL or Group Policy.
    Detection
    Egress telemetry for outbound UDP 443 (QUIC) from servers that do not browse, since Unit 42 advises logging or blocking it so traffic falls back to TCP, paired with proxy and TLS egress telemetry because the HTTP/2-only variants and the KUKURAT HTTP/2 build never use UDP 443; SYSVOL and Group Policy change audit plus endpoint alerts on an uncommon startup process running under a domain user SID at logon, which raised an alert in Unit 42's telemetry; process events for rundll32 loading comsvcs.dll with an ordinal argument; and Exchange audit of ApplicationImpersonation role holders and of Add-MailboxPermission loops that grant FullAccess across all mailboxes (Unit 42, 2026-11-16).
    Defender takeaway
    Patch or isolate internet-facing Exchange and web servers first, then check domain logon scripts, ApplicationImpersonation holders and mailbox permissions, and decide whether servers need outbound UDP 443 at all.

    ROUTINENATOB2

    BundID: automated mass login attempts against Germany's federal citizen accounts lock accounts; the BSI confirms the attack, password sign-in was switched off on 16 November and no compromise is evidenced

    Germany's BSI confirmed to heise security and Handelsblatt on 2026-11-16 an IT security incident involving BundID accounts: automated, mass login attempts whose failures locked accounts, triggered automated mails and prompted account holders to reset their passwords (heise, 2026-11-16). The federal government switched off username-and-password sign-in on Monday morning for security reasons (Handelsblatt, 2026-11-16), while sign-in with the online ID card (eID) and the Elster certificate stayed possible (WEB.DE, 2026-11-16). The BSI says countermeasures it does not name repelled the attack and that it has no indication of a compromise of any account, and heise reports that locked accounts are apparently not being unlocked in bulk, so account holders must pass the password-reset flow or use another sign-in method (heise, 2026-11-16). Handelsblatt, citing government circles, describes the attack as credential stuffing, the automated replay of credentials from earlier leaks at other services (Handelsblatt, 2026-11-16). An aggregator reports that password sign-in returned the same afternoon behind a mandatory e-mail one-time code (ad-hoc-news.de, 2026-11-16); no primary source read confirms it. The same aggregator attributes the credential-stuffing label to the BSI, which neither heise nor Handelsblatt does (ad-hoc-news.de, 2026-11-16). No Swiss portal is reported affected.

    Exposure
    Citizen-facing or employee-facing login portals that accept a password and lock an account after repeated failures.
    Detection
    Authentication logs showing a surge of failed password sign-ins spread over many usernames and sources, followed by lockout notices, password-reset mail volume and helpdesk contacts; a lockout storm is itself the alert.
    Defender takeaway
    The operator's containment, as heise and Handelsblatt report it, was to switch off the password-only path while eID and other sign-in means stayed open; a lockout-after-failures control turns credential stuffing into mass lockouts and reset mail even when no account is taken over, so settle that containment lever for your own portals before a run starts.

    NOTABLENATOB2

    Symantec: a September 2026 intrusion at a US retailer shows attackers switching to AI-generated PowerShell and, about ten minutes after first querying SolarWinds Orion, using the RabbitMQ Erlang cookie bundled with it to run a command on a second server

    Symantec's Threat Hunter Team describes a September 2026 intrusion at a US retail organization in which the attackers first worked by hand on a compromised web server, with typing errors and every staged payload terminated by security software, and then, the next day, submitted about 50 long, error-free PowerShell scripts over roughly two hours, with labelled output sections and comments that read as a model's reasoning (Symantec, 2026-11-12). Symantec assesses AI assistance with high confidence and an operator relaying output to an AI tool, not an autonomous agent, with moderate confidence; it could not identify the model (Symantec, 2026-11-12). The initial infection vector is unknown (Symantec, 2026-11-12).

    The earliest activity, on 2026-09-18, ran cmd.exe directly under sqlservr.exe on three SQL Servers, which Symantec reads as commands issued through the database service, most likely xp_cmdshell; on one host the attackers compiled the public EfsPotato exploit with csc.exe from base64 text decoded by certutil and saved the SAM, SYSTEM and SECURITY hives (Symantec, 2026-11-12). On a web server compromised through w3wp.exe they side-loaded payloads with a legitimate Bitdefender executable (bdreinit.exe with log.dll) and a G DATA executable (ask.exe with ask.dll) from ProgramData, used a utility called BreakChain to relaunch them so they no longer appeared as children of w3wp.exe, copied one to a file named w3wp.exe, and planted ASP web shells in the application's images folder (Symantec, 2026-11-12). The AI-style scripts then harvested credentials from connection strings, FileZilla, WinSCP and PuTTY settings, saved RDP files and IIS configuration, read the Erlang cookie file of the RabbitMQ broker that ships with Orion; running Orion's bundled erl.exe with that cookie, they called the broker on a second web server to run an encoded operating system command (Symantec, 2026-11-12). Later activity searched a probable domain controller for NTDS.dit, SYSVOL cpassword values and LAPS passwords and ran a Chisel tunnelling tool and a password sprayer (Symantec, 2026-11-12).

    Symantec says no second-phase technique was new and suggests a possible link, through a shared address and the retail focus, to the operation Gambit Security described on 2026-09-22 (Symantec, 2026-11-12). No Swiss or public-sector victim is named; the case matters for the transferable chain and its AI-assisted tempo.

    Exposure
    Windows estates running SolarWinds Orion with its bundled RabbitMQ broker alongside SQL Server hosts and IIS web applications; the Erlang cookie file on the Orion host is the pivot.
    Detection
    Process-creation telemetry with parent lineage for cmd.exe or PowerShell started under sqlservr.exe or w3wp.exe, csc.exe started by PowerShell on a server, certutil decoding a text file in ProgramData, a vendor-signed executable running from ProgramData beside an unsigned DLL, an executable named w3wp.exe outside the IIS directory, and erl.exe started from the Orion directory with a cookie argument and a remote broker call; registry hive save events for SAM, SYSTEM and SECURITY.

    Triage: long, labelled PowerShell is not the signal on its own, because administrators write such scripts too; a parent of sqlservr.exe or w3wp.exe rather than an administrator session, credential-store targets and a blocked loader returning rebuilt are.

    Defender takeaway
    Hunt SQL Server and IIS hosts for this lineage, treat an Orion server as a lateral-movement bridge to every host that runs its RabbitMQ node, and alert on behavior rather than file names, since the tools were renamed and rebuilt after each block.

    CVE-2026-123488, Craft CMS 4.0.0 to 4.18.8 and 5.0.0 to 5.11.1: an unauthenticated SQL injection in front-end search lets a visitor become an administrator on MySQL and MariaDB; the Canadian Cyber Centre reports exploitation in the wild and 4.18.9 and 5.11.2 fix it (CVSS 4.0 9.3)

    Craft CMS 4.0.0 before 4.18.9 and 5.0.0 before 5.11.2 contain an unauthenticated SQL injection in front-end search: the attribute parameter is concatenated into the query unsanitized and emulated PDO prepares allow stacked statements, so a remote attacker can read and write the database, setting the admin flag or overwriting password hashes in the users table to gain administrator access (CVSS 4.0 9.3) (VulnCheck, 2026-11-06). Craft's own advisory, published on 2026-10-22 as critical, places the flaw on the front end of any site that uses craft.search, says it affects only MySQL and MariaDB, and says the write primitive was used to set the admin flag on user ID 1 (Craft CMS, 2026-10-22). The fixed releases are 4.18.9 and 5.11.2, and Craft's temporary workaround is to block front-end requests that carry the bracketed attribute token, plain or encoded, in the query string (Craft CMS, 2026-10-22). ENISA's record for CVE-2026-123488 lists Craft's advisory among its references (ENISA EUVD, 2026-11-06).

    On exploitation, the Canadian Centre for Cyber Security's update of 2026-11-12 says open source reporting indicates the flaw is exploited in the wild (CCCS, 2026-11-12), and VulnCheck's advisory page states that it is in the VulnCheck KEV database (VulnCheck, 2026-11-06). No first-hand telemetry, victim statement or CISA listing was found.

    Exposure
    Craft CMS 4.0.0 to 4.18.8 and 5.0.0 to 5.11.1 on MySQL or MariaDB whose public pages use craft.search.
    Detection
    Web access logs for front-end search requests whose query string carries the bracketed attribute token that Craft's workaround blocks; database audit for changes to the admin column or password hashes in the users table, and new administrator accounts or sessions afterwards. Updating closes the injection but not an administrator flag or hash that was already written.
    Defender takeaway
    Update every Craft CMS site to the fixed release now, since the attack needs no account and ends in administrator access, and check the users table on any internet-facing site that ran an older build.

    NOTABLENATOB2

    GTIG AI Threat Tracker, November 2026: an exposed exploit_agent framework automates patch diffing, exploit drafting and execution without a human, a suspected North Korean cluster plants a Claude Code startup download in internal repositories, and PRC-nexus actors stage and exfiltrate through an LLM platform's file hosting

    Three findings from GTIG's quarterly update on adversary use of AI, published 2026-11-16, change what defenders can look for (GTIG, 2026-11-16). First, GTIG identified an exposed staging server hosting a multi-agent vulnerability research and weaponization framework, dubbed exploit_agent, that integrates frontier and local LLMs and runs continuous differential analysis of popular web application software: it compares code before and after patch announcements, analyzes the findings, drafts exploits and executes them automatically, which GTIG says is the first time it has seen LLM frameworks fully automate discovery and exploitation without a human in the loop (GTIG, 2026-11-16). The server also held scripts for internal reconnaissance, brute-forcing, installing web shells and removing other attackers' web shells, and its victim telemetry suggested interest in French media, entertainment and education websites (GTIG, 2026-11-16).

    Second, in intrusions against cryptocurrency organizations in North America and Europe, a suspected MIDNIGHT NEPTUNE cluster used fraudulent recruiter profiles, sent targets to fake meeting platforms with ClickFix lures that ran likely LLM-authored staging scripts, and then pivoted into internal code repositories and modified .claude/settings.json so that Claude Code startup triggered the download of the SOMBERMEME backdoor; it masked lateral movement with GitHub personal access tokens named after Microsoft Copilot (GTIG, 2026-11-16). Third, in what GTIG calls a new trend, PRC-nexus actors abused LLM platforms and file-hosting backends for staging, dead-drop command channels and exfiltration, in one case staging lure archives and exfiltrating stolen data through a frontier model's file-hosting infrastructure (GTIG, 2026-11-16). GTIG separately assesses that the open-source agentic pentest frameworks it tracks, among them ARTEX, CAIRN, CyberStrikeAI and PentAGI, currently trade stealth for velocity: they generate forensic traffic, rely on recognizable identifiers and leave distinct code-level traces (GTIG, 2026-11-16).

    Exposure
    Organizations whose developers run Claude Code against shared repositories, where a committed project settings file executes at startup, and internet-facing web applications and plugins whose patches are public, since exploit_agent works from patch diffs.
    Detection
    Repository change monitoring for edits to .claude/settings.json and its hook or startup commands, and GitHub audit events that create personal access tokens named after a vendor assistant; for agentic scanning, the forensic traffic, recognizable identifiers and code-level traces that GTIG says pentest frameworks leave behind (GTIG, 2026-11-16).
    Defender takeaway
    Review a change to a project-level Claude Code settings file like a code-execution change, and move internet-facing web components to the fastest patch lane, because GTIG describes patch diffs being turned into executed exploits without a human.
