    BigBlueButton bbb-web before 3.0.21 and 3.0.23: predictable session tokens, an API checksum bypass and an SSRF (CVE-2026-46351, CVE-2026-46353, CVE-2026-46404)

    BigBlueButton, an open-source virtual classroom, published three security advisories for its bbb-web component on 2026-05-13 (ENISA EUVD-2026-44996; BigBlueButton GHSA-7959-pf2v-xc4h, 2026-05-13; BigBlueButton GHSA-43hc-5g2m-cqff, 2026-05-13; BigBlueButton GHSA-xqm3-6q7q-4v5h, 2026-05-13). Before version 3.0.21, bbb-web generated conference session tokens with insufficiently secure randomness, so a user could determine the session tokens of other users in the same session and impersonate them (CVE-2026-46351) (BigBlueButton GHSA-7959-pf2v-xc4h, 2026-05-13; ENISA EUVD-2026-44996), and supplying a presentationUploadExternalUrl parameter bypassed checksum validation, so any user could send valid requests to some endpoints without a checksum (CVE-2026-46353) (BigBlueButton GHSA-43hc-5g2m-cqff, 2026-05-13; ENISA EUVD-2026-44998). Before 3.0.23, presentation URL validation did not restrict access to site-local and link-local addresses, and the fix also pins resolved IPs when following redirects; BigBlueButton says private-address assets may be compromised if the attacker has gained additional access (CVE-2026-46404) (BigBlueButton GHSA-xqm3-6q7q-4v5h, 2026-05-13; ENISA EUVD-2026-44997). The CVSS 3.1 scores in the CVE records are 8.1 for the first two, with low privileges and no user interaction, and 6.8 for the SSRF, with high privileges and a changed scope (ENISA EUVD-2026-44996; ENISA EUVD-2026-44998; ENISA EUVD-2026-44997). Germany's BSI summarized the set as letting a remote, authenticated attacker bypass security measures and disclose confidential information (translated from German) (BSI WID-SEC-2026-1568, 2026-05-18). No source reports exploitation.

    Exposure
    BigBlueButton servers running bbb-web older than 3.0.21, or older than 3.0.23 for the SSRF; the token flaw needs a user inside the meeting, the checksum bypass any user of the API, and the SSRF a high-privilege user (ENISA EUVD-2026-44996; ENISA EUVD-2026-44998; ENISA EUVD-2026-44997).
    Detection
    In bbb-web API logs, requests carrying a presentationUploadExternalUrl parameter that reach endpoints without a valid checksum, and joins in which one participant presents another participant's session token; in egress telemetry from the BigBlueButton server, presentation fetches to site-local or link-local addresses (BigBlueButton GHSA-43hc-5g2m-cqff, 2026-05-13; BigBlueButton GHSA-7959-pf2v-xc4h, 2026-05-13; BigBlueButton GHSA-xqm3-6q7q-4v5h, 2026-05-13).
    Defender takeaway
    Upgrade BigBlueButton to 3.0.23 or later, which covers all three flaws; the advisories offer no workaround besides updating (BigBlueButton GHSA-xqm3-6q7q-4v5h, 2026-05-13; BigBlueButton GHSA-7959-pf2v-xc4h, 2026-05-13). Organizations without BigBlueButton have no decision to make.

    ARWINI, Lower Saxony's prescription audit body: police confirm a data outflow and name the Kairos group, which lists 2.87 TB for sale

    According to the Hannover police directorate, data left the system of the Arbeitsgemeinschaft Wirtschaftlichkeitsprüfung Niedersachsen (ARWINI), which processes health and billing data of statutorily insured people in Lower Saxony and audits the cost-effectiveness of prescriptions on behalf of the statutory health insurers and the Kassenärztliche Vereinigung Niedersachsen (KVN), and the police confirmed to heise online that the Kairos ransomware group is behind the attack (Heise, 2026-05-18). ARWINI said that "based on current findings, it is likely that personal and also particularly sensitive data are affected" (translated from German), potentially contact and health data and billing information of statutorily insured patients, and that the extent of the outflow was not yet established (Deutsches Ärzteblatt, 2026-05-18); it put the worst case at up to 75,000 records, while its external data protection officer told heise online it was still unclear whether and which data had left (Heise, 2026-05-18). The case matters as a statutory health-insurance audit body in the DACH region holding health and billing data; no source states how the attackers got in.

    Grafana Labs confirms GitHub breach claimed by CoinbaseCartel: a workflow token missed after the TanStack npm compromise let attackers download its code and internal repositories

    Grafana Labs said in posts on X that an unauthorized party had obtained a token granting access to its GitHub environment and downloaded its codebase, that no customer data or personal information was accessed and customer systems were unaffected, and that it would not pay the attacker's extortion demand, following FBI guidance (The Hacker News, 2026-05-17; BleepingComputer, 2026-05-18). SecurityWeek dates the confirmation to Sunday 2026-05-17, two days after the group CoinbaseCartel listed Grafana on its leak site on 2026-05-15 (SecurityWeek, 2026-05-18). In its update of 2026-05-19, Grafana said the incident originated from the TanStack npm supply-chain attack via the Mini Shai-Hulud campaign, that it detected the malicious activity on 2026-05-11 and rotated a significant number of GitHub workflow tokens, but that a missed token, from a workflow it had first deemed not impacted, gave the attackers access to its repositories (Grafana Labs, 2026-05-19); The Hacker News attributes the TanStack attack to TeamPCP (The Hacker News, 2026-05-20). The download covered public and private source code and internal repositories some teams use for operational information, including business contact names and email addresses, but not production systems or the Grafana Cloud platform; the ransom demand from an unnamed actor arrived on 2026-05-16, and Grafana has since rotated automation tokens, implemented enhanced monitoring and audited all commits since the May 11 incident (Grafana Labs, 2026-05-19).

    CoinbaseCartel, active since September 2025, steals data and extorts victims without encrypting files; SecurityWeek counts 105 victims on its site, while The Hacker News, citing Halcyon and FortiGuard Labs, puts the total at 170 (SecurityWeek, 2026-05-18; The Hacker News, 2026-05-17). Security firms link the group to ShinyHunters, Scattered Spider and Lapsus$ (SecurityWeek, 2026-05-18), but ShinyHunters told BleepingComputer that CoinbaseCartel is not linked to it (BleepingComputer, 2026-05-18). Grafana's paying customers include governments, banks and infrastructure operators, and more than 7,000 organizations use the product (BleepingComputer, 2026-05-18).

    Exposure
    Organizations whose build pipelines took in the compromised TanStack npm packages, where any CI workflow token left unrotated afterwards stays usable, as one did at Grafana (The Hacker News, 2026-05-20). Grafana reports no impact on customer production systems or Grafana Cloud (Grafana Labs, 2026-05-19).
    Detection
    In source-control audit logs, repository downloads and clones made with workflow tokens, including those of workflows judged unaffected after a dependency compromise; Grafana's attackers came in through exactly such a workflow (The Hacker News, 2026-05-20).
    Defender takeaway
    After a dependency compromise reaches CI, rotate every workflow token, including those of workflows that look unaffected, and confirm the rotation is complete, since one missed token was enough here (The Hacker News, 2026-05-20). Grafana users have no product action to take: Grafana reports no customer impact and has audited its commits for malicious changes (The Hacker News, 2026-05-20).

    CISA contractor's public GitHub repository exposed AWS GovCloud admin keys and plaintext passwords for internal CISA systems for up to six months

    GitGuardian researcher Guillaume Valadon alerted KrebsOnSecurity on 2026-05-15 to a public GitHub repository named Private-CISA, kept by an employee of the government contractor Nightwing, that held cloud keys, tokens, plaintext passwords, logs and files describing how CISA builds, tests and deploys software (Krebs on Security, 2026-05-18). One file held administrative credentials to three AWS GovCloud servers, which Philippe Caturegli of Seralys validated as authenticating to three GovCloud accounts at a high privilege level; a CSV of browser-saved passwords listed plaintext credentials for dozens of internal CISA systems, among them LZ-DSO (Landing Zone DevSecOps), the agency's secure code development environment; and the archive also held plaintext credentials to CISA's internal Artifactory package repository (Krebs on Security, 2026-05-18). The commit logs show the administrator had disabled GitHub's default setting that blocks publishing SSH keys or other secrets, and many passwords were each platform's name followed by the current year (Krebs on Security, 2026-05-18).

    The repository was created on 2025-11-13 and taken offline shortly after KrebsOnSecurity and Seralys notified CISA, but the AWS keys stayed valid for another 48 hours (Krebs on Security, 2026-05-18); Gizmodo puts the exposure at about six months, possibly much shorter depending on when each item was added (Gizmodo, 2026-05-19). Caturegli suspects the contractor used the repository to synchronize files between a work laptop and a home computer, and calls the Artifactory credentials a prime place to move laterally and backdoor software packages (Krebs on Security, 2026-05-18). CISA said it was investigating, that there was no indication any sensitive data was compromised, and that it was adding safeguards (Krebs on Security, 2026-05-18). For public bodies the case is a transferable pattern: a contractor's own repository holding an agency's privileged cloud and build-system credentials.

    Exposure
    Organizations whose staff or contractors can push agency material to public code repositories and can switch off the platform's secret-blocking setting, as this administrator did (Krebs on Security, 2026-05-18).
    Detection
    In code-hosting and secret-scanning telemetry, alerts on public repositories outside the organization's own namespace that contain its credentials, the kind of finding GitGuardian raised here; in cloud control-plane audit logs, use of long-lived access keys after the material they leaked from has been taken down, since these keys kept working for 48 hours (Krebs on Security, 2026-05-18).
    Defender takeaway
    When a secret leaks through a public repository, revoke the keys and passwords at once rather than relying on the takedown, and check that administrators cannot disable the code platform's secret blocking for repositories that hold agency material (Krebs on Security, 2026-05-18).

    MiniPlasma: Chaotic Eclipse PoC turns the 2020 Windows Cloud Files driver flaw CVE-2020-17103 into a SYSTEM shell on patched Windows 11; June 2026 updates fix it

    Chaotic Eclipse, also known as Nightmare Eclipse, released source code and a compiled exploit for MiniPlasma on GitHub, saying that the flaw James Forshaw of Google Project Zero reported in September 2020 in the HsmOsBlockPlaceholderAccess routine of the Cloud Filter driver cldflt.sys, assigned CVE-2020-17103 and reportedly fixed in December 2020, was still present and that Google's original proof of concept worked unchanged (BleepingComputer, 2026-05-17). The exploit appears to abuse how the driver handles registry key creation through the undocumented CfAbortHydration API, which Forshaw's report said could create arbitrary registry keys in the .DEFAULT user hive without proper access checks (BleepingComputer, 2026-05-17). BleepingComputer, using a standard user account on a fully patched Windows 11 Pro system with the May 2026 updates, got a command prompt with SYSTEM privileges, and Will Dormann confirmed the exploit on the latest public Windows 11 but not on the latest Insider Preview Canary build (BleepingComputer, 2026-05-17); the researcher says success may vary because it is a race condition and that all Windows versions are likely affected (The Hacker News, 2026-05-18).

    Microsoft re-released CVE-2020-17103 on 2026-06-09 to comprehensively address the flaw "recently publicly referred to as 'Mini-Plasma'" and recommends installing the June 2026 Windows updates; it rates it Important with a CVSS 3.1 base score of 7.0 and lists it as not exploited (Microsoft MSRC, CVE-2020-17103).     Symantec and Carbon Black: the fast16 sabotage framework corrupted LS-DYNA and AUTODYN nuclear-detonation simulations; Kim Zetter argues it was contemporaneous with Stuxnet

    Broadcom's Symantec and Carbon Black teams published on 2026-05-16 an analysis of fast16, the sabotage framework that SentinelOne first analyzed in April 2026 and whose oldest components date from around 2005, and confirm that its hook engine targets LS-DYNA and AUTODYN, applications used to simulate problems such as vehicle crashworthiness, material modelling and explosive simulation (Broadcom Security, 2026-05-16; The Hacker News, 2026-05-18). The framework combines a service binary that embeds a Lua 5.0 virtual machine, a boot-start filesystem filter driver that patches Intel-compiled executables on the fly as they are read from disk, and 101 byte-pattern rules in nine or ten groups for different builds of the two programs (Broadcom Security, 2026-05-16). Its hooks act only in high-explosive simulations and scale down outputs such as pressure or stress once the simulated material density passes 30 g/cm³, the threshold Broadcom says uranium reaches only under the shock compression of an implosion device, which it reads as sabotage of nuclear weapons research (Broadcom Security, 2026-05-16).

    Before installing, fast16 checks for 18 endpoint-security registry keys and refuses to spread if any is present; it then registers itself as a service whose file takes the creation dates and permissions of a system binary, loads its driver as a SCSI-class filter at the next boot, and persists by hijacking a chosen application through the Image File Execution Options Debugger value (Broadcom Security, 2026-05-16). It spreads only inside its own network, enumerating domains, servers and shares and, for hosts in local address ranges, copying itself to their admin share under the logged-on user's credentials and creating a remote service (Broadcom Security, 2026-05-16). Kim Zetter, citing Symantec researchers and nuclear experts, argues that if fast16 targeted Iran in 2005 it was contemporaneous with Stuxnet rather than its predecessor, and that it fed false simulation data to engineers rather than altering weapons (Kim Zetter / ZERO DAY, 2026-05-16); Broadcom still calls it a pre-Stuxnet tool (Broadcom Security, 2026-05-16).

    Exposure
    Windows hosts that run Intel-compiled simulation software, specifically builds of LS-DYNA and AUTODYN from that era; the framework does not spread to hosts carrying any of the endpoint-security products it checks for (Broadcom Security, 2026-05-16).
    Detection
    In driver inventory telemetry, a boot-start filter driver registered under the SCSI class that is unsigned or unfamiliar; in registry telemetry, an Image File Execution Options Debugger value that launches a non-debugger binary and is deleted and re-added around each launch of the target application; in file and service telemetry, a new service binary whose timestamps match a system file; in network telemetry, one host copying an executable to the admin shares of same-subnet hosts and starting remote services (Broadcom Security, 2026-05-16).
    Defender takeaway
    Broadcom does not know whether a modern version of fast16 exists; operators of simulation and research-computing estates concerned about similar sabotage should inventory loaded drivers regularly, flagging unsigned or unfamiliar ones, and run tightly tuned application control (Broadcom Security, 2026-05-16). Other organizations have no decision to make.
