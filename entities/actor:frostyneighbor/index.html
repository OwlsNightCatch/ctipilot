    NOTABLEupdatedNATOB2

    FrostyNeighbor (Ghostwriter, UNC1151): since March 2026, geofenced PDF lures deliver a JavaScript PicassoLoader and Cobalt Strike to Ukrainian government organisations

    ESET attributes new activity since March 2026 to FrostyNeighbor, also known as Ghostwriter, UNC1151, UAC-0057, TA445, PUSHCHA or Storm-0257, a long-running cyberespionage group apparently aligned with the interests of Belarus, using links in spearphishing PDFs to target governmental organisations in Ukraine (ESET, 2026-05-14). In ESET's telemetry the group's Ukrainian targeting focuses on military, defence and government, while its victimology in Poland and Lithuania is broader, spanning industry and manufacturing, healthcare and pharmaceuticals, logistics and many governmental organisations (ESET, 2026-05-14).

    The lure is a blurred PDF impersonating Ukrtelecom whose download button leads to the group's delivery server; visitors outside Ukraine receive a benign PDF of the same name, while Ukrainian IP addresses receive a RAR archive holding a JavaScript first stage that shows a decoy, re-runs itself, drops a base64-embedded JavaScript PicassoLoader and builds a scheduled task from an XML template the C2 serves as a fake JPG (ESET, 2026-05-14). PicassoLoader collects the username, computer name, OS version, boot time, current time and running processes, posts them over HTTPS every 10 minutes and evaluates any response longer than 100 bytes (ESET, 2026-05-14). Operators very likely decide by hand whether the victim is of interest; if so, the C2 returns a third-stage dropper that copies rundll32.exe into %ProgramData% under another name, writes the base64-decoded Cobalt Strike beacon DLL beside it, and registers in the HKCU Run key a LNK that starts the copied rundll32 with the DLL's export (ESET, 2026-05-14).

    Exposure
    Governmental organisations in Ukraine are the targets of this chain; the payload is delivered only after server-side checks of the user agent and IP address and a manual operator decision, so a request from outside Ukraine sees only the benign PDF (ESET, 2026-05-14).
    Detection
    In process telemetry, a JavaScript file from a RAR archive that relaunches itself, followed by scheduled-task creation from a downloaded XML template; in network telemetry, a script process posting to the same HTTPS endpoint every 10 minutes; in persistence telemetry, an HKCU Run entry pointing at a LNK in %ProgramData% that starts a renamed copy of rundll32.exe loading a DLL from the same directory (ESET, 2026-05-14).

    Triage: rundll32.exe is a normal Windows binary when it runs from the system directory; a copy of it under a different name in %ProgramData%, which ESET says is very likely meant to bypass detection rules, is the signal (ESET, 2026-05-14).

    Defender takeaway
    Because delivery is geofenced and operator-gated, a clean verdict on an Ukrtelecom-themed lure link from a sandbox outside Ukraine proves nothing; hunt on the host artefacts above instead (ESET, 2026-05-14). The Hacker News reports the same chain (The Hacker News, 2026-05-14).
