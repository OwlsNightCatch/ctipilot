    HIGHCVE-2026-41089 +3exploitedupdatedNATOA3

    Microsoft May 2026 Patch Tuesday: Netlogon pre-auth RCE on domain controllers (CVE-2026-41089), later reported exploited by Belgium's CCB, leads four critical fixes

    Microsoft's May 2026 Patch Tuesday fixed 118 vulnerabilities by Tenable's count, 16 rated critical, with none exploited or publicly disclosed at release (Tenable, 2026-05-12) (Krebs on Security, 2026-05-12); Help Net Security counts more than 120 (Help Net Security, 2026-05-12) and ZDI 138 (ZDI, 2026-05-12). The one that matters most is CVE-2026-41089 (CVSS 9.8), a stack-based buffer overflow in Windows Netlogon that lets an unauthenticated attacker execute code over the network (Microsoft MSRC); on a domain controller that means code execution as SYSTEM (CERT-EU, 2026-06-10). CVE-2026-41096 (CVSS 9.8) is a heap-based buffer overflow in the Windows DNS Client reachable through a malicious DNS response from an attacker able to influence replies (ZDI, 2026-05-12), which Microsoft assesses as less likely to be exploited (Krebs on Security, 2026-05-12). CVE-2026-41103 (CVSS 9.1) is an elevation of privilege in the Microsoft SSO Plugin for Jira and Confluence rated "Exploitation More Likely" (Tenable, 2026-05-12), and CVE-2026-42898 (CVSS 9.9) is a code-injection flaw in on-premises Dynamics 365 that requires an authenticated attacker (ZDI, 2026-05-12).

    Exposure
    CVE-2026-41089 affects Windows Server 2012 through 2025 acting as a domain controller; the fixed builds are 10.0.14393.9140 (2016), 10.0.17763.8755 (2019), 10.0.20348.5074 (2022), 10.0.25398.2330 (2022 23H2) and 10.0.26100.32772 (2025) (CERT-EU, 2026-06-10); Windows Server 2012 and 2012 R2 are also affected (CERT-EU, 2026-06-10), and Krebs reports patches for every Windows Server version from 2012 onwards (Krebs on Security, 2026-05-12).
    Detection
    The indicators Automox lists for the Netlogon flaw are unexpected Netlogon service crashes or restarts, anomalous Netlogon traffic patterns from source addresses that are not domain controllers, and authentication failures or domain trust errors right after suspicious traffic reaches a domain controller (Help Net Security, 2026-06-01).

    Contradiction: Belgium's CCB states that CVE-2026-41089 is exploited, on information from "trusted partners", while Microsoft told BleepingComputer it had no evidence to support the claim (CCB, 2026-05-29) (BleepingComputer, 2026-06-01).

    Defender takeaway
    Patch every domain controller to the fixed build (CERT-EU, 2026-06-10); because CCB reports exploitation and notes that patching does not remediate historic compromise (CCB, 2026-05-29), check domain controllers that were unpatched after the May update for the Netlogon indicators above.

    CCB's exploitation statement dates from 2026-05-29 and rests on information from trusted partners; Microsoft told BleepingComputer it had no evidence to support it (CCB, 2026-05-29) (BleepingComputer, 2026-06-01). Microsoft says 16 of the May CVEs, CVE-2026-41089 and CVE-2026-41096 among them, were found with its MDASH agentic system, and places the DNS Client flaw in dnsapi.dll (Microsoft Security Blog, 2026-05-12); no source says that flaw runs code as NetworkService. The priority moves from critical to high: the exploitation claim rests on one national CERT's partner information, Microsoft said in a statement BleepingComputer added on 2026-06-02 that it had no evidence, and its advisory lists the flaw as not exploited (Microsoft MSRC); patching domain controllers remains the action.
