    Exposure

    Triage

    Packet size separates nothing on a modern fleet, where members send the 120-byte form as normal time sync and the public tools emit 68 bytes; domain controllers can legitimately request a trust account's RID during hierarchy synchronization, so they need an allowlist (Huntress, 2026-11-19).     Detection

    Network and host telemetry, not authentication logs: the targeted accounts generate no 4768, 4769, 4624 or 4776 events. On the domain controller, Windows Filtering Platform audit event 5156 records w32time accepting the UDP/123 connection when that subcategory is enabled; on any other host, a process other than the time service sending UDP/123 to a domain controller is a high-signal EDR hit (Huntress, 2026-11-19). The rule that holds for both forms and even a single packet resolves the source address to its computer account and flags a request for any other RID; a source asking for many RIDs in a short window is the weaker volumetric fallback (Huntress, 2026-11-19).

    Hunt.io recovered the contents of three exposed open directories and, reading the operators' own files, reports a domain-controller workflow against a Swiss tax office: a log records ntdsutil install-from-media creation, and a script copies the domain database and the registry hives from a controller share to a staging area, decodes them with a single-byte XOR and then requests removal of the install-from-media set (Hunt.io, 2026-11-25). Hunt.io says complete off-host transfer is not independently confirmed, that an NTLM-relay run against an internal LDAP service belongs to the same environment, and that the Swiss output begins after code execution was already available, so how the crew first got in is not shown (Hunt.io, 2026-11-25). The report names no canton, commune or federal body, and Hunt.io says it notified CISA before publishing (Hunt.io, 2026-11-25).

    The same files hold a Java class registered as a java.sql.Driver service provider that poses as Microsoft's SQL Server JDBC driver: its boot routine runs when an application loads the JAR, with no scheduled task needed, and either polls an HTTPS endpoint on TCP 8443 for commands passed to cmd.exe or decodes a packed file into an Apollo-derived Windows executable written under the Java temp directory and started from Java (Hunt.io, 2026-11-25). Hunt.io reads the operation as a Chinese-speaking, Southeast Asia-based cybercrime crew running a Russian-authored toolkit and ties it to no named group and no state sponsor (Hunt.io, 2026-11-25).

    NOTABLENATOB2

    Huntress on timeroasting: the unauthenticated MS-SNTP sweep that harvests crackable MACs for computer and trust accounts leaves no logon event, Defender for Identity raised no alert in its tests, modern Windows sends an extended authenticator Huntress now has a cracker for, and the signal that holds is a host asking a domain controller to sign for an account other than its own

    Timeroasting abuses MS-SNTP, Microsoft's authentication extension to NTP: a client names an account by its RID, and the domain controller answers with a MAC computed with that account's password-derived key, without the client authenticating first; the reachable accounts are computer and trust accounts, and the MAC is then cracked offline with no further contact and no lockout (Huntress, 2026-11-19). Huntress names the crackable population as image-built or never-rotated machines, hand-set trusts and non-Windows joins, and says a pre-created account still on its lowercase-name default falls instantly while a normal random machine secret would not (Huntress, 2026-11-19).

    Reading w32time.dll and netlogon.dll on a fully patched Windows Server 2025 domain controller, Huntress documents two authenticator forms: a 68-byte legacy form with an MD5 MAC, which public tools emit and hashcat cracks, and a 120-byte extended form using HMAC-SHA512, which modern Windows clients send by default and which had no public cracker (Huntress, 2026-11-19). The patched controller answered extended-form requests that asked for the previous key, and Huntress published a reference implementation and a hashcat module for it that awaits a mode number upstream, so an extended-form capture can no longer be read as uncrackable (Huntress, 2026-11-19). Across eleven runs over five hours, with the sensor confirmed live by a control DCSync, Defender for Identity raised no alert on the MS-SNTP traffic; its "Suspicious SAM Account Name Change" alert, which names timeroasting, fires on a sAMAccountName change (event 5136), the fingerprint of the targeted variant, not of the unauthenticated sweep (Huntress, 2026-11-19).

    Exposure
    Windows domain controllers, which answer MS-SNTP for computer and trust accounts (Huntress tested one patched Windows Server 2025 controller, and Samba AD controllers do not implement the extended form); the accounts at risk are those whose secret is weak, hand-set or never rotated (Huntress, 2026-11-19).
    Detection
    Network and host telemetry, not authentication logs: the targeted accounts generate no 4768, 4769, 4624 or 4776 events. On the domain controller, Windows Filtering Platform audit event 5156 records w32time accepting the UDP/123 connection when that subcategory is enabled; on any other host, a process other than the time service sending UDP/123 to a domain controller is a high-signal EDR hit (Huntress, 2026-11-19). The rule that holds for both forms and even a single packet resolves the source address to its computer account and flags a request for any other RID; a source asking for many RIDs in a short window is the weaker volumetric fallback (Huntress, 2026-11-19).

    Triage: packet size separates nothing on a modern fleet, where members send the 120-byte form as normal time sync and the public tools emit 68 bytes; domain controllers can legitimately request a trust account's RID during hierarchy synchronization, so they need an allowlist (Huntress, 2026-11-19). A machine account that authenticates and then sprays shares is delegation abuse, not timeroasting (Huntress, 2026-11-19).

    Defender takeaway
    Do not treat Defender for Identity or authentication analytics as coverage; collect UDP/123 telemetry from domain controllers and build the own-RID check, and reset pre-created, image-built and hand-set computer and trust account secrets, since those are the ones a sweep can crack.
