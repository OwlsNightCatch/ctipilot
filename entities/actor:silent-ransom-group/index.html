    What each entry about Silent Ransom Group tells a defender to do, newest first.

    2026-11-14NOTABLEReliaQuest: Luna Moth has staff hand over a Graph token from Copilot on a video call; no sign-in event follows

    Defender takeaway

    Disable developer tools through Group Policy on managed browsers and block Graph Explorer and the browser net-export pages, because the handoff depends on users reading tokens out of browsers; pilot Continuous Access Evaluation with strict location enforcement, defining every egress address including secure web gateway ranges as a named location; and tell staff that IT will never ask for developer tools or tokens and that they should verify IT requests by callback (ReliaQuest, 2026-11-12). ReliaQuest notes that default Microsoft access tokens last 60 to 90 minutes and that Continuous Access Evaluation can extend supported tokens to as long as 28 hours (ReliaQuest, 2026-11-12).

    Exposure · detection
    Exposure

    A Microsoft 365 tenant whose staff can open browser developer tools and take calls from outside IT, with Microsoft 365 Copilot reachable in the browser; ReliaQuest says law firms are the current focus and other sectors holding similarly sensitive data could be next (ReliaQuest, 2026-11-12).

    Detection

    With no malware or endpoint alert, the evidence is ordinary-looking events, a blank email, an external video-call session and Graph access from an unfamiliar address, which ReliaQuest says to correlate across email, video-call and Microsoft 365 logs; a video-call screen share, a Copilot session, a visit to a text-sharing site and Graph file access from an unfamiliar address are each ordinary alone and together can indicate a token handoff (ReliaQuest, 2026-11-12). Video-call platform logs, web proxy or DNS logs and Microsoft 365 audit logs each record part of the handoff but rarely reach a detection pipeline (ReliaQuest, 2026-11-12).

    NOTABLENATOB3

    Luna Moth returns to law firms that likely did not pay, with a token handoff: a video-call 'IT support' agent has the employee copy a Microsoft Graph access token out of Microsoft 365 Copilot through browser developer tools, then bulk-downloads files from the attacker's own server (ReliaQuest)

    ReliaQuest says Luna Moth, also called Silent Ransom Group, has targeted law firms since at least mid-2023 and in October and early November went back to firms it had extorted in May and August; those firms appear on the group's leak site, which ReliaQuest says suggests they likely did not pay, and the group exfiltrated a second round of data (ReliaQuest, 2026-11-12). The approach reverses the group's earlier flow: a blank-subject email from a free address carries a deliberately invalid PDF that crashes the viewer, and the attacker then calls the target, often on a personal number outside corporate call controls, posing as IT support responding to a "malicious email" (ReliaQuest, 2026-11-12). By late August the group paired video calls with a built-in remote-assistance tool, and by October the video call alone carried both the conversation and the screen control (ReliaQuest, 2026-11-12).

    On the call the attacker has the employee open Microsoft 365 Copilot in the browser on a managed, compliant laptop, open the browser's developer tools to find the request Copilot sends to Microsoft Graph and copy the access token it carries, and paste the token into a public text-sharing site where the attacker retrieves it (ReliaQuest, 2026-11-12). Within a minute the attacker replays the token from its own server and downloads files en masse through the Graph API, thousands in about an hour (ReliaQuest, 2026-11-12). The stolen token passes Conditional Access because the device check runs only at sign-in, not when the token is later used, and, unlike device-code phishing, the token is issued to the victim's compliant device and then handed over (ReliaQuest, 2026-11-12). Nothing is installed, and the video-call applications are signed legitimate software (ReliaQuest, 2026-11-12).

    Exposure
    A Microsoft 365 tenant whose staff can open browser developer tools and take calls from outside IT, with Microsoft 365 Copilot reachable in the browser; ReliaQuest says law firms are the current focus and other sectors holding similarly sensitive data could be next (ReliaQuest, 2026-11-12).
    Detection
    With no malware or endpoint alert, the evidence is ordinary-looking events, a blank email, an external video-call session and Graph access from an unfamiliar address, which ReliaQuest says to correlate across email, video-call and Microsoft 365 logs; a video-call screen share, a Copilot session, a visit to a text-sharing site and Graph file access from an unfamiliar address are each ordinary alone and together can indicate a token handoff (ReliaQuest, 2026-11-12). Video-call platform logs, web proxy or DNS logs and Microsoft 365 audit logs each record part of the handoff but rarely reach a detection pipeline (ReliaQuest, 2026-11-12).
    Defender takeaway
    Disable developer tools through Group Policy on managed browsers and block Graph Explorer and the browser net-export pages, because the handoff depends on users reading tokens out of browsers; pilot Continuous Access Evaluation with strict location enforcement, defining every egress address including secure web gateway ranges as a named location; and tell staff that IT will never ask for developer tools or tokens and that they should verify IT requests by callback (ReliaQuest, 2026-11-12). ReliaQuest notes that default Microsoft access tokens last 60 to 90 minutes and that Continuous Access Evaluation can extend supported tokens to as long as 28 hours (ReliaQuest, 2026-11-12).
