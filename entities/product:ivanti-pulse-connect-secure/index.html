    Exposure

    25.1.1.1 and prior, 25.1.2.2 and prior and 22.8R2.4 and prior are affected by CVE-2026-104935 and 22.7.x and below are not (Rapid7, 2026-10-13).     Detection

    The appliance's own logs were tampered with, so start upstream: web proxy, load balancer or WAF logs for many requests to welcome.cgi, above all with an X-DSCGI-PATH header or one whose script differs from the URL path.     CRITICALCVE-2026-104935 +2exploitedupdatedNATOA1

    CVE-2026-104935, Ivanti Connect Secure: an authentication bypass chained to code execution is exploited as a zero-day, the root-escalation step was patched on 2026-10-29 and CISA lists all three chain flaws (CVSS 8.6)

    Ivanti disclosed CVE-2026-104935 in Connect Secure on 2026-10-13 and says it is aware of limited exploitation in the wild (Ivanti, 2026-10-13); Rapid7 describes it as an authentication bypass by spoofing that lets a remote unauthenticated attacker run commands, CVSS 8.6 (Rapid7, 2026-10-13), and CISA listed it in KEV the same day (CISA, 2026-10-13). Volexity tracks the operator as UTA0576 and dates exploitation of a fully patched 22.8R2.4 appliance to 2026-10-03 (Volexity, 2026-10-13).

    The chain has three steps. A request to the public login script welcome.cgi names a protected script in an X-DSCGI-PATH header, so the URL passes the authentication check and the header picks the destination. The upload script wu.cgi writes a file to disk before checking that it is a ZIP, and parallel requests run a Perl script before it is deleted. A root escalation then abuses the dsinvoked service's trust in the shared DSCache configuration store (Volexity, 2026-10-13). The first two steps are CVE-2026-104935 and the root step is CVE-2026-111357 (GitHub Advisory Database, 2026-10-15); Volexity's update banner says Ivanti patched it on 2026-10-29 (Volexity, 2026-10-13). CISA listed it and a third chain flaw, CVE-2026-118527, on 2026-10-30, says each can be chained with the other two, and describes CVE-2026-118527 as a predictable-identifier flaw that lets a remote authenticated attacker upload files with attacker-controlled content to a known location on disk (CISA KEV catalog, 2026-10-30). No source says which step of the chain that is, and it has no public CVE record or fixed build yet.

    The exploit leaves no web shell and patches library code in memory only, so Ivanti's Integrity Checker Tool, which looks for file changes, does not detect it, and Volexity found log entries removed. The operator then went after the Active Directory service account stored on the appliance: LDAP queries for LAPS passwords, BitLocker recovery keys and password attributes, password spraying, and packet capture of plaintext LDAP, HTTP Basic and NTLM traffic (Volexity, 2026-10-13).

    Exposure
    25.1.1.1 and prior, 25.1.2.2 and prior and 22.8R2.4 and prior are affected by CVE-2026-104935 and 22.7.x and below are not (Rapid7, 2026-10-13). The Canadian Cyber Centre's bulletin, updated 2026-10-30, lists every version before 25.1.1.3, 25.1.3.1 and 22.8R2.6 as affected (Canadian Centre for Cyber Security, 2026-10-13), which takes in 25.1.1.2 and 22.8R2.5, the builds of 2026-10-13; CISA's alert, updated the same day, says the three chain CVEs affect versions 25.1.1.2 and prior, 25.1.2.2 and prior and 22.8R2.5 and prior (CISA, 2026-10-13). Ivanti's advisory could not be read, so per-CVE fixed builds are unconfirmed.
    Detection
    The appliance's own logs were tampered with, so start upstream: web proxy, load balancer or WAF logs for many requests to welcome.cgi, above all with an X-DSCGI-PATH header or one whose script differs from the URL path. On domain controllers, look for LDAP queries from the appliance's service account for LAPS, BitLocker recovery and password attributes, and spraying from the appliance's address. Patching does not evict an attacker who is already in.

    Upgrade to 25.1.1.3, 25.1.3.1 or 22.8R2.6 now, then treat every appliance that was exposed on an affected build as a compromise-assessment target and rotate what it could reach. Where compromise cannot be excluded, isolate the appliance and preserve its memory and logs before any reset, because CERT-FR knows of lateral movement using the LDAP and Active Directory secrets stored on it (CERT-FR, 2026-10-14).

    CERT-FR's alert of 2026-10-14 says Ivanti reports the vulnerability as actively exploited and that CERT-FR itself is aware of lateral movement using the LDAP and Active Directory secrets stored on the appliance (CERT-FR, 2026-10-14). It puts the response in an order: fully isolate the appliance from both the internet and the internal network, snapshot the file system and memory of a virtual appliance, avoid powering it off so that traces survive, place the logs under seal and analyse the appliance with the Volexity indicators, and only then, on compromise, factory-reset it, upgrade and reset the secrets (CERT-FR, 2026-10-14). Its list of secrets to treat as compromised is wider than a password reset: the LDAP and Active Directory secrets, every certificate on the appliance (machine, user-authentication, code-signing and the TLS certificate of the exposed interface), the administration password, stored API keys, the passwords of local accounts including the service accounts used for authentication servers, the Kerberos tickets and other authentication material of those service accounts, and the licence-server authentication (CERT-FR, 2026-10-14). CERT-FR adds that running Ivanti's external Integrity Checker Tool needs physical access to the appliance and can interrupt service, and that some threats survive a factory reset (CERT-FR, 2026-10-14). Its affected-systems list names the 22.8Rx builds before 22.8R2.5, the 25.1.1.x builds before 25.1.1.2 and the 25.1.3.x builds before 25.1.3.1 and does not list a 25.1.2.x line; by counting 25.1.3.x builds before 25.1.3.1 as affected it includes 25.1.3.0, a build that Rapid7's table lists as resolved (CERT-FR, 2026-10-14).

    NOTABLECVE-2015-3306 +7exploitedNATOA2

    AA26-281A: China-linked actors enabled by Integrity Technology Group scan with MicroScan, spray Exchange and Microsoft 365 passwords and steal mail, and five old flaws from the scanner's scripts enter CISA KEV

    The FBI, CISA, NSA, NCSC UK and partners from Australia, Canada, Japan, New Zealand and Spain describe Integrity Technology Group as a China-based company with links to the Chinese government that builds and sells cyber tools, hosts infrastructure and compromises networks; the actors it enables use tactics consistent with Flax Typhoon, Ethereal Panda and Red Juliett, among others (FBI IC3, AA26-281A, 2026-10-08). The Justice Department says the FBI seized the domains of MicroScan and the FishHub phishing platform, both operated by Integrity Tech (U.S. Department of Justice, 2026-10-08). Victims include U.S. government services, other critical sectors and organisations in Southeast Asia, Africa and North America; the advisory names no Swiss victim (FBI IC3, AA26-281A, 2026-10-08).

    The chain starts with open-source scanners and MicroScan, a Python-based web application of 1,300-plus scripts, used since at least 2017 (FBI IC3, AA26-281A, 2026-10-08). Initial access has mostly come since January 2021 from command-line exploit utilities, and additionally from a cross-site-scripting payload that overlays a login form and offers a ZIP holding an executable that starts a process named like the Windows DiagTrack service (FBI IC3, AA26-281A, 2026-10-08). The actors spray and guess passwords with the EBurst tool against Exchange and Microsoft 365 (ECP, EWS, OAB, OWA, RPC, API, MAPI, PowerShell, Autodiscover, ActiveSync) (FBI IC3, AA26-281A, 2026-10-08). Persistence is a SoftEther VPN client, often named conhost.exe or dllhost.exe, which endpoint tools are less likely to flag (FBI IC3, AA26-281A, 2026-10-08). Collection uses a PHP bot and a Linux utility that read mail through Exchange Web Services and Microsoft 365 with application client, tenant and secret values, and a DCSync tool that replicates directory data from a domain controller; mail was stolen from government, law-enforcement and healthcare bodies in Southeast Asia (FBI IC3, AA26-281A, 2026-10-08).

    Appendix B lists eight successfully exploited CVEs recovered from MicroScan's scripts: ProFTPD 1.3.5, ISC BIND 9.x, Apache Struts 2.3.19 to 2.3.28, ONLYOFFICE DocumentServer 5.1.5 through 5.6.2 and Strapi up to 4.5.5, plus GNU Bash through 4.3, Pulse Connect Secure and GitLab from 11.9 (FBI IC3, AA26-281A, 2026-10-08); CISA added the first five to its catalogue on 2026-10-08 (CISA KEV catalogue, 2026-10-08). Apache names Struts 2.3.20.3, 2.3.24.3 and 2.3.28.1 as fixed (Apache Struts, 2021-02-13) and Strapi names 4.8.0 (Strapi, 2023-04-17).

    Exposure
    Internet-facing Exchange and Microsoft 365 sign-in without a second factor, web applications open to cross-site scripting, and the eight products at the versions above; an inventory and the Exchange authentication logs show whether an organisation is in scope (FBI IC3, AA26-281A, 2026-10-08).
    Detection
    Authentication logs across the Exchange interfaces for failed sign-ins spread over many accounts from one source, mailbox reads by connected applications nobody registered, a SoftEther client presented as conhost.exe or dllhost.exe in process and service-installation telemetry, directory-replication requests that reach a domain controller from a host that is not one, and web access logs for traversal, command-injection and enumeration attempts (FBI IC3, AA26-281A, 2026-10-08).

    Triage: conhost.exe and dllhost.exe are legitimate Windows names, so the file's path, signature and network behaviour separate a downloaded SoftEther client from the system binary (FBI IC3, AA26-281A, 2026-10-08).

    Defender takeaway
    Hunt Exchange and Microsoft 365 logs for spraying across interfaces and mailbox access by unknown applications, confirm multifactor authentication on webmail and VPN, and treat an internet-facing instance of any of the eight products as a possible intrusion point rather than patch debt.
