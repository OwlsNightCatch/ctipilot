    Exposure

    2026-07-31HIGHexploitedThe autonomous agent landed nothing; the operator's hand-driven work took data from three NetScaler targets and ran commands on 11 Marimo servers

    Defender takeaway

    The headline is not that an AI agent ran an attack; it is that the agent's attacks all failed against configuration and the human's did not. For the constituency the practical item is unglamorous: a SAML-IDP-configured NetScaler on an unpatched build leaks session material to anyone who asks, and it has been exploited by more than one unrelated actor since March. The secondary lesson is that the two products the agent chose autonomously, Langflow and n8n, are exactly the kind of self-hosted workflow and AI-orchestration software that spreads through research and public-sector environments without going through an asset inventory, and that in both cases the thing that saved the targets was an authentication setting rather than a patch.

    Latest update · triage · detection
    Latest update · 2026-08-10

    The patch has existed since April, so the practical action is inventory rather than remediation; identify which Windows hosts are actually configured as IKEv2 responders, confirm they took the April 2026 update, and close UDP 500/4500 inbound on the ones that are not. This adds mechanism to a CVE already known to have been reached in a real campaign; it does not change its patch status.

    Triage

    Scanning noise against edge appliances is constant, so volume alone discriminates nothing. Two things separate this from background scanning: the requests target the specific identity-provider paths rather than sweeping the whole surface, and successful reads produce responses that are neither errors nor valid authentication outcomes. On the enumeration side, ordinary vulnerability scanners announce themselves through breadth and user-agent consistency; what Unit 42 describes is narrow, sequenced and selective, a fingerprint pass followed by exploitation of only the matching subset.

    Detection

    For the NetScaler exposure the observable is in the appliance's own web logs: repeated requests to the SAML identity-provider endpoints from a single source, returning responses whose length varies request to request, with no corresponding completed authentication; memory-overread harvesting looks like a failing login loop that never fails cleanly. Follow it with authentication telemetry: a session cookie presented from an address or client fingerprint that never performed the sign-in that minted it is the downstream consequence the operator was working toward. More broadly, the enumeration behaviour Unit 42 describes leaves an approach signature worth hunting on any exposed application, high-volume version-fingerprinting requests from a narrow address set, followed within a short window by a small number of precisely-targeted exploit attempts against just the instances whose version replied in scope.

    T1053.005Scheduled Task/Job: Scheduled Task×2

    Adversaries may abuse the Windows Task Scheduler to perform task scheduling for initial or recurring execution of malicious code. There are multiple ways to access the Task Scheduler in Windows.     CVE-2026-111497, Node.js and Google Brotli (Node2Shell): an out-of-bounds write in the Brotli decoder lets crafted compressed data run code, reached through fetch() and Express 5 or body-parser 2 request bodies; fixed in Node.js 22.23.4, 24.22.1 and 26.12.1 and in the PyPI packages Brotli 1.2.1 and brotlicffi 1.2.1.0 (CVSS 4.0 9.2)

    Node.js shipped security releases on 2026-10-21 for CVE-2026-111497, an out-of-bounds write in the Brotli decoder it bundles: an invalid block switch was reported as a need for more input instead of a format error, so the streaming decoder kept appending input to an eight-byte internal buffer (Node.js project, 2026-10-21). An attacker who can supply Brotli data that an application decompresses with node:zlib can corrupt process memory, which can lead to a crash, disclosure of process memory or remote code execution (Node.js project, 2026-10-21). Imperva ran code carried in Brotli data against the official 24.22.0 image in its laboratory, through fetch() and through Express 5 and body-parser 2 request parsers, and the fixed 24.22.1 rejected the same input (Imperva, 2026-10-22).

    CISA added the flaw to its Known Exploited Vulnerabilities catalog on 2026-10-27 "based on evidence of active exploitation", naming no actor or victim (CISA, 2026-10-27). The only first-hand attack telemetry found is ELLIO's: on 2026-10-26 its sensors recorded one Brotli-coded request body of about 23 MB built against Node.js 24.22.0 on x86-64, although the chain got no shell against ELLIO's own copy of that build (ELLIO, 2026-10-26). Tenable relays the report without confirming it, and Cisco and Palo Alto say they know of no malicious use against their own products (Tenable, 2026-10-26; Cisco PSIRT, 2026-10-27; Palo Alto Networks, 2026-10-28).

    Fixes are in Node.js 22.23.4, 24.22.1 and 26.12.1; end-of-life lines are always affected, and because Node.js cherry-picked the fix without bumping the bundled version string, process.versions.brotli reads 1.2.0 on patched and vulnerable builds alike (Node.js project, 2026-10-21; ELLIO, 2026-10-26). The decoder is Google's, so Bun (fixed in 1.4.4), Istio, the PyPI packages Brotli (fixed in 1.2.1) and brotlicffi (1.2.1.0), Envoy and Microsoft .NET carry the flaw too (ELLIO, 2026-10-26; Tenable, 2026-10-26; OpenSourceMalware, 2026-10-23; Envoy, 2026-10-23; .NET Blog, 2026-10-25).

    Exposure
    A service on Node.js 22.x, 24.x or 26.x below the fixed releases that decodes Brotli from an untrusted party, either request bodies inflated by Express 5 or body-parser 2 or compressed responses that fetch() consumes from a server an attacker influences (Imperva, 2026-10-22); Python code that decompresses untrusted data with the PyPI packages (OpenSourceMalware, 2026-10-23); Envoy with the Brotli decompressor configured (Envoy, 2026-10-23); .NET applications that decompress attacker-controlled Brotli data (dotnet/announcements #494, 2026-10-25); VMware Cloud Foundation's SDDC Manager, critical on 9.1.1 with no patch yet (Broadcom, 2026-10-28); and PAN-OS 12.2, 12.1 and 11.2 firewalls that inspect Brotli traffic with TLS decryption enabled (Palo Alto Networks, 2026-10-28).
    Detection
    In web server, proxy and WAF logs, requests that carry a Brotli content encoding to endpoints that parse bodies, followed by worker crashes or restarts; in ELLIO's lab most of 400 attempts against Express crashed the worker instead of returning a shell, and a patched build answers at once with HTTP 400 and ERR__ERROR_FORMAT_BLOCK_SWITCH (ELLIO, 2026-10-26). Where systemd-coredump is enabled, each forced crash writes a core file that can hold other visitors' session cookies, tokens and key material, so restrict who can read it (ELLIO, 2026-10-26).
    Defender takeaway
    Replace the runtime, the two Python packages and any Envoy with the decompressor configured now, because CISA lists the flaw as exploited; where an update has to wait, reject Content-Encoding: br as NCSC Switzerland advises (NCSC Switzerland, 2026-10-26) and, if the application accepts no compressed request bodies, set the body-parser inflate option to false (Akamai, 2026-10-26).
