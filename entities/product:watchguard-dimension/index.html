    2026-10-31NOTABLELinux TCP use-after-free: Sophos hotfix and Ubuntu generic kernels out; WatchGuard, Fortinet have no fixed build

    Defender takeaway

    Install the distribution kernel and reboot as soon as it ships and confirm the running version afterwards; Ubuntu 20.04 and older and some variant kernels were not out on 2026-11-10. Until then, drop IPv4 TCP packets whose header carries IP options before the TCP stack sees them, tested first on one non-production host because it also drops legitimate option-bearing traffic; disabling MPTCP alone does not remove the path (CIQ, 2026-10-30).

    Exposure · detection
    Exposure

    A Linux host on a kernel below the fixed builds that accepts IPv4 TCP connections from an attacker; the demonstrated exploit needs an MPTCP listener, which sudo ss -M -l -n -p -e lists and which Go programs enable on Linux listen sockets by default since Go 1.24 unless the multipathtcp GODEBUG setting or a per-socket option overrides it (Akamai, 2026-11-02; Go team, 2026-10-29). CIQ's testing found that setting net.mptcp.enabled to 0 leaves the plain-TCP path reachable (CIQ, 2026-10-30), and Akamai reports a similar flaw when request-socket migration is on (Akamai, 2026-11-02).

    Detection

    No source publishes an indicator. Because the trigger is a SYN packet with IP options (CIQ, 2026-10-30) and a lost race only fails the handshake, so the attacker can retry (Anthropic, 2026-10-27), repeated option-bearing SYNs from one source toward a listener in firewall or flow telemetry are the pattern the mechanism implies.

    NOTABLECVE-2026-98432updatedNATOB2

    CVE-2026-98432, Linux kernel IPv4 TCP: a use-after-free in connection setup, present since 4.4, has an Anthropic-built remote root exploit against MPTCP listeners that CloudLinux could not reproduce; Citrix XenServer, XCP-ng, MikroTik, Red Hat, Debian, CIQ, Amazon Linux, Ubuntu's generic kernels for 22.04 to 26.10 and Sophos have fixes, Ubuntu 20.04 and older and some HWE, FIPS, NVIDIA and Azure variant kernels are in progress and WatchGuard and Fortinet have none for their products (CVSS 9.8)

    The Linux kernel CVE team published CVE-2026-98432 on 2026-10-15; the kernel.org CNA scores it 9.8 while upstream rates it 8.1 with high attack complexity (CIQ, 2026-10-30). It is a use-after-free in the IPv4 TCP connection setup path, introduced in Linux 4.4 and fixed upstream in 6.12.113, 6.18.56, 7.2.10 and 7.3-rc7 (Linux kernel CVE team, 2026-10-15). An unauthenticated peer starts it by sending TCP SYN packets that carry IPv4 options, and a retransmitted SYN can then touch the freed option memory (CIQ, 2026-10-30).

    Anthropic wrote on 2026-10-27 that Claude produced an exploit that gives a remote attacker root on a Linux server with a multipath TCP (MPTCP) listener (Anthropic, 2026-10-27), but CloudLinux's kernel team could not reproduce the claim (CloudLinux, 2026-11-02). Akamai is not aware of a public working exploit and says disabling MPTCP alone does not prevent exploitation (Akamai, 2026-11-02), whereas Vates, XCP-ng and WatchGuard say a public exploit exists or circulates (XCP-ng, 2026-11-04; Vates, 2026-11-04; WatchGuard, 2026-11-03). No source reports attacks, and NCSC-NL judges large-scale abuse unlikely given the exploit's complexity (NCSC-NL, 2026-10-30).

    Debian, Red Hat, CIQ and AWS have fixed kernels (Debian Security Tracker, 2026-11-03; Red Hat, 2026-11-03; CIQ, 2026-11-01; AWS, 2026-11-02), and Ubuntu's tracker, last updated 2026-11-10, lists 22.04 LTS to 26.10 as fixed (linux 5.15.0-203.213, 6.8.0-149.149, 7.0.0-43.43 and 7.3.0-10.10) while 20.04, 18.04 and 16.04 are still in progress (Canonical, 2026-11-10). Citrix has fixed its XenServer appliances (Citrix, 2026-11-03). XCP-ng released a kernel fix (XCP-ng, 2026-11-04), MikroTik's RouterOS 7.25.1 and 7.24.6 changelogs list the CVE (MikroTik, 2026-11-02; MikroTik, 2026-10-30), Sophos released Sophos Firewall hotfix HF110626.1 on 2026-11-06 and SD-RED firmware 3.0.012 on 2026-11-05 (Sophos, 2026-11-06), and Veeam's KB4966 says its Software and Infrastructure Appliances, workers, helper appliances and recovery media include an affected kernel, delivered fixed through Veeam Updater (Veeam, 2026-11-10). WatchGuard lists Fireware OS, AP and Dimension as potentially affected with no fix (WatchGuard, 2026-11-03); Fortinet names no fixed build but added an IPS virtual patch in FMWP database update 26.113 on 2026-11-07 (Fortinet, 2026-11-07).

    HIGHCVE-2026-19313 +4updatedNATOA2

    WatchGuard Fireware OS: three pre-auth RCEs in the iked IKE/VPN daemon plus a pre-auth stack overflow in the deprecated Mobile Security epm service

    WatchGuard's 27 August 2026 "Immediate Action Required" advisory ships fixes for eleven CVEs in Fireware OS, reserved under coordinated disclosure and detailed on WatchGuard's PSIRT pages. Two are pre-authentication remote code execution in the iked process, the daemon that handles IKE/IPsec VPN negotiation, each rated CVSS 4.0 9.3 Critical by WatchGuard: CVE-2026-19313 is a heap buffer overflow triggered by specially crafted network traffic reaching iked (WatchGuard PSIRT, 2026-08-27), and CVE-2026-19315 is a type confusion, with an out-of-bounds read and the release of an invalid pointer among its listed weaknesses, that lets a remote unauthenticated attacker execute arbitrary code with crafted network traffic (WatchGuard PSIRT, 2026-08-27). Both flaws need no authentication and no configuration beyond a running iked process, which handles VPN and Mobile IKEv2 negotiation and is commonly reachable from the internet on a Firebox configured as a VPN gateway.

    The third flaw, CVE-2026-13086 (also CVSS 4.0 9.3 Critical), is a stack-based buffer overflow in the epm (Endpoint Protection Manager) service used by Fireware's deprecated Mobile Security feature that lets an unauthenticated remote attacker execute arbitrary code, and WatchGuard's weakness list for it also includes the use of hard-coded credentials (WatchGuard PSIRT, 2026-08-27). WatchGuard rates it network-reachable with no privileges, user interaction or attack requirements (CVSS 4.0 AV:N/AC:L/AT:N/PR:N/UI:N), the same rating as the iked flaws (WatchGuard PSIRT, 2026-08-27), so an appliance with Mobile Security still enabled is exposed on those terms.

    All three, along with the remaining eight CVEs WatchGuard's own bulletin lists, are fixed in Fireware OS 2026.3.1, 2026.2.2, 12.12.2 and 12.5.20 (WatchGuard PSIRT, 2026-08-27). The 2026.3 branch is a separate affected band from the 2025.0-2026.2.2 one and takes its own fix: on CVE-2026-19315 (WatchGuard PSIRT, 2026-08-27) and CVE-2026-13086 (WatchGuard PSIRT, 2026-08-27) the band >= 2026.3, < 2026.3.1 sits on the Default product row, and on CVE-2026-19313 (WatchGuard PSIRT, 2026-08-27) and CVE-2026-19318 (WatchGuard PSIRT, 2026-08-27) it sits on the T15/T35 row. WatchGuard states it has not seen any indication that these vulnerabilities have been exploited (WatchGuard, 2026-08-27). Germany's BSI CERT-Bund relayed the same advisory as WID-SEC-2026-3068 the same day, listing a twelfth CVE for the same iked heap-overflow class not present in WatchGuard's own blog roundup, CVE-2026-81851, "Fireware OS Heap-Based Buffer Overflow in iked Allows Denial of Service" (BSI CERT-Bund, 2026-08-27).
