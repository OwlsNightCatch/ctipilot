    Defender takeaway

    Install the distribution kernel and reboot as soon as it ships; Debian's is out, Ubuntu's and Red Hat's were not on 2026-10-30. Until then, CIQ's interim measure is a packet filter that drops IPv4 TCP packets whose header carries IP options before the TCP stack sees them, to be tested on one non-production host first because it also drops legitimate TCP traffic that carries IP options; disabling MPTCP alone does not remove the path (CIQ, 2026-10-30).

    Exposure · detection
    Exposure

    A Linux host on a kernel below the fixed builds that accepts IPv4 TCP connections from an attacker; the demonstrated exploit needs an MPTCP listener, which sysctl net.mptcp.enabled shows as possible when it returns 1 and which matters for software built with Go 1.24 or newer, but CIQ's testing found that setting it to 0 leaves the plain-TCP path reachable (CIQ, 2026-10-30).

    Detection

    No source publishes an indicator. Because the trigger is a SYN packet with IP options (CIQ, 2026-10-30) and a lost race only fails the handshake, so the attacker can retry (Anthropic, 2026-10-27), repeated option-bearing SYNs from one source toward a listener in firewall or flow telemetry are the pattern the mechanism implies (an inference, since no source describes the traffic).

    NOTABLECVE-2026-98432NATOB2

    CVE-2026-98432, Linux kernel IPv4 TCP: a use-after-free in connection setup, present since 4.4, has an Anthropic-built remote root exploit against MPTCP listeners; Debian is fixed, Ubuntu and Red Hat kernels are not yet (CVSS 9.8)

    The Linux kernel CVE team published CVE-2026-98432 on 2026-10-15: a use-after-free in the IPv4 TCP connection setup path, introduced in Linux 4.4 and fixed upstream in 6.12.113, 6.18.56, 7.2.10 and 7.3-rc7 (Linux kernel CVE team, 2026-10-15). An unauthenticated peer starts it by sending TCP SYN packets that carry IPv4 options, and a retransmitted SYN or the ACK of the syncookie path can then touch the freed option memory (CIQ, 2026-10-30). Anthropic wrote on 2026-10-27 that Claude produced an exploit that lets a remote attacker send packets to a Linux server with a multipath TCP (MPTCP) listener and run arbitrary commands as root without credentials (Anthropic, 2026-10-27). The Go team says the bug is not specific to MPTCP, that systems with no MPTCP listener may be open to similar attacks, and that since Go 1.24 Go programs enable MPTCP on Linux listen sockets by default (Go team, 2026-10-29). NCSC-NL judges large-scale abuse unlikely given the exploit's complexity and the mitigations distributions carry (translated from Dutch) (NCSC-NL, 2026-10-30), and BleepingComputer found no confirmed report of exploitation in the wild (BleepingComputer, 2026-10-30).

    Severity is disputed: the CNA scores it 9.8, upstream 8.1 with high attack complexity (CIQ, 2026-10-30), and Red Hat rates it Critical for RHEL because it lets an unauthenticated remote attacker cause kernel memory corruption or an immediate crash over ordinary IPv4 TCP traffic, while saying reliable code execution needs precise heap control (Red Hat, 2026-10-31). Patch state as read on 2026-10-30 and 2026-10-31: Debian's security kernels 6.1.190-1 (bookworm) and 6.12.113-1 (trixie) are fixed (Debian Security Tracker, 2026-10-31); Ubuntu 22.04, 24.04, 26.04 and 26.10 are marked vulnerable with work in progress and 20.04, 18.04 and 16.04 vulnerable (Canonical, 2026-10-30); Red Hat lists RHEL 8, 9 and 10 as affected and RHEL 7 as not affected (BleepingComputer, 2026-10-30); BleepingComputer reports fixes for some kernel versions from Oracle Linux, Amazon Linux and SUSE (BleepingComputer, 2026-10-30); and CIQ had published no patched kernel for its RLC Pro LTS 9.6, RLC Pro LTS 8.10 or RLC Pro 10 variants and refers Rocky Linux community releases to Rocky errata (CIQ, 2026-10-30).

    Exposure
    A Linux host on a kernel below the fixed builds that accepts IPv4 TCP connections from an attacker; the demonstrated exploit needs an MPTCP listener, which sysctl net.mptcp.enabled shows as possible when it returns 1 and which matters for software built with Go 1.24 or newer, but CIQ's testing found that setting it to 0 leaves the plain-TCP path reachable (CIQ, 2026-10-30).
    Detection
    No source publishes an indicator. Because the trigger is a SYN packet with IP options (CIQ, 2026-10-30) and a lost race only fails the handshake, so the attacker can retry (Anthropic, 2026-10-27), repeated option-bearing SYNs from one source toward a listener in firewall or flow telemetry are the pattern the mechanism implies (an inference, since no source describes the traffic).

    Install the distribution kernel and reboot as soon as it ships; Debian's is out, Ubuntu's and Red Hat's were not on 2026-10-30. Until then, CIQ's interim measure is a packet filter that drops IPv4 TCP packets whose header carries IP options before the TCP stack sees them, to be tested on one non-production host first because it also drops legitimate TCP traffic that carries IP options; disabling MPTCP alone does not remove the path (CIQ, 2026-10-30).
