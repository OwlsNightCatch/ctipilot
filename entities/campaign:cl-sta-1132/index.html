    Exposure · detection
    Exposure

    A PA-Series or VM-Series firewall below the fixed build for its branch on which both of Palo Alto Networks' conditions hold: the User-ID Authentication Portal is configured (Device > User Identification > Authentication Portal Settings), and an interface management profile with Response Pages enabled is attached to an L3 interface in a zone where untrusted or internet traffic can enter; restricting the portal to trusted zones and disabling Response Pages in the Interface Management Profile of every L3 interface where untrusted traffic can enter, or disabling the portal, removes the exposure (Palo Alto Networks PSIRT). Threat ID 510019 (Applications and Threats content 9097-10022) blocks the attack for Threat Prevention subscribers and needs PAN-OS 11.1 or later (Palo Alto Networks PSIRT).

    Detection

    On the firewall, gaps in crash and kernel logs, deleted nginx crash records, outbound tunnelling connections from the firewall, and Active Directory queries made with the firewall's service account are the behaviours Unit 42 describes; a second device promoted to active after a burst of SAML traffic is a further signal (Unit 42, 2026-05-07). Patching does not remove a foothold, so a device that was exposed before its fixed build needs a compromise check.

    HIGHCVE-2026-0300exploitedupdatedNATOA1

    CVE-2026-0300: PAN-OS User-ID Authentication Portal unauthenticated root RCE, exploited by a likely state-sponsored cluster; fixed builds for every supported branch

    CVE-2026-0300 is a buffer overflow in the User-ID Authentication Portal (Captive Portal) service of PAN-OS that lets an unauthenticated attacker execute code with root privileges on PA-Series and VM-Series firewalls by sending crafted packets; Prisma Access, Cloud NGFW and Panorama are not affected (Palo Alto Networks PSIRT). Palo Alto scores it CVSS 4.0 9.3 where the portal is reachable from untrusted networks and 8.7 where it is restricted to trusted internal addresses, and reports limited exploitation against portals exposed to untrusted addresses or the internet (Palo Alto Networks PSIRT). CISA added it to its Known Exploited Vulnerabilities catalog on 2026-05-06 (CISA KEV catalog, 2026-05-06). Fixed builds are listed for every supported branch: 12.1.4-h5 and 12.1.7; 11.2.4-h17, 11.2.7-h13, 11.2.10-h6 and 11.2.12; 11.1.4-h33, 11.1.6-h32, 11.1.7-h6, 11.1.10-h25, 11.1.13-h5 and 11.1.15; 10.2.7-h34, 10.2.10-h36, 10.2.13-h21, 10.2.16-h7 and 10.2.18-h6; older unsupported versions must move to a supported fixed version, and the advisory's table still marks 12.1.7 with an ETA of 05/28 (Palo Alto Networks PSIRT).

    Unit 42 attributes the exploitation to CL-STA-1132, a cluster of likely state-sponsored activity: unsuccessful exploitation attempts began on 2026-04-09, and a week later the attackers achieved code execution and injected shellcode (Unit 42, 2026-05-07). They then cleared crash kernel messages and nginx crash entries and records, deployed the tunnelling tools EarthWorm and ReverseSocks5, enumerated Active Directory with the firewall's service-account credentials, and deleted ptrace injection evidence; on 2026-04-29 a SAML flood against the compromised device promoted a second device to active, inheriting the same internet-facing traffic, and that device was then targeted too (Unit 42, 2026-05-07).

    Exposure
    A PA-Series or VM-Series firewall below the fixed build for its branch on which both of Palo Alto Networks' conditions hold: the User-ID Authentication Portal is configured (Device > User Identification > Authentication Portal Settings), and an interface management profile with Response Pages enabled is attached to an L3 interface in a zone where untrusted or internet traffic can enter; restricting the portal to trusted zones and disabling Response Pages in the Interface Management Profile of every L3 interface where untrusted traffic can enter, or disabling the portal, removes the exposure (Palo Alto Networks PSIRT). Threat ID 510019 (Applications and Threats content 9097-10022) blocks the attack for Threat Prevention subscribers and needs PAN-OS 11.1 or later (Palo Alto Networks PSIRT).
    Detection
    On the firewall, gaps in crash and kernel logs, deleted nginx crash records, outbound tunnelling connections from the firewall, and Active Directory queries made with the firewall's service account are the behaviours Unit 42 describes; a second device promoted to active after a burst of SAML traffic is a further signal (Unit 42, 2026-05-07). Patching does not remove a foothold, so a device that was exposed before its fixed build needs a compromise check.

Prisma Access, Cloud NGFW and Panorama remain unaffected, and Threat ID 510019 remains the interim control for unpatched devices on PAN-OS 11.1 or later (Palo Alto Networks PSIRT).
