    Exposure · detection
    Exposure

    A service on Node.js 22.x, 24.x or 26.x below the fixed releases that decodes Brotli from an untrusted party, either request bodies inflated by Express 5 or body-parser 2 or compressed responses that fetch() consumes from a server an attacker influences (Imperva, 2026-10-22); Python code that decompresses untrusted data with the PyPI packages (OpenSourceMalware, 2026-10-23); Envoy with the Brotli decompressor configured (Envoy, 2026-10-23); .NET applications that decompress attacker-controlled Brotli data (dotnet/announcements #494, 2026-10-25); VMware Cloud Foundation's SDDC Manager, critical on 9.1.1 with no patch yet (Broadcom, 2026-10-28); and PAN-OS 12.2, 12.1 and 11.2 firewalls that inspect Brotli traffic with TLS decryption enabled (Palo Alto Networks, 2026-10-28).

    Detection

    In web server, proxy and WAF logs, requests that carry a Brotli content encoding to endpoints that parse bodies, followed by worker crashes or restarts; in ELLIO's lab most of 400 attempts against Express crashed the worker instead of returning a shell, and a patched build answers at once with HTTP 400 and ERR__ERROR_FORMAT_BLOCK_SWITCH (ELLIO, 2026-10-26). Where systemd-coredump is enabled, each forced crash writes a core file that can hold other visitors' session cookies, tokens and key material, so restrict who can read it (ELLIO, 2026-10-26).

    HIGHCVE-2026-111497exploitedupdatedNATOA1

    CVE-2026-111497, Node.js and Google Brotli (Node2Shell): an out-of-bounds write in the Brotli decoder lets crafted compressed data run code, reached through fetch() and Express 5 or body-parser 2 request bodies; fixed in Node.js 22.23.4, 24.22.1 and 26.12.1 and in the PyPI packages Brotli 1.2.1 and brotlicffi 1.2.1.0 (CVSS 4.0 9.2)

    Node.js shipped security releases on 2026-10-21 for CVE-2026-111497, an out-of-bounds write in the Brotli decoder it bundles: an invalid block switch was reported as a need for more input instead of a format error, so the streaming decoder kept appending input to an eight-byte internal buffer (Node.js project, 2026-10-21). An attacker who can supply Brotli data that an application decompresses with node:zlib can corrupt process memory, which can lead to a crash, disclosure of process memory or remote code execution (Node.js project, 2026-10-21). Imperva ran code carried in Brotli data against the official 24.22.0 image in its laboratory, through fetch() and through Express 5 and body-parser 2 request parsers, and the fixed 24.22.1 rejected the same input (Imperva, 2026-10-22).

    CISA added the flaw to its Known Exploited Vulnerabilities catalog on 2026-10-27 "based on evidence of active exploitation", naming no actor or victim (CISA, 2026-10-27). The only first-hand attack telemetry found is ELLIO's: on 2026-10-26 its sensors recorded one Brotli-coded request body of about 23 MB built against Node.js 24.22.0 on x86-64, although the chain got no shell against ELLIO's own copy of that build (ELLIO, 2026-10-26). Tenable relays the report without confirming it, and Cisco and Palo Alto say they know of no malicious use against their own products (Tenable, 2026-10-26; Cisco PSIRT, 2026-10-27; Palo Alto Networks, 2026-10-28).

    Fixes are in Node.js 22.23.4, 24.22.1 and 26.12.1; end-of-life lines are always affected, and because Node.js cherry-picked the fix without bumping the bundled version string, process.versions.brotli reads 1.2.0 on patched and vulnerable builds alike (Node.js project, 2026-10-21; ELLIO, 2026-10-26). The decoder is Google's, so Bun (fixed in 1.4.4), Istio, the PyPI packages Brotli (fixed in 1.2.1) and brotlicffi (1.2.1.0), Envoy and Microsoft .NET carry the flaw too (ELLIO, 2026-10-26; Tenable, 2026-10-26; OpenSourceMalware, 2026-10-23; Envoy, 2026-10-23; .NET Blog, 2026-10-25).

    Exposure
    A service on Node.js 22.x, 24.x or 26.x below the fixed releases that decodes Brotli from an untrusted party, either request bodies inflated by Express 5 or body-parser 2 or compressed responses that fetch() consumes from a server an attacker influences (Imperva, 2026-10-22); Python code that decompresses untrusted data with the PyPI packages (OpenSourceMalware, 2026-10-23); Envoy with the Brotli decompressor configured (Envoy, 2026-10-23); .NET applications that decompress attacker-controlled Brotli data (dotnet/announcements #494, 2026-10-25); VMware Cloud Foundation's SDDC Manager, critical on 9.1.1 with no patch yet (Broadcom, 2026-10-28); and PAN-OS 12.2, 12.1 and 11.2 firewalls that inspect Brotli traffic with TLS decryption enabled (Palo Alto Networks, 2026-10-28).
    Detection
    In web server, proxy and WAF logs, requests that carry a Brotli content encoding to endpoints that parse bodies, followed by worker crashes or restarts; in ELLIO's lab most of 400 attempts against Express crashed the worker instead of returning a shell, and a patched build answers at once with HTTP 400 and ERR__ERROR_FORMAT_BLOCK_SWITCH (ELLIO, 2026-10-26). Where systemd-coredump is enabled, each forced crash writes a core file that can hold other visitors' session cookies, tokens and key material, so restrict who can read it (ELLIO, 2026-10-26).
    Defender takeaway
    Replace the runtime, the two Python packages and any Envoy with the decompressor configured now, because CISA lists the flaw as exploited; where an update has to wait, reject Content-Encoding: br as NCSC Switzerland advises (NCSC Switzerland, 2026-10-26) and, if the application accepts no compressed request bodies, set the body-parser inflate option to false (Akamai, 2026-10-26).
    Update26 Oct 2026 03:40 UTCrun 2026-10-26T0256Z-intelactionsaffected_productsbodycvesentitiesevidencesourcessummary

    Two more vendors have shipped fixes for the same decoder flaw. Envoy's advisory of 2026-10-23 says a buffer overflow in its Brotli decompressor allows a remote unauthenticated attacker to corrupt adjacent decoder state memory, disclose sensitive memory contents, cause a denial of service or potentially execute arbitrary code with a crafted Brotli-compressed stream; it names v1.39.2, v1.38.5, v1.37.7 and v1.36.11 as vulnerable, v1.40.0, v1.39.3, v1.38.6, v1.37.8 and v1.36.12 as fixed, and limits the impact to deployments that have the Brotli decompressor configured (Envoy, 2026-10-23). Microsoft's out-of-band .NET release of 2026-10-25 (8.0.33, 9.0.22, 10.0.14 and 11 Release Candidate 3) fixes the same CVE, and an application is exposed only when it decompresses attacker-controlled Brotli data through ASP.NET Core request decompression, HttpClient automatic decompression or the Brotli APIs (dotnet/announcements #494, 2026-10-25); .NET Blog, 2026-10-25 lists the fixed releases. No source reports exploitation outside Imperva's laboratory demonstration against Node.js.

    Update27 Oct 2026 03:43 UTCrun 2026-10-27T0256Z-intelactionsaffected_productsbodycvesentitiesevidenceheadlinesourcessummarytags

    NCSC Switzerland (BACS) published advisory 13105 on 2026-10-26 on the Brotli decoder flaw: it names Node.js, Microsoft .NET, Visual Studio, PowerShell, the Python Brotli and brotlicffi packages and Bun among the affected dependents, rates the current exploitation status unknown with a proof of concept available, and gives as the temporary measure disabling Brotli decoding of untrusted data and rejecting Content-Encoding: br until patched, with services restarted and containers rebuilt after updating (NCSC Switzerland, 2026-10-26).

    Palo Alto Networks lists PAN-OS 12.2 before 12.2.4-h1, 12.1 before 12.1.4-h13, 12.1.7-h11 and 12.1.10-h3, and 11.2 before 11.2.4-h23, 11.2.7-h23, 11.2.10-h17, 11.2.13-h4 and 11.2.16-h1 as affected, but only on PA-Series and VM-Series firewalls that have inspection of Brotli-compressed traffic and TLS decryption enabled on the dataplane; PAN-OS 11.1 and 10.2 and the management interface are not affected, and the hotfixes carry estimated dates from 2026-10-27 to 2026-10-30 (Palo Alto Networks, 2026-10-26). Brotli encoding is disabled by default in PAN-OS 11.2.4 and later, the command show system setting brotli shows whether a firewall is exposed (Enabled: yes), and set system setting brotli-encoding disable is the vendor's interim mitigation; Palo Alto rates the urgency moderate and is not aware of malicious exploitation (Palo Alto Networks, 2026-10-26).

    PHP rebuilt its Windows packages as 8.5.12-1, 8.4.27-1, 8.3.36-1 and 8.2.35-1 on 2026-10-26 with Brotli 1.2.1; the vulnerable decoder is reachable there through the cURL extension when automatic HTTP response decompression is enabled, which cURL leaves off by default (PHP, 2026-10-26). Ubuntu lists brotli fixes for 26.10 (1.2.0-4ubuntu0.1), 26.04 LTS (1.2.0-3ubuntu0.1), 24.04 LTS (1.1.0-2ubuntu0.1) and 22.04 LTS (1.0.9-2ubuntu0.1), marks 20.04 LTS as needing evaluation and its nodejs package on 20.04, which vendors Brotli, as vulnerable (Ubuntu, 2026-10-26).

    Update28 Oct 2026 03:40 UTCrun 2026-10-28T0256Z-intelheadlinesummaryprioritytagscvessourcesevidencesourcing_noteactionsbodyaffected_productsentities

    CISA added CVE-2026-111497 to its Known Exploited Vulnerabilities catalog on 2026-10-27 "based on evidence of active exploitation", naming no actor or victim (CISA, 2026-10-27). ELLIO's sensors recorded a public checker that maps hosts decompressing Brotli and then, on 2026-10-26, one Brotli-coded request body of about 23 MB built against Node.js 24.22.0 on x86-64, which ELLIO reads as adoption by an operator focused on mass exploitation; its own test of the attacker's chain against that build got no shell in 50 attempts, so a failed attempt shows as a worker crash (ELLIO, 2026-10-26). Tenable relays the report and has not confirmed it (Tenable, 2026-10-26); Cisco and Palo Alto report no malicious use against their own products (Cisco PSIRT, 2026-10-27; Palo Alto Networks, 2026-10-28). Palo Alto's advisory, as read on 2026-10-28, shows six of the nine PAN-OS hotfixes released and the other three, 12.1.4-h13, 12.1.10-h3 and 11.2.4-h23, due on 2026-10-29 and 2026-10-30 (Palo Alto Networks, 2026-10-28).

    JFrog reproduced a remote crash of a ClickHouse server with one request carrying a crafted 23 MB body, with the fix merged but not released when it wrote (JFrog, 2026-10-25). Akamai gives a lever for Express 5 and body-parser 2 services that accept no compressed request bodies: set the inflate option to false (Akamai, 2026-10-26). A Node.js build is judged by its release version, because the bundled version string reads 1.2.0 on patched builds as well (ELLIO, 2026-10-26).

    Update29 Oct 2026 07:03 UTCrun 2026-10-29T0255Z-intelsummaryupdated_atentitiesaffected_productscvessourcesevidenceactionsbody

    Broadcom's advisory VMSA-2026-0008, issued on 2026-10-27 and revised as 0008.1 on 2026-10-28 to clarify the impacted products, lists VMware Cloud Foundation's SDDC Manager as affected because it uses Node.js: a malicious actor with network access to SDDC Manager may exploit the flaw to execute arbitrary code (Broadcom, 2026-10-28). Broadcom rates it critical, CVSS 3.1 9.8, on SDDC Manager 9.1.1 only and important, 7.5, on 9.1.0, 9.0.x and 5.2.x, none has a patch yet, and workarounds are in KB460732 for 9.1.1 and KB460734 for the others (Broadcom, 2026-10-28).

    Palo Alto Networks' timeline of 2026-10-29 removes the estimated dates of 11.2.4-h23, 12.1.4-h13 and 12.1.10-h3 because those builds are released, so every PAN-OS hotfix listed for this flaw is now available (Palo Alto Networks, 2026-10-29).
