    NOTABLECVE-2026-121653 +1updatedNATOA2

    CVE-2026-121653, Ivanti Endpoint Manager before 2024 SU8: an unauthenticated SQL injection in the Core leads to remote code execution (CVSS 3.1 9.8), with a missing-authentication flaw in the Cloud Services Application that edits trusted EPM Core certificates (CVE-2026-121683, 9.4)

    Ivanti's CNA records of 2026-11-10 describe CVE-2026-121653 as an SQL injection in the Core of Ivanti Endpoint Manager before 2024 SU8 that "allows a remote unauthenticated attacker to achieve remote code execution", scored CVSS 3.1 9.8 with a network vector, low complexity, no privileges and no user interaction (Ivanti via ENISA EUVD, 2026-11-10). A second record, CVE-2026-121683, describes missing authentication in Ivanti Cloud Services Application version 5.0.8 that lets a remote unauthenticated attacker add and delete arbitrary trusted EPM Core certificate entries, scored 9.4 (Ivanti via ENISA EUVD, 2026-11-10); CERT-FR lists that application as affected before 5.0.8.1 (CERT-FR, 2026-11-12). NCSC-NL reported on 2026-11-13 that public proof-of-concept code for CVE-2026-121653 can now be found on the internet, which it says raises the chance of active exploitation in the short term, and names no source for it (translated from Dutch) (NCSC-NL, 2026-11-13). Ivanti says it has no evidence of exploitation (Ivanti, 2026-11-10).

    Exposure
    An Ivanti Endpoint Manager Core server below 2024 SU8 that an attacker can reach; the records do not say which port or interface carries the injectable request. A trusted-certificate store that an unauthenticated caller can edit weakens the trust the Core places in the Cloud Services Application and its appliances.
    Detection
    No indicator is published; the signals that follow from the mechanism are SQL syntax or errors in requests to the Core's web service, child processes of that service, and trusted-certificate entries nobody approved.
    Defender takeaway
    Upgrade the Core to 2024 SU8 or later and the Cloud Services Application to 5.0.8.1; an endpoint-management server is a software-distribution channel to the whole estate, so an unauthenticated path to code execution on it warrants an out-of-cycle update even without reported exploitation, and a national CERT's report of public proof-of-concept code shortens the time to do it (NCSC-NL, 2026-11-13).
    Update14 Nov 2026 04:01 UTCrun 2026-11-14T0255Z-intelheadlinesummarytagscvessourcesevidencesourcing_noteactionsbody

    NCSC-NL revised its advisory on 2026-11-13 (revision 1.0.1) to say that public proof-of-concept code for CVE-2026-121653 can now be found on the internet and that this raises the chance of active exploitation in the short term; it rates probability medium and damage high, and names no source for the code (translated from Dutch) (NCSC-NL, 2026-11-13). CERT-FR's advisory of 2026-11-12 lists the Cloud Services Application as affected in version 5.0.8 before 5.0.8.1, so 5.0.8.1 is the fixed build (CERT-FR, 2026-11-12).     ROUTINECVE-2026-8043 +2updatedNATOA2

    CVE-2026-8043, Ivanti Xtraction: authenticated file read and HTML write (CVSS 9.6), patched with an Endpoint Manager SQL injection to RCE and a Virtual Traffic Manager admin command injection in Ivanti's May 2026 batch

    Ivanti's May 2026 security update of 2026-05-12 discloses vulnerabilities in Secure Access Client, Xtraction, Virtual Traffic Manager and Endpoint Manager (EPM), and Ivanti says it has no evidence of any of them being exploited in the wild (Ivanti, 2026-05-12); SecurityWeek counts seven flaws across the four advisories (SecurityWeek, 2026-05-13). The most severe, CVE-2026-8043, is external control of a file name in Xtraction before version 2026.2 that lets a remote authenticated attacker read sensitive files and write arbitrary HTML files to a web directory, leading to information disclosure and possible client-side attacks; Ivanti scores it 9.6, with low privileges required and a changed scope (ENISA EUVD, 2026-05-12).

    The batch also fixes CVE-2026-8111, an SQL injection in the EPM web console before 2024 SU6 that lets a remote authenticated attacker achieve remote code execution, scored 8.8 (ENISA EUVD, 2026-05-12), and CVE-2026-8051, an OS command injection in Virtual Traffic Manager before 22.9r4 that lets a remote authenticated attacker with admin privileges achieve remote code execution, scored 7.2 (ENISA EUVD, 2026-05-12). CERT-FR lists the affected versions as EPM before 2024 SU6, Secure Access Client before 22.8R6, Virtual Traffic Manager before 22.9r4 and Xtraction before 2026.2 (CERT-FR, 2026-05-13).

    Exposure
    Any Xtraction installation before version 2026.2 is attackable by a user with a low-privilege account (ENISA EUVD, 2026-05-12); the EPM web console before 2024 SU6 by any authenticated user (ENISA EUVD, 2026-05-12); Virtual Traffic Manager before 22.9r4 only by holders of admin credentials (ENISA EUVD, 2026-05-12).
    Detection
    No exploitation or exploit detail is published; on Xtraction servers, file-integrity telemetry on the web directory surfaces HTML files that no release or administrator placed there, the artifact the write primitive leaves (ENISA EUVD, 2026-05-12).
    Defender takeaway
    Patch in the regular cycle, Xtraction first by severity: Xtraction 2026.2, EPM 2024 SU6, Virtual Traffic Manager 22.9r4 and Secure Access Client 22.8R6 (CERT-FR, 2026-05-13); Ivanti says it has no evidence of these vulnerabilities being exploited in the wild (Ivanti, 2026-05-12).
