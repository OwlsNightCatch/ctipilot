    2026-11-15NOTABLEPolinRider: forged backdated commits, npm hijacks and a fake recruiter run a loader at build or folder open

    Defender takeaway

    Treat a machine or runner that built an infected checkout as compromised and rotate what it could reach, because the stolen access, not the file, reinfects; run take-home tests from unknown recruiters only in a throwaway virtual machine with no tokens or keys, and block public blockchain RPC from CI runners (Apiiro, 2026-11-09; JFrog, 2026-11-09).

    Exposure · triage · detection
    Exposure

    Any developer machine, CI runner or coding agent that builds or opens a checkout the worm reached, installs one of the hijacked npm packages, or runs a take-home from an unverified recruiter. Apiiro's checks are a semicolon followed by 200 or more spaces on any branch, a .vscode/tasks.json task with runOn set to folderOpen that runs node, and force-pushes in the GitHub Activity view whose commit is dated days before the push (Apiiro, 2026-11-09).

    Triage

    Blockchain developers legitimately call public RPC endpoints; the discriminator is a build or lint process in a project with no Web3 purpose doing so and then spawning a detached node child (Apiiro, 2026-11-09).

    Detection

    In process telemetry, a detached node child with no console started from a build script, editor or package entrypoint; in egress telemetry, build hosts and CI runners resolving public blockchain RPC endpoints and then making plain HTTP requests on port 443 to a bare IP address; in GitHub audit telemetry, force-pushes whose replacement commit repeats the replaced commit's author and message (Apiiro, 2026-11-09; Sonatype, 2026-11-04).

    Defender takeaway

    Treat a coding assignment or repository from a recruiter or interviewer as untrusted code, because here the compromise needed only a trusted workspace and an opened terminal.     Exposure · triage · detection
    Exposure

    Developer workstations whose users clone and open repositories from outside parties, recruitment pretexts included, in an editor that trusts the workspace; and any managed device that is compliant in identity and device management but does not report to the endpoint console, as Sophos's fleet review found (Sophos RCA, 2026-10-20).

    Triage

    A terminal profile normally launches a shell executable; this one launched a command that downloads and runs a remote script in a loop; it came from the settings of a freshly cloned repository (Sophos RCA, 2026-10-20).

    Detection

    In macOS process lineage, the code editor's integrated terminal launching a download-and-run command that a cloned workspace's settings define, followed by a hidden directory in the user profile and a package-manager install run from it (Sophos RCA, 2026-10-20). In identity telemetry, a device that still signs in but does not report to the endpoint console is a coverage gap; a third-party authorization reading repositories from an address new to the user is the second signal (Sophos blog, 2026-11-04; Sophos RCA, 2026-10-20).

    Defender takeaway

    This is a social-engineering-led initial-access vector, not an exploited vulnerability, so the controls are procedural rather than patch-based. Employees approached by recruiters, developers above all, should never run take-home-assignment or interview code on a machine that holds work credentials or production access, and should sandbox or review any coding-assignment repository before execution. HR and recruiting workflows, including at cantonal or federal IT departments and their contracted suppliers that source developer talent through crowdsourcing or freelance platforms, should verify a remote contractor's identity documents against known facilitator/laptop-farm patterns before onboarding. The advisory's interview flags for suspected North Korean IT workers are refusals or excuses regarding in-person meetings, requests to receive payment in cryptocurrency, frequent glances at another monitor as if reading from the screen, occasional background voices, and repeated video or audio freezes (FBI/IC3, 2026-09-18). For developers and their endpoints, the advisory's controls are to open unknown VS Code projects only in Restricted Mode, by answering "No" to the prompt asking whether to trust the authors of the files in the folder, which stops .vscode/tasks.json from running on launch. Developers should check any tasks.json for code that downloads or executes further files, avoid opening unknown projects from a path previously marked as trusted, run unknown code only in a sandbox or virtual machine, and be especially cautious of commands or scripts containing strings such as curl, base64, -enc, mshta, Invoke-WebRequest or hidden (FBI/IC3, 2026-09-18).

    Triage
    Triage

    The advisory lists the data the actors' infostealers target (browser authentication data, clipboard contents, keystrokes, screenshots and wallet data) and the StoatWaffle delivery through a malicious VS Code configuration file that runs when the folder is opened and trusted (FBI/IC3, 2026-09-18). It gives no process lineage, so as a hunting hypothesis expect a node or python process spawned from an IDE or terminal shortly after a new project folder is opened or npm install completes, then reading browser credential stores or the clipboard; legitimate build tooling does neither. The distinguishing context is timing correlation with an active job-interview or coding-test process rather than node, npm or VS Code activity alone.

    PolinRider: a North Korea-linked loader reaches developers through force-pushed forged commits in at least 7,609 GitHub repositories, hijacked npm releases and a fake employer's take-home test, and reads its server address from an Ethereum wallet

    Apiiro calls PolinRider a North Korea-linked worm and found it in at least 7,609 GitHub repositories owned by 2,330 accounts, mostly developers' own (Apiiro, 2026-11-09). Three routes, none relying on an npm install script. Forged commits: with stolen GitHub access the worm force-pushes a copy of a commit the owner already made, with the same author, message and date, plus a loader hidden after hundreds of spaces in a build configuration file; in 94% of 9,990 injection pushes the copy claims to be more than an hour older than the push, so git log shows an old commit under the owner's name. Cloning runs nothing; building the project or running its dev, build or lint scripts loads the file, and in the newest wave opening the folder in VS Code is enough (Apiiro, 2026-11-09). Hijacked npm releases: Sonatype found concealed loaders in 12 releases across 10 hijacked packages with no install or postinstall hook, so disabling install scripts does not help (Sonatype, 2026-11-04). A fake employer: JFrog traced AccuraSoftHire, a decoy recruiter with ID-verified LinkedIn recruiters and job ads, whose take-home loads a look-alike npm package and whose scripted camera check fails and hands the candidate a command that installs the same loader (JFrog, 2026-11-09); StepSecurity says taking its site down, as had happened by 2026-11-13, does not end the operation (StepSecurity, 2026-11-13).

    The loader reads the latest outbound transaction of a hard-coded Ethereum wallet and decodes two IPv4 addresses from its recipient field (Apiiro, 2026-11-09), then fetches XOR-encoded JavaScript over plain HTTP on port 443, so blocking one server changes nothing; the wallet in the hijacked npm releases also appears in GitGuardian's GhostAction report, which Sonatype says does not establish a shared operator (Sonatype, 2026-11-04). Cleanup does not hold: 1,949 repositories were infected again after being publicly listed, and where owners cleaned up the stolen access often still worked; Apiiro counts roughly 2,300 developers reached (Apiiro, 2026-11-09).

    Exposure
    Any developer machine, CI runner or coding agent that builds or opens a checkout the worm reached, installs one of the hijacked npm packages, or runs a take-home from an unverified recruiter. Apiiro's checks are a semicolon followed by 200 or more spaces on any branch, a .vscode/tasks.json task with runOn set to folderOpen that runs node, and force-pushes in the GitHub Activity view whose commit is dated days before the push (Apiiro, 2026-11-09).
    Detection
    In process telemetry, a detached node child with no console started from a build script, editor or package entrypoint; in egress telemetry, build hosts and CI runners resolving public blockchain RPC endpoints and then making plain HTTP requests on port 443 to a bare IP address; in GitHub audit telemetry, force-pushes whose replacement commit repeats the replaced commit's author and message (Apiiro, 2026-11-09; Sonatype, 2026-11-04).

    Triage: blockchain developers legitimately call public RPC endpoints; the discriminator is a build or lint process in a project with no Web3 purpose doing so and then spawning a detached node child (Apiiro, 2026-11-09).

    Defender takeaway
    Treat a machine or runner that built an infected checkout as compromised and rotate what it could reach, because the stolen access, not the file, reinfects; run take-home tests from unknown recruiters only in a throwaway virtual machine with no tokens or keys, and block public blockchain RPC from CI runners (Apiiro, 2026-11-09; JFrog, 2026-11-09).

StepSecurity counts 576 infected repositories of 622 it fetched, across 311 accounts, and assesses from a shared funding wallet that the fake interviews and these infections share an operator (StepSecurity, 2026-11-26).

    NOTABLEupdatedNATOB2

    Sophos's own root-cause analysis of a developer-targeted intrusion: a fake job-interview repository's VS Code workspace settings ran BeaverTail and InvisibleFerret on a Mac whose endpoint agent had not reported since 11 June, and a third-party OAuth authorization outlived the session revocation

    On 2026-09-14 a Sophos employee cloned a public repository presented as a job-interview coding assignment and opened it as a workspace in VS Code; a weaponized workspace settings file replaced the editor's integrated terminal profile with a command that downloads and runs a remote script in a loop, delivery relied on the user opening the workspace as trusted, and no exploit or vulnerability was involved (Sophos RCA, 2026-10-20). Opening a terminal was enough: a shell script fetched a JavaScript component and a package manifest into a hidden directory in the user profile, a package-manager install ran, the JavaScript ran under Node.js and the final-stage backdoor lived in memory only, with no persistence found (Sophos RCA, 2026-10-20). SophosLabs identified the BeaverTail loader followed by the InvisibleFerret backdoor, able to steal browser-stored credentials, keychain data and SSH keys, and the JavaScript stage sent the process environment to an attacker web endpoint on a cloud application-hosting service (Sophos RCA, 2026-10-20).

    Two gaps lengthened the exposure. The Sophos Endpoint agent was installed but its core services were not running, so it enforced nothing and reported nothing; the device was last seen in Sophos Central on 2026-06-11, the cause is still under investigation, and SophosLabs says a working agent would have blocked the chain at the first dropped file (Sophos RCA, 2026-10-20). A third-party application authorization on the employee's source-code platform account survived the session revocation and password reset of 2026-09-15 and made 27 read requests against two internal repositories from an address new to the user until it was revoked on 2026-09-16; Sophos found no other host, no cloud activity and no customer impact (Sophos RCA, 2026-10-20). The analysis names no group; Sophos CTU says the technique matches the tradecraft of NICKEL ALLEY, which it describes as running the Contagious Interview campaign of fake companies, fake recruiters and malicious code repositories (Sophos blog, 2026-11-04).

    Exposure
    Developer workstations whose users clone and open repositories from outside parties, recruitment pretexts included, in an editor that trusts the workspace; and any managed device that is compliant in identity and device management but does not report to the endpoint console, as Sophos's fleet review found (Sophos RCA, 2026-10-20).
    Detection
    In macOS process lineage, the code editor's integrated terminal launching a download-and-run command that a cloned workspace's settings define, followed by a hidden directory in the user profile and a package-manager install run from it (Sophos RCA, 2026-10-20). In identity telemetry, a device that still signs in but does not report to the endpoint console is a coverage gap; a third-party authorization reading repositories from an address new to the user is the second signal (Sophos blog, 2026-11-04; Sophos RCA, 2026-10-20).

    Triage: a terminal profile normally launches a shell executable; this one launched a command that downloads and runs a remote script in a loop; it came from the settings of a freshly cloned repository (Sophos RCA, 2026-10-20).

    Defender takeaway
    Treat a coding assignment or repository from a recruiter or interviewer as untrusted code, because here the compromise needed only a trusted workspace and an opened terminal. Sophos's lasting controls are to require the endpoint agent for device compliance, to monitor for managed devices that stop reporting, and to revoke application authorizations as part of credential containment, not only sessions and passwords (Sophos RCA, 2026-10-20).

    NOTABLEupdatedNATOA1

    WaterPlum ("Contagious Interview"): a seven-agency joint advisory counts 30,000+ devices in 100+ countries and $10.7M in crypto from December 2025 to July 2026, and discloses Japan's first dismantled "laptop farm"

    Seven government agencies (Japan's National Police Agency and National Cybersecurity Office, the US FBI and DoD Cyber Crime Center, Australia's Signals Directorate/ACSC, and Germany's BND and BfV) jointly published a Cybersecurity Advisory on 2026-09-18 on the North Korean "WaterPlum" cyber-actor group, publicly known as Contagious Interview (FBI/IC3, 2026-09-18). The advisory puts figures on the campaign from around December 2025 through July 2026: at least 30,000 infected devices across more than 100 countries, funds or credentials exfiltrated from over 7,000 cryptocurrency wallets, and roughly 1.7 billion Japanese yen (about USD 10.7 million) moved to DPRK (FBI/IC3, 2026-09-18). Germany's BfV confirms the campaign has targeted software developers "also in Germany" (translated from German) (Bundesamt für Verfassungsschutz, 2026-09-18).

    WaterPlum poses as recruiters, frequently impersonating AI, cryptocurrency or NFT companies and also using legitimate freelance and recruiting platforms, to lure software developers and IT professionals into a technical interview or take-home coding assignment; victims are told to download and run files hosted on collaboration platforms and code repositories to "complete a coding assignment or troubleshoot an error." Those files carry one of five malware families the advisory names: BeaverTail (JavaScript-based malware hidden inside NPM packages and downloadable from GitHub or Bitbucket), InvisibleFerret (a Python backdoor), OtterCookie (a JavaScript RAT and infostealer), OtterCandy (combining OtterCookie and RATatouille features), and StoatWaffle, a modular Node.js loader, credential harvester and RAT that hides inside blockchain-themed decoy VS Code project repositories and auto-executes through a malicious VS Code configuration file the moment the victim opens and trusts the folder (FBI/IC3, 2026-09-18). Once backdoored, operators use the RATs for persistence and lateral pivoting while infostealers harvest browser-stored credentials, clipboard contents, keystrokes, screenshots and cryptocurrency-wallet data to a command-and-control address; the same access lets operators pursue further espionage or intellectual-property theft inside the victim's employer.

    The advisory ties the malware-delivery operation to North Korea's remote-IT-worker placement scheme: "the NPA and the FBI assess both WaterPlum cyber actors and some North Korean IT workers operate under the 313 General Bureau of the Munitions Industry Department subordinate to the Central Committee of the Workers Party of Korea" (FBI/IC3, 2026-09-18). It adds that some WaterPlum actors also operate as North Korean IT workers, and that both used the same IP addresses when accessing laptop farms, using crowdsourcing services and applying for positions at a Japanese cryptocurrency exchange (FBI/IC3, 2026-09-18). Separately, Japanese authorities "for the first time in Japan" identified and dismantled a "laptop farm" operated by an enabler in Japan, and obtained evidence that the actor group transferred "several hundred million" yen in cryptocurrency abroad. The advisory defines a laptop farm as a location, often an enabler's residence, where employment-related computers are set up and remotely controlled by North Korean IT workers (FBI/IC3, 2026-09-18). The advisory records two prior cases of IT-worker escalation beyond simple wage fraud: one worker extorted a company over payment and published its proprietary source code online, and another defaced and disabled a hiring company's website (FBI/IC3, 2026-09-18).

    Defender takeaway
    This is a social-engineering-led initial-access vector, not an exploited vulnerability, so the controls are procedural rather than patch-based. Employees approached by recruiters, developers above all, should never run take-home-assignment or interview code on a machine that holds work credentials or production access, and should sandbox or review any coding-assignment repository before execution. HR and recruiting workflows, including at cantonal or federal IT departments and their contracted suppliers that source developer talent through crowdsourcing or freelance platforms, should verify a remote contractor's identity documents against known facilitator/laptop-farm patterns before onboarding. The advisory's interview flags for suspected North Korean IT workers are refusals or excuses regarding in-person meetings, requests to receive payment in cryptocurrency, frequent glances at another monitor as if reading from the screen, occasional background voices, and repeated video or audio freezes (FBI/IC3, 2026-09-18). For developers and their endpoints, the advisory's controls are to open unknown VS Code projects only in Restricted Mode, by answering "No" to the prompt asking whether to trust the authors of the files in the folder, which stops .vscode/tasks.json from running on launch. Developers should check any tasks.json for code that downloads or executes further files, avoid opening unknown projects from a path previously marked as trusted, run unknown code only in a sandbox or virtual machine, and be especially cautious of commands or scripts containing strings such as curl, base64, -enc, mshta, Invoke-WebRequest or hidden (FBI/IC3, 2026-09-18).

    Triage: the advisory lists the data the actors' infostealers target (browser authentication data, clipboard contents, keystrokes, screenshots and wallet data) and the StoatWaffle delivery through a malicious VS Code configuration file that runs when the folder is opened and trusted (FBI/IC3, 2026-09-18). It gives no process lineage, so as a hunting hypothesis expect a node or python process spawned from an IDE or terminal shortly after a new project folder is opened or npm install completes, then reading browser credential stores or the clipboard; legitimate build tooling does neither. The distinguishing context is timing correlation with an active job-interview or coding-test process rather than node, npm or VS Code activity alone.
