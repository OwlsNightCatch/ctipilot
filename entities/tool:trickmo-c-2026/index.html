    Exposure · detection
    Exposure

    NOTABLEupdatedNATOB2

    TrickMo C: Android banking trojan moves its C2 onto The Open Network and turns infected phones into SOCKS5 and SSH network pivots

    ThreatFabric identified a new TrickMo variant between January and February 2026 that is progressively replacing its predecessor in campaigns against banking and wallet customers in France, Italy and Austria (ThreatFabric, 2026-05-11). The on-device feature set is largely unchanged: once the user grants the accessibility-service permission the bot coerces, the operator gets overlay credential phishing, keylogging, screen recording and streaming, remote control, and SMS and notification interception that silently suppresses one-time-password messages, while the offensive code arrives as a module fetched from operator infrastructure at runtime (ThreatFabric, 2026-05-11). Campaign tags point to TikTok-themed apps delivered over Facebook (ThreatFabric, 2026-05-11); the droppers pose as adult-friendly versions of TikTok and the malware as Google Play Services (The Hacker News, 2026-05-12).

    Command and control now runs over The Open Network: an embedded native TON proxy starts on a loopback port, the bot's HTTP client sends every request through it to .adnl hostnames resolved inside the TON overlay, and the few clearnet names it still needs are resolved over public DNS-over-HTTPS (ThreatFabric, 2026-05-11). New operator commands run curl, DNS lookups, ping, multi-port TCP-connect probes and traceroute from the device's network position, open SSH local-forward and remote-forward tunnels, the latter reaching into the corporate or home LAN the phone is on, and start an authenticated SOCKS5 proxy whose traffic appears to come from the victim's IP and so defeats IP-based fraud checks (ThreatFabric, 2026-05-11). The Pine hooking framework and a full set of NFC permissions are bundled but unused, which ThreatFabric reads as preparation for features delivered at runtime later (ThreatFabric, 2026-05-11).

    Exposure
    Android users of banking, fintech, wallet and authenticator apps in France, Italy and Austria, by the campaign tags; any corporate or home network an infected phone joins is reachable to the operator through the remote-forward tunnel (ThreatFabric, 2026-05-11).
    Detection
    Network-edge traffic analysis sees only encrypted TON traffic that cannot be told apart from other TON applications, and takedowns of the C2 lose effect (ThreatFabric, 2026-05-11), so the signals sit on the device and around it: in mobile-device inventories, an app presenting itself as Google Play Services that holds the accessibility-service permission (The Hacker News, 2026-05-12), and in internal network telemetry, TCP-connect sweeps, DNS lookups and traceroutes originating from a phone's address (ThreatFabric, 2026-05-11).
    Defender takeaway
    ThreatFabric judges domain takedowns largely ineffective against this variant and network blocking less effective (ThreatFabric, 2026-05-11), so the control point is the device: on managed Android devices, restrict app installs from outside the official store and accessibility-service grants, and handle an infected phone that has joined a corporate network as a foothold in that network as well as a fraud case. Security Affairs reports the same findings (Security Affairs, 2026-05-12).
