    HIGHNATOA2

    Fortinet coordinated security hardening release: critical and high-severity fixes in FortiOS 8.0.2, 7.6.8, 7.4.13 and 7.2.14, FortiManager, FortiAnalyzer, FortiMail and FortiAuthenticator, with the advisories withheld until 2026-11-10

    Fortinet announced on 2026-10-21 a coordinated set of security updates for FortiOS, FortiManager and FortiAnalyzer, scheduled for 2026-10-22 and following recent releases for FortiMail and FortiAuthenticator (Fortinet, 2026-10-21). Fortinet says the releases fix vulnerabilities found through its frontier-AI-assisted testing programme, that they include critical and high-severity fixes, and that customers should treat them as a priority change rather than routine maintenance, because AI tools can help adversaries reverse-engineer patches and build working exploits in hours or days, patch differences show where the weakness sits, and AI can chain lower-severity flaws (Fortinet, 2026-10-21). The public advisories will appear only at the next Patch Tuesday, 2026-11-10 (Fortinet, 2026-10-21). NCSC.ch's advisory describes the fixes as ones that might allow attackers to gain unauthorized control over affected security infrastructure and lists the current exploitation status as unknown (NCSC.ch, 2026-10-22).

    Fortinet's tables name these affected and fixed versions: FortiOS 8.0.0 to 8.0.1 (fixed 8.0.2), 7.6.0 to 7.6.7 (7.6.8), 7.4.0 to 7.4.12 (7.4.13) and 7.2.0 to 7.2.13 (7.2.14); FortiManager and FortiAnalyzer 8.0.0 to 8.0.1 (8.0.2), 7.6.0 to 7.6.7 (7.6.8), 7.4.0 to 7.4.11 (7.4.12) and 7.2.0 to 7.2.12 (7.2.13); FortiMail 8.0.0 to 8.0.1 (8.0.2), 7.6.0 to 7.6.6 (7.6.7), 7.4.0 to 7.4.8 (7.4.9) and 7.2.0 to 7.2.9 (upgrade to the 7.4 branch or later); FortiAuthenticator 8.0.0 to 8.0.3 (8.0.4) and 6.6.0 to 6.6.10 (6.6.11) (Fortinet, 2026-10-21). FortiSASE updates automatically, FortiManager Cloud may need a manual update, and public-cloud instances follow their cloud partners' release processes (Fortinet, 2026-10-21). heise online lists the same fixed builds and the same 2026-11-10 disclosure date (heise online, 2026-10-22).

    The FortiMail rows are identical to the fix table of Fortinet's advisory FG-IR-26-175, an unauthenticated path traversal in the FortiMail IBE webmail service (CVE-2026-104286) that Fortinet reports as exploited in the wild (Fortinet PSIRT, 2026-10-01). Those FortiMail builds therefore already fix a flaw under attack, and the post does not say whether they carry further fixes; for FortiOS, FortiManager, FortiAnalyzer and FortiAuthenticator no source states exploitation.

    HIGHCVE-2026-44277 +1updatedNATOA2

    CVE-2026-44277 and CVE-2026-26083: unauthenticated code execution in the Fortinet FortiAuthenticator API and the FortiSandbox web UI

    CVE-2026-44277 is an improper access control flaw (CWE-284) on FortiAuthenticator's API endpoints that may let an unauthenticated attacker execute unauthorized code or commands through crafted requests; it affects FortiAuthenticator 6.5.0 to 6.5.6, 6.6.0 to 6.6.8, 8.0.0 and 8.0.2, is fixed in 6.5.7, 6.6.9 and 8.0.3, does not affect FortiAuthenticator Cloud, and can be worked around by disabling API access on exposed interfaces under Network, Interfaces, Access Rights (Fortinet FG-IR-26-128). CVE-2026-26083 is a missing authorization flaw (CWE-862) in the web UI of FortiSandbox, FortiSandbox Cloud and FortiSandbox PaaS with the same effect through HTTP requests; FortiSandbox is fixed in 4.4.9 and 5.0.2, FortiSandbox Cloud 5.0 in 5.0.6 and FortiSandbox PaaS 4.4 and 5.0 in 4.4.9 and 5.0.2, while FortiSandbox Cloud 23 and 24 and PaaS 21.3 to 23.4 must migrate to a fixed release (Fortinet FG-IR-26-136). Fortinet discovered both internally, rates each Critical with a CVSSv3 base score of 9.8 and a temporal score of 9.1, and marked neither as known exploited when it published on 2026-05-12 (Fortinet FG-IR-26-128; Fortinet FG-IR-26-136). ENISA's EUVD records carry the 9.1 figure and also list FortiAuthenticator 6.4.0 to 6.4.10 and FortiSandbox 4.2.1 to 4.2.8 as affected (EUVD-2026-29729; EUVD-2026-29550), branches for which Fortinet's advisories, as read on 2026-10-21, name no fixed release (Fortinet FG-IR-26-128; Fortinet FG-IR-26-136).

    Exposure
    FortiAuthenticator and FortiSandbox appliances, and FortiSandbox Cloud and PaaS instances, on the affected releases whose API or web UI an attacker can reach over the network (NCSC-CH, 2026-05-13); FortiAuthenticator Cloud is not affected (Fortinet FG-IR-26-128).
    Detection
    Management-interface access logs on the appliances: requests to the FortiAuthenticator API or the FortiSandbox web UI from sources outside the administrators' networks, since both flaws are reached through unauthenticated requests to those interfaces (Fortinet FG-IR-26-128; Fortinet FG-IR-26-136).
    Defender takeaway
    Upgrade FortiAuthenticator to 6.5.7, 6.6.9 or 8.0.3 and FortiSandbox to 4.4.9 or 5.0.2 (Cloud 5.0.6), and migrate FortiSandbox Cloud 23 and 24 and PaaS 21.3 to 23.4 to a fixed release; until FortiAuthenticator is upgraded, disable API access on its exposed interfaces (Fortinet FG-IR-26-128; Fortinet FG-IR-26-136).
